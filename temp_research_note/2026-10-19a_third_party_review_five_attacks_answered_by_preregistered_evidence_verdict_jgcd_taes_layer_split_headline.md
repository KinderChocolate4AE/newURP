## 2. 사용자 방향 결정 (대화 중)

- **"전자" (feasibility 논문) 선택**: 헤드라인 = "χ 가 지배하는 보증 비파괴 포획의 성립가능성 이론". MARL = 이론을 예시·확증하는 도구. 협력 NULL = 성립가능성 진술로 재서술. **credit-assignment 질문은 명시적 범위 밖** (독자에게 "왜 못 배웠나"를 빚지지 않음). 기존 3축 지도 결정 (Paper 1 기여 ③ 없이) 및 연구 정체성 (guidance/systems, MARL frontier 아님) 과 일치 — 새 결정이라기보다 재확인·강화.

## 3. 리뷰어 최종 산출 (반영 대상)

1. **유일한 서술 리스크 = 층 분리 간판**: "존재 경계 = χ 단독 / 창 길이 = χ 와 R/V" 를 abstract/intro 에 선언하고 들어갈 것. R/V 를 뒤에서 발견하게 하면 신뢰 흔들림. → **AIAA abstract (11/12) spine 규칙 후보** (사용자 결재 대기). 공사판은 §0.6/4-2 구조상 이미 분리되어 있으나 요약 문장 점검.
2. **저널 상한 = JGCD / TAES** (AIAA 컨퍼 → JGCD 확장 = 교과서적 파이프라인). 기존 Phase F "Paper 1-J (TAES/AST)" 와 정합 — JGCD 를 1순위 후보로 승격 검토. 막는 네 가지: 시뮬 전용·점질량 / capture volume 미앵커 / 방법 아닌 성립가능성 결과 / 유한표본 판정 (정리 아님).
3. **티어 레버** (독립 작동): ① 존재 경계 형식 정리화 (reachability/미분게임 증명 — TAC/Automatica 급, 최중량; 기존 "Proposition 정형화 (가을)" 슬롯) ② 고충실도 전개 앵커 1점 = 보수계수 ("모델 대비 X% 깎인 하한"; Han 외 2026 FEM 연결, 후속 후보 메모됨) ③ 두 번째 군 (R/V) 해석 유도 깨끗이 = 프로브 0-8 + 해석 ④ 정면 worst-case·점질량 너머 일반화.
4. **냉정 보정**: 사전 등록·봉인·NULL 정직성은 방패지 창이 아님 — 티어는 결과 일반성·모델 충실도가 올림. 노력은 레버 ①②로.
5. **멈춤선 규칙** (현실성 추가 종결 기준, 채택 가치): **필요조건 경계 (χ\*) 를 움직이는 현실성만 추가, 도달 수준만 흔드는 현실성은 버림**. 개방 실패·τ(D)·δ = 경계를 움직임 (추가 ✓) / τ-지평 선회 제한 = ±w (지배항의 1/8) 뿐 (버림 ✓, vτ/w 수치가 증명) / 접근 단계 관성 = χ\*_herd 를 해석으로 정의할 수 있을 때만 (해석 먼저, 배선은 그다음).
6. **Paper 2 규율** (후자 추적 시): 해석으로 χ\*_herd regime 예측 먼저 → 실험은 확증/반증만. opportunity 해석상 없는 영역의 NULL = 층 1 확장 (내구적) / 있는데 미실현 = RL 결과 (다른 논문). 야간 후보 (docs/141) 제3 후보로 연결 — 사용자 결재·11/12 이후.

## 4. 남은 실험 큐와의 정합 (새 작업 없음, 순서만 확인)

(1) collapse 완결 = 프로브 0-6 (R 재시험, 측정 컷 회피 설계) · 0-8 (V — 해석 예고: 존재는 V 무관, 길이는 R/V → "예고된 명명") · 0-7 (실제 가속 창) — 판정 기준 선커밋 후 실행. (2) 낙관 상수 경화 = 승인된 비이상성 프로브 계약 (δ·L·τ_r, 10/19 밤~, 판독 ~10/24) + 개방 실패 모델링은 그다음 후보. (3) 보수계수 앵커 = 후속 (AIAA 이후) 후보 유지.
