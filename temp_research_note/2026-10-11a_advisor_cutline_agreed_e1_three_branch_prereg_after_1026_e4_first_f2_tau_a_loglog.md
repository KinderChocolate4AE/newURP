## 4b. 지도교수 2차 답변 (같은 날) + main 코드 확인

- **dt 계단 (확인)**: FSM 전개 타이머는 연속 τ 에서 dt 씩 감소, ε = 1e-9 (`finisher_fsm.py:28,96-101`).
  실현 전개 tick: ρ 1.92 = 6 (τ/dt 정확히 6, ε 로 7 안 됨) · 2.3 = 6 · 2.66 = 6 · **2.94 = 5** · 3.4 = 5 ·
  3.92 = 5 · 7.69 = 3 · 11.77 = 3. **6 → 5 계단이 2.66 과 2.94 사이** (ρ½ 등록 대역 바로 옆).
- **포획 결과 = 발사 순간의 robust 판정, 연속 τ 사용 (확인)**: `env.py:341`
  (`_pending_capture = ¬boxed ∧ v_shot_worst ≥ 1`, 판정 τ = `self.tau_deploy` 연속값). tick 은 결과가 아니라
  **해소 시각** (DEPLOYING n tick + LOCKED τ_lock 0.1 s) 과 net_spent → fallback 무장 시각만 정한다.
  - 남는 경로 하나: 해소 전에 공격자가 침투하면 판정상 포획이 사라진다 → net 지표도 계단의 영향을 조금
    받을 수 있다 (1 tick ≈ 1.15 m 이동). E1 계약에 "robust 발사였으나 해소 전 침투" 수를 변형별로 보고하도록 넣는다.
  - `env.py:321-324` 주석의 "PHYSICAL capture (judge-independent)" 는 341 행 코드와 맞지 않는 **stale 주석**
    (코드 = 판정 기반). 논문 서술은 S3 (판정 = 보장-포획 하한) 그대로.
- **E1 판정 지표 = net 기반** (NET_CAPTURE + CAPTURE_WITH_CONTACT). 전체 방어 수는 보고만. 참고: E7-b 에서
  ceil_det 와 net_det 의 차이는 0–2 (예: 41/40, 21/20) → 지표를 바꿔도 기존 수치는 거의 같다.
- **공격자 정규화 (확인)**: residual 범위 = ±2·att_a_max (`world.py:162-164`), autopilot 출력도 att_a_max 로
  clip (`world.py:156`), 합산은 백엔드가 a_max 로 clip. **a 를 줄이면 residual 권한도 비례해서 준다**

- **Λ = V²/(a·R_max)**: a 계열이 함께 바꾸는 두 번째 무차원군 (선회 반경 V²/a: 26 → 53 m). E6 의 "같은 ρ, 다른
  천장" 은 Λ 의 몫으로 명명한다.
- **μ 보정**: 주 조건 = a_def 절대 고정 (μ' ≈ 0.72), 여유 있으면 μ 고정 조건으로 반대쪽도 감싼다. E6 도 net 지표 (A안에서는 a↓ 가 K_FIRST 를 통해 천장을 올리므로).
- **E6 위치**: E1 계약 안의 조건부 a-arm (ρ 3.92 한 점). ρ½ 는 τ 사다리로만 추정하고, a-arm 은 같은 계약의
  τ-3.92 점과만 비교. E2 분기표에 양방향 트리거를 기재, E6 가설·게이트는 E6 실행 전에 봉인, 결과는 무조건 보고.
- **E4 재설계**:
  - a 계열은 넓은 sweep 금지. ρ 매칭점 (a ≈ 13.4 / 10.0 / 5.1 ↔ ρ 2.94 / 3.92 / 7.69) + **ρ₀ 근방**
    (a = 25 / 30 / 33 → ρ 1.57 / 1.31 / 1.19, 그리고 τ 1.2× → ρ 1.34).
    지금까지 모든 데이터가 ρ ≥ 1.92 라서 ρ < ρ₀ 를 처음 시험한다. main 추가: 판정상 ρ < ρ₀ 에서 robust tick 은 불가능하므로,
    여기서 나오는 robust tick 은 **판정 witness 표본 수 (유한 n) 의 근사 오차**를 직접 잰다.
  - **collapse 등록 좌표 = N/N∞ vs ρ/ρ₀(θ)** (R 계열은 N∞ ∝ R 이라 N 자체로는 모이지 않는다). 예측 곡선 = 1 − ρ₀/ρ.

- **F2 의 V**: 본 패널에 V = 15 / 23 / 35 m/s 의 ρ* 선 (main 계산: 1.95 / 2.81 / **8.34** — 지도교수 문안의 "~8.2"
  는 8.34 로 정정). ρ₀ 는 V 와 무관. V ≥ R_max/(4dt) = 41.1 m/s 이면 어떤 ρ 에서도 창이 4 step 에 닿지 않는다.

## 4c. 지도교수 3차 답변 (같은 날) — E1 판정 설계 확정안 + main 검증

- **평탄부 (Q1)**: 외부 상수로 고정하지 않는다. 사전 등록 모형 (log ρ 에 대한 4-모수 logistic: 바닥·평탄부·위치
  ρ½·기울기) 으로 E1 데이터에서 함께 추정하고, 추정 대상은 ρ½ 하나. 모형·맞춤 절차·CI 방법은 결과 전에 봉인.
  - **E1 사다리에 7.69 추가** (평탄부 식별에 위쪽 점 2개 필요) → 7점 × seed 5 = 35 run.
  - 민감도: 외부 평탄부 (E7-b/b′ net 기준) 로 고정했을 때의 ρ½ 도 보고.
  - **갈래 배정 = CI 가 한 갈래 안에 완전히 들어갈 때만**. 경계를 걸치면 "미결정" (사전 기재).
- **확정 전 침투 (Q2)**: 주 판정은 보정하지 않는다 (실현 net 포획이 주 지표). 2차 추정량 = robust 발사 수 기준
  천장 (tick 경로 제거, 판정 층) 으로 같은 절차의 ρ½. 주·2차 갈래가 다르면 **"이산화 민감"** 표시, 갈래 주장 안 함.
  - **main 검증: 6 → 5 tick 계단은 τ = 0.25 s, ρ = 2.769** (ρ*(4dt) 2.813 의 98.4%, 등록 대역 안). τ = 0.25 는 5 tick,
    τ = 0.25 + 2e-9 는 6 tick. dt = 0.05 고정인 한 피할 수 없다.
  - 선택 진단 (GPU 여유 시, +10 run): 계단 양쪽 쌍 ρ 2.75 (τ 0.25087, 6 tick) / ρ 2.78 (τ 0.24951, 5 tick).
    지도교수 문안의 τ 0.2503 / 0.2497 은 근사치. tick 수는 맞음.
- **서술 규율 (Q3)**: v0 한계 절에 넣는다 (지도교수 다듬은 문장 — 사용자가 직접 문장화). F2 는 **E4 가 10/20 까지
  판독되면** v0 에 넣고, 아니면 v0 는 ρ 축 그림만 쓰고 "(τ, a) 평면 iso-ρ 는 후속 검증 대상" 한 문장으로 대신.
  해석선만 있는 (τ, a) 평면 + "해석 경계" 라벨은 E4 전에도 정직하다. 금지 = a 방향 영역에 데이터 라벨.
- **ρ < ρ₀ 점의 함의**: 유한 witness 는 탈출 구를 덜 덮는 쪽으로 오차가 난다 → robust tick 이 나오면 판정이 관대하다는
  뜻 (K1 유도 A1: "이산 witness → 최대 ~18% ↓" 와 같은 방향). E4 계약에 기재:
  0 이면 "보장-포획 하한" 서술 유지 / 0 이 아니면 "유한 witness 근사 하의 보장-포획 판정" 으로 한정하고 관대함 크기 보고.
  → E4 를 v0 전 (10/16–20) 에 돌릴 이유가 하나 더 생김.
