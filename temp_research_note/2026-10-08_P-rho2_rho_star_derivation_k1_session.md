## 0. 세계 정의 (FS1 실측 상수 — 이것만 사용)

| 기호 | 값 | 비고 |
|---|---|---|
| dt | 0.05 s | |
| τ (τ_deploy) | 0.3 s | |
| θ | 0.212 rad (12.2°) | 콘 반각. sinθ = 0.21042, cosθ = 0.97761, tanθ = 0.21523 |
| R_max (= d*) | 8.22 m | 콘 range_max |
| a_max | 20.45 m/s² | 공격자, 등방. 선회율 ω=10 rad/s 는 τ 동안 ~246° 라 비구속 |
| ω_fin | 2.0 rad/s | 포탑 slew |
| r = ½·a_max·τ² | 0.920 m | 탈출 반경 (파생) |

- 판정 = se3_cone: 콘 축 = 포탑 heading, 탈출 witness 종점이 전부 콘 안 ∧ ¬boxed → robust.
- 조준점 = p_att + v_att·τ (등속 외삽), 포탑은 그 방향을 ω_fin 제한으로 추적.
- ρ = d*·tanθ / (½·a_max·τ²) = R_max·tanθ / r (계약 고정). 항등 세계 ρ = 1.923.
- 판정 의미론 = 보장-포획 하한 (witness ⊇ 실제 공격자).

## 1. 등록 요약

| 항목 | 결과 |
|---|---|
| 창 존재 경계 (폭 0) | **ρ₀ = secθ + tanθ = tan(π/4 + θ/2) = 1.238** |
| 창 폭 | **N(ρ) = N∞·(1 − ρ₀/ρ)₊**, N∞ = R_max/(V̄·dt) = 164.4/V̄ |
| ★ρ* (창 중앙값 ≥ 4 step) | **ρ* = ρ₀ / (1 − 4·dt·V̄/R_max) = 1.238 / (1 − 0.02433·V̄)** |

**입력 하나가 상수 목록에 없다.** 창 폭을 시간으로 번역하려면 V̄ 가 필요하다. V̄ = 조준점(p + vτ)이 콘 꼭짓점에 대해 움직이는 상대속도 크기의 중앙값이다. 따라서 ρ* 는 V̄ 에 대한 공식으로 등록된다. 단일 값으로 등록하려면 **V̄ 를 E7-b 전에 세계 스펙(공격자 순항속도, capturer 속도 상한)에서 고정**해야 한다. rollout 에서 측정한 V̄ 를 쓰면 forking path 가 열린다.

| V̄ (m/s) | ρ* (T ≥ 4dt) | ρ* (T ≥ 3.5dt, 이산화 하한) |
|---|---|---|
| 5 | 1.41 | 1.39 |
| 8 | 1.54 | 1.49 |
| 10 | 1.64 | 1.57 |
| 12 | 1.75 | 1.66 |
| 15 | 1.95 | 1.82 |
| 20 | 2.41 | 2.16 |
| ≥ 41.1 | 불가 (ρ→∞ 에서도 N < 4) | |

**V̄ 와 무관하게 성립하는 판정**: 항등 세계(ρ = 1.923)의 창은 N = 58.6/V̄ tick. 따라서 항등 세계가 4 step 이상 창을 갖는 것은 **V̄ ≤ 14.6 m/s** 일 때뿐이다.

## 2. (a) 단일 tick no-escape 조건

**Witness 집합.** W = B(c, r), c = p_att + v_att·τ, r = ½·a_max·τ² = 0.920 m.
이 구는 이중적분기(|a| ≤ a_max)의 τ-도달집합과 정확히 일치한다 (시변 가속도라도, 임의 방향으로 가장 멀리 가는 해는 일정 가속이므로 같은 구). 등속 외삽 조준점이 곧 c 이므로, 조준 오차 δ 는 포탑 lag 만으로 정해진다.

**콘.** K = {x : ∠(x, 축) ≤ θ, |x| ≤ R_max}, 꼭짓점 = 발사 시점 포탑 위치.

**W ⊂ K 조건** (연속 구에 대해 근사가 아닌 필요충분):

```
(i)  arcsin(r/D) + δ ≤ θ        구의 각반경 + 축 오차가 콘 안
(ii) D + r ≤ R_max              구의 가장 먼 점이 사거리 안
```

D = 꼭짓점에서 c 까지 거리. 축 방향 절단 캡이면 (ii) 는 D·cosδ + r ≤ R_max 이고 δ = 0 에서 동일하다.

**ρ 로 재작성.** r = R_max·tanθ/ρ, u = D/R_max:

```
ρ ≥ max( tanθ / (u·sin(θ−δ)) ,  tanθ / (1−u) )
```

- 구간(band): D ∈ [D_min, D_max] = [r / sin(θ−δ), R_max − r]
- 구간 비지 않을 조건: **ρ ≥ ρ₀(δ) = tanθ·(1 + 1/sin(θ−δ))**
- δ = 0 → ρ₀ = secθ + tanθ = 1.238
- 창이 처음 열리는 거리 D* = R_max/(1 + sinθ) = 6.79 m
- 탈출 반경으로 쓰면 r ≤ r₀ = R_max·sinθ/(1 + sinθ) = 1.429 m

**ρ₀ ≠ 1 인 이유.** ρ = 1 은 "최대 사거리에서 콘 반폭 = 탈출 반경" 일 뿐이다. 여기에 두 몫이 더해진다:
- 구의 깊이가 사거리를 먹는 몫: + tanθ
- 콘 표면까지 거리가 D·tanθ 가 아니라 D·sinθ 인 보정: secθ

결과적으로 ρ₀ ≈ 1 + θ.

**항등 세계.** 구간 4.37 ~ 7.30 m, ΔD = 2.93 m.

## 3. (b) 창 폭 스케일링

**Robust 영역.** 포탑이 c 를 추적하면(δ ≈ 0) robust 영역은 꼭짓점 중심 구각 shell D ∈ [D_min, D_max] 이다. 창 = 조준점이 shell 안에 머무는 시간.

**상대경로별 창 길이.** 직선 상대경로, 속도 V, 최근접 거리 b:

```
b = 0 (정면)          : T = ΔD / V
b < D_min             : T = [√(D_max²−b²) − √(D_min²−b²)] / V  ≥ ΔD/V
D_min ≤ b < D_max     : T = 2√(D_max²−b²) / V
```

정면 chord 가 최소 → 정면 기준 ρ* 는 보수적(상한 쪽). 단 b 가 크면 포탑 slew lag 가 반대 방향으로 작용한다 (가정 A4).

**창 폭 공식.** ΔD = R_max·(1 − ρ₀/ρ) 이므로

```
N(ρ) = N∞·(1 − ρ₀/ρ)₊ ,   N∞ = R_max / (V̄·dt)
```

**검증 가능한 형상 예측 (main 겹쳐 그리기용):**
- 창은 ρ₀ 에서 0 부터 연속적으로 열린다. 점프 없음.
- N 은 1/ρ 에 대해 선형. x 절편 1/ρ₀, y 절편 N∞.
- 손잡이 하나만 바꿀 때:
  - τ 만: N = N∞·(1 − (τ/τ₀)²), τ₀ = √(2·r₀/a_max) = 0.374 s
  - a_max 만: N = N∞·(1 − a/a₀)
- θ 또는 R_max 를 바꾸는 variant 는 ρ 단일 곡선에 collapse 하지 않는다. 예측 이탈 방향:
  - ρ₀(θ) = secθ + tanθ 가 θ 에 따라 이동
  - N∞ ∝ R_max
- N 은 V 에 단조 → 창 중앙값 = N(V̄).

**Tick 이산화.** 길이 T 구간 내 tick 수는 ⌊T/dt⌋ 또는 +1 (위상 균등 가정). P(count ≥ 4) = T/dt − 3 (3dt ≤ T < 4dt) 이므로 중앙값 ≥ 4 ⇔ T ≥ 3.5dt. 4dt 는 보수적 표기. §1 표의 두 열이 이 범위.

## 4. (c) ★등록 대상

```
ρ* = (secθ + tanθ) / (1 − 4·dt·V̄/R_max)
   = 1.238 / (1 − 0.02433·V̄)          [V̄ 단위 m/s]
```

등록 문장에 함께 고정해야 할 정의:
1. **V̄ 출처**: E7-b 전에 세계 스펙에서 고정한 값. rollout 측정값 금지.
2. **중앙값 모집단**: shell 을 통과한 encounter 에 조건부. shell 에 도달하지 못한 encounter(창 = 0)를 섞으면 중앙값이 ρ 가 아니라 정책 도달 능력을 잰다.
3. **Tick 기준**: 4dt (보수) 를 판정선으로, 3.5dt 를 이산화 허용 하한으로 병기.

등록 문장 초안:

> P-ρ2: FS1 se3_cone robust 판정에서, shell 통과 encounter 조건부 robust 창 tick 수 중앙값이 4 이상이 되는 경계는 ρ* = (secθ + tanθ)/(1 − 4·dt·V̄/R_max) 이다. V̄ = [세계 스펙 고정값] m/s 에서 ρ* = [값]. 창 폭은 N = N∞·(1 − ρ₀/ρ) 형상(1/ρ 에 선형, ρ₀ = 1.238 에서 연속 개방)을 따른다.

## 5. (d) 기동-인지 조준의 역효과 조건 (선택 과제)

**결론: 현 판정 의미론에서는 항상 약지배(weakly dominated).**

**구조적 이유.**
- Robust 판정의 witness 는 c 중심 등방 구 — 공격자의 현재 가속을 신용하지 않는다.
- 기동-인지 조준점 = c + ½·â·τ² → 축이 구 중심에서 횡방향으로 k·r 이탈 (k = |â_⊥|/a_max ≤ 1).
- 대칭성: 등방 구에 대해 최소 각여유를 최대화하는 축은 c 방향 유일. → â_⊥ ≠ 0 이면 엄격히 손해.
- 경계 이동 (근사): ρ₀(k) ≈ (1 + k)·secθ + tanθ. k = 0.5 → 1.75, k = 1 → 2.26.

**지터 항 (위 손해에 추가).**
- â 가 bang-bang 전환을 1 tick 늦게 따라가면 조준점이 최대 a_max·τ² = 1.84 m 튄다.
- 각도 1.84/D rad (D = 5 m 에서 0.37 rad) vs 포탑 tick 당 slew ω_fin·dt = 0.1 rad → 재정렬 ~4 tick. 이것만으로 4 step 창 하나를 지울 수 있다.
- 포탑 포화 조건: ½·|Δâ_⊥|·τ²/D > ω_fin·dt.
- â 를 잡음 섞인 속도의 유한차분으로 얻으면 축 지터 ≈ ½τ²·√2·σ_v/dt = 1.27·σ_v (m).

**이득이 날 수 있는 유일한 경우.** 판정이 공격자 commitment 를 신용할 때 (실현 궤적 판정, 또는 witness 구를 ½âτ² 만큼 이동한 판정). 둘 다 현 계약 의미론 밖.

## 6. 가정 목록과 민감도

| # | 가정 | 깨질 때 ρ* 방향 |
|---|---|---|
| A1 | Witness 는 연속 구, 속도 상한·항력 없음 | 속도 상한/항력 → witness ⊂ 구 → **↓**. 축 정렬 6점 등 이산 witness → 최대 ~18% **↓** |
| A2 | 상태 완전 관측 (등속 조준점 = 구 중심) | 속도 잡음 σ_v → δ ≈ σ_v·τ/D → **↑** |
| A3 | 콘 꼭짓점 = 발사 시점 위치 고정, 최소 사거리 없음, 캡 형태(구면/축)는 δ=0 에서 무관 | 형태 불변 |
| A4 | **δ ≈ 0 (포탑이 c 를 따라잡음) — 최대 민감 항목.** dρ₀/dδ = 1/sinθ = 4.75 /rad; δ = 0.05 rad → ρ₀ = 1.55 (+25%). δ/θ 가 두 번째 핵심 무차원 그룹. Slew 포화 조건 U_⊥ = \|V_⊥\| + \|a_⊥\|·τ > ω_fin·D_min, 이때 D_min,eff ≈ max(D_min, U_⊥/ω_fin). 항등 세계 ω_fin·D_min = 8.7 m/s, 횡방향 전력 jinking(a_⊥τ = 6.1 m/s) 시 횡단 속도 여유 2.6 m/s | **↑** |
| A5 | ¬boxed 만족 (교전 내부) | 위반 tick 은 창에서 빠질 뿐 → **↑** |
| A6 | Shell 내 V 일정, 직선 상대경로 (정면 = 최소 chord) | 비스듬한 경로 → 창 길어짐 → **↓** |
| A7 | 중앙값 = shell 통과 encounter 조건부, tick 위상 균등 | 4dt 대신 3.5dt → §1 표 두 번째 열 |
| A8 | V̄ 는 외부 입력 | 등록 전 고정 필수 |
