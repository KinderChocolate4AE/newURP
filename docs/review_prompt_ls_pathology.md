# 외부 리뷰 요청 9 — MARL 1차 결과 (LL 0/300 · LS = finisher-단독 퇴화) 와 다음 팔 선택

> 그대로 붙여 넣어 쓴다. 리뷰어는 리포·이전 대화 접근이 없으므로 자기완결적으로 썼다.

---

당신은 다중 에이전트 강화학습 논문의 **비판적 외부 리뷰어**다. 우리는 동결된
TRAIN 위협 분포에서 첫 MARL 두 런을 완주했고, 둘 다 사전등록 규율대로
기록했다 (곡선 보고 중간 개입 없음, reward/분포/게이트 불변). 결과는 실패인데
실패의 **모양**이 특이해서, 다음 팔 선택 전에 진단과 규율을 공격받고 싶다.

> **핵심 질문: "학습 정책이 자기 actuator 를 즉시 자폭시키는 퇴화 국소최적"
> 이라는 우리 진단이 맞는가 — 그리고 사전 선언된 폴백 팔(commit 비트 제거)로
> 넘어가는 것이 적법한가, 아니면 adaptive arm search 의 시작인가?**

## 1. 시스템 (요약)

무인기 last-mile 방어 (3D 질점, dt 0.05 s, 300 m 스케일, 지평선 1100스텝):
공격자 1기 (반응형 scripted — 회피 gain·감지반경 랜덤, 동결 분포), limiter
4기 (자산 주위 8–16 m standby 시작), finisher 1기 (그물 1발, fire gate).
**limiter 행동 = 연속가속 3축 + 이산 commit 비트 1개** — commit 제안 시
env 가드가 해소: 기하 불만족 → **limiter 소모(GEOM_FAIL)** 후 원격 주차 /
기하 만족 ∧ Bernoulli(Pk) → 파괴적 하드킬. 보상: 포획 +1, 하드킬 +0.5,
침투 −1, limiter 소모당 −0.1. MAPPO, 공유 advantage, rollout 256스텝
(에피소드 1100 을 4~5회 절단), limiter commit 헤드 entropy 계수 0.

비교 기준선 (사전 동결): bearing-aware arc scripted (commit 0 고정) —
TRAIN 튜닝 p_net 0.11. headline = hold vs scripted vs MARL, held-out IID
300판 paired, Δ_net CI. 발사만 스크립트로 바꾼 역할분리 팔들이 사전 선언돼
있다 (LL = 전부 학습 / LS = 편대만 학습 + 발사 scripted / …).

## 2. 결과 (판정용 final eval 300판, 커밋된 사실)

```
LL (전부 학습):      무력화 0/300 — 전판 침투. 학습 내내 곡선 eval 비영점 0회
LS (발사 scripted): 무력화 49/300 (0.163) — 전부 순수 NET_CAPTURE.
                    FREE regime 49/136 (0.36) · SHAPING 0/164
                    hold(무개입) 팔의 floor 와 유사 수준 (동일 근처)
```

**궤적 덤프 (viz-first, 8판 전수)**: LS 의 limiter 4기가 **모든 판에서
t=6~17 (0.3~0.85초) 안에 전량 commit → 공격자가 250 m+ 밖이라 전부
GEOM_FAIL 소모 → 주차**. 이후 수백 스텝은 finisher 단독. 학습 곡선의
commit rate 는 0.44~0.80 로 진동 (내려가지 않음).

## 3. 우리 진단 (공격 대상)

1. **LS 0.163 은 "편대 학습의 실패치"가 아니라 "limiter 부재 상태의
   finisher 단독 성능"이다** — 편대 협력 질문에 정책이 도달조차 못 했다.
2. 퇴화가 고착된 기제: 스텝당 Bernoulli 제안이라 commit rate ≫ 0 이면 수
   스텝 내 전원 소모가 확정 → 소모 후엔 limiter 행동에 gradient 가 안 흘러
   "살려두면 뭘 할 수 있는지" 자체가 탐색 불가. 반대 신호는 c_lim 총 −0.4
   (1회) 뿐이고 ±1 종말 노이즈에 묻힘. entropy 0 이 압력을 더하지 않음.
3. LL 의 0/300 = 같은 병리 + 발사 credit 실패 (legacy 에서 실증된 병목의
   재현) 의 중첩.

## 4. 다음 팔 후보 (우리는 아직 안 골랐다)

- **(a) LS + limiter_commit=false** — commit 비트를 정책 손에서 떼는 대조군.
  ★ 이 폴백은 **결과 전에 선언돼 있었다** (커밋 배선 설계 문서의 §15.2 (b)
  "config 로 끄면 커밋을 정책 손에서 뗀 팔이 된다" + 학습기 config 주석).
  4기가 생존하므로 편대 질문이 처음으로 실제 탐색됨. scripted 기준선도
  commit 0 이라 비교가 더 대칭적. 대가: 이 팔은 하드킬 능력 없음 (headline
  1차가 nondestructive 라 영향 제한적이라는 게 우리 주장).
- **(b) 학습 하이퍼 개정** — commit entropy 부여 / c_lim 상향 / rollout
  길이 연장 (1100 절단 완화). 전부 학습 계약 변경 = 재사전등록 필요.
- **(c) 여기서 종료** — 현 결과로 headline (IID) 기록: "채널 실재(사전
  실증) + 현 학습 계약에서 협력 이득 미검출". 정직한 negative.
- **(d) 시드 추가 먼저** — 현재 n=1 시드. 선언된 시드 축 {0..4}.

## 5. 무너뜨려 볼 주장들

1. **"0.163 = finisher-단독 성능"** — 궤적 8판 + hold 유사 floor 가 근거다.
   300판 전체로 일반화하는 데 빈틈이 있는가? (저장된 threat_log 로 소모
   시점 전수 확인 가능 — 어떤 추가 확인이 진단을 확정/반증하는가?)
2. **"(a) 는 소급 튜닝이 아니다"** — 폴백이 결과 전 선언된 건 사실이나,
   *발동 시점*은 결과를 본 뒤다. "결함이 예견돼 폴백이 미리 선언된 경우의
   발동" 과 "실패 보고 팔을 고르는 adaptive search" 의 경계를 판정하라.
   P95 때 우리는 stop rule 로 재탐색을 잘랐다 — **팔 사다리에도 같은 stop
   rule 이 필요한가? 몇 번째 팔까지가 정당한가?**
3. **"commit 제거는 headline 을 왜곡하지 않는다"** — scripted 기준선과
   대칭이 좋아진다는 우리 논리 vs "MARL 의 행동공간을 결과 보고 축소해
   비교를 쉽게 만들었다" 는 공격. 어느 쪽이 맞나? (참고: 기존 문서에
   "headline MARL 은 commit live" 를 전제한 문구가 있어 개정 필요 여부 포함)
4. **병리의 대안 설명** — "commit 자폭 때문" 이 아니라 (i) rollout 256
   절단으로 credit 이 원래 못 흐른다, (ii) Δv_shot dense 신호가 route 채널
   을 즉시 반영 안 해 limiter 에 유효 신호 자체가 없다, (iii) 지평선 희석 —
   이면 (a) 를 해도 똑같이 실패한다. 어떤 저비용 진단이 이 셋을 (a) 실행
   전에 판별하는가?
5. **서술 상한** — 현 시점에서 논문(국내 학술대회 2p 포함)에 쓸 수 있는
   문장의 상한을 제시하라. 특히 "cooperative shaping 은 학습되지 않았다"
   는 표현이 (a) 실행 전에 허용되는가?

## 6. 제약 (잠긴 규율 — 재론 대상 아님)

- 위협 분포 (FINAL FREEZE) · 보상 가중치 · 게이트 · scripted 기준선 (동결)
  · headline 계약 (IID 300판, lexicographic) 전부 불변.
- P95 계열 stop rule 유지. 성능 보고 threat/reward 재설계 금지.
- 폴백 (a) 외의 새 팔 발명은 새 사전등록 + 리뷰 사이클.

## 7. 요청 형식

- §5 주장 1~5 각각: **유지 / 조건부 유지 / 기각** + 이유 (2–3문장).
- **다음 액션 1개 지정** (§4 의 a~d 또는 수정안) + 그 액션의 **사전등록
  문구 초안** (판정 기준 + 시드 수 + stop rule 포함 — "이것도 실패하면
  어디서 멈추는가" 를 반드시 명시).
