## 0. 개요 (간단히)

이번 기간의 작업은 신청서 **Phase A** 와 **Phase B 전반**에 해당한다.

- Phase A 의 **최우선 항목 T0 = "Net forward model 검증 + C_0 false-positive gate (N1 go/no-go)"** 를 수행했고,
  **신청서가 요구한 경험적 FP sweep 보다 강한 형태 — 해석적 경계식 — 으로 답이 나왔다.**
- Phase A 의 비학습 baseline(B-1/B-2 계열)과 임무 지표 체계를 구축했다.
- Phase B 의 학습 배선까지 끝냈으나, **모델링 결정 1건이 미해소여서 학습은 아직 걸지 않았다.**
- 그 과정에서 **우리 전제 세 개가 문헌 앵커링에 의해 반증**되었고, 세 번 다 계산 자원을 쓰기 전에
  사전등록된 게이트가 잡았다.

> 한 줄: **신청서의 1차 gate(N1)를 통과했고, 그 통과 방식이 예상보다 강했다.
> 다만 2차 gate(N2 marginal) 앞에서 모델링 결정 하나가 남았다.**

## 2. N1 — 실패 경계의 해석적 형태 **[갱신 — 가장 큰 성과]**

신청서 §4.2 Step 0 / §4.7 Phase A T0 는 *"C_0 false-positive rate 가 어느 영역에서 솟는지"* 를
**경험적 sweep** 으로 재라고 했다. 실제로는 **닫힌 형태**가 나왔다.

```
w = ½ · a_att · τ²   vs   ρ (net radius)        ->   a* = 2ρ / τ²
w < ρ  :  조향 없이도 포획된다        (기하학적 조건이 보수적 — shaping 의 방어가치 = 0)
w > ρ  :  조향이 필요하다             (N1 이 말하는 regime)
```

현재 앵커 값으로 **a\* = 39.3 m/s²**.

**슬라이드 소재**
- 1차원 수직선: `a_att` 축 위에 a\*=39.3 을 긋고, 위협 브래킷 [11, 78] 이 **가로지르는** 그림
- 등급별 표: a=11(문헌 표적) 0.49 / a=30 1.35 / **a=48(무장 FPV) 2.16** / **a=78(5인치) 3.51** vs ρ=1.77

**왜 중요한가** — 신청서의 1차 gate 판정 기준은 *"전 범위에서 FP ≈ 0 이면 즉시 피벗"* 이었다.
**FP ≈ 0 이 아니다.** 경계가 현실 위협 등급 한복판을 지나고, 위·아래가 모두 실재하는 기체 등급이다.
⇒ **N1 양성, Phase B 진입 조건 충족.**

## 7. 게이트가 잡은 것 — 전제 붕괴 3 + 버그 1 **[신규]**

**이번 기간의 실질.** 전부 학습 착수 *전*에 잡혔다.

### ① τ 를 grounding 하니 조향이 불필요해졌다
`τ = 0.4`(근거 없던 값)를 폐로 기하로 다시 풀면 0.15 → 게이트에서 **무개입이 12/12 전부 저지**.
명제 N 이 예측한 그대로(`w = 0.88 < ρ = 2.0`).
→ **"협력 조향이 필요하다"는 전제가 근거 없는 파라미터 위에 서 있었다.**
→ 해소: τ 를 under-modeling 했던 것. 분해(§3)로 복원.

### ② 콘의 축방향 밴드가 τ 와 3.6배 어긋나 있었다
`range_max = 29.847` vs τ_flight 동안 네트 병진 **8.22 m**.
**네트가 닿을 수 없는 15 m 표적을 "포획"으로 판정**하고 있었다.

### ★ 버그 — 베이스라인이 공짜 하드킬을 쓰고 있었다
`limiter_pressure = 1.0` 이 *"RESERVED — env receives-and-ignores"* 로 문서화돼 있었는데
M4 가 그 차원을 커밋 비트로 재사용 → **1스텝째에 전 limiter 하드킬 커밋**.
hold/ring/intercept 가 bit-identical 이 되어 게이트가 무의미한 값을 재고 있었다.
→ **못 잡았으면 논문의 모든 baseline 이 무의미했고, 50런 스윕 뒤에 발견했을 것.**

### ③ `kill_radius` 를 grounding 하니 조향 능력이 붕괴 — **미해소**
paired **n=48**: hold 와 ring 이 **0승 0패 48무**. 조향이 임무 결과를 하나도 안 바꾼다.
원인 — `kill_radius` 가 물리적으로 다른 두 양을 겸한다:

| | 물리량 | 옳은 값 |
|---|---|---|
| (1) | 치사·접촉 반경 | 0.75 m (grounding 이 맞음) |
| (2) | 공격자가 존중해야 하는 이격 | limiter 의 **τ_kill 내 도달집합** = `0.75 + ½a_limτ² + v_limτ` ≈ **3.9 m** |

**기존 2.0 보다 오히려 크다.** τ 때와 같은 종류의 과소 모델링.

**슬라이드 소재** — 3+1 을 한 줄씩. 제목은 *"게이트가 세 번 작동했다"*.
