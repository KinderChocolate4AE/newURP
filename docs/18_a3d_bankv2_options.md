## 0. 위치: 무엇이 끝났고, 무엇을 정하는가

- 파일럿2 판정 유보 후 외부 리뷰 전 항목 채택(09 (ss)): SBE = **action-necessary, forward-verified predecessor synthesis** 재정의 / bank admissibility **6조건**(기존 4: 전방 롤 tol·t=0 clean·robust≥0.9(10 fresh seeds)·클립 무접촉 + **⑤ demo 성공 ⑥ zero 규정마진 실패**, gap≥ε) / V-5′ = 동일-ep paired McNemar(vs zero) + δ_min / exit = paired action-induced arrival(값은 calibration 유도·선등록) / dev·sealed 번들 분리 / 추론 단위 = training seed.
- P0 진행: **0-a** 게이팅 att_speed 핀(V-4′)+parity+`cur` 라벨 픽스(`96b0326`) → **0-b** 균형 번들 = 30판 × witness{v16,v20,v24} × 스테이지{d1..d4}, dev/sealed 각 360판, seed족 전부 서로소(`c8cf70f`) → **0-c** 4-arm × 12셀 calibration 완료(`970b039`, 서버 1440판; §2). witness = A-3b robust bank 3본(x12v16·x16v20·x20v24; fresh-seed clean ≥ 0.9).
- 0-c 결론(09 (tt)/(uu)): **bank v1은 12셀 중 2셀만 admissible**(d1/v20·d3/v24) — 실패 모드 3종(선점 / 관성 공짜 / 지터·개방루프 취약)이 나머지를 죽임 → **bank v2 재생성 필요 확정**. 재생성 전에 생성식·측정기·수치를 고정하는 것이 본 결정 5건이다.
- 결정 5건((uu)의 설계 입력 (1)~(5)와 동일 순서): **0d-1** v24 관성 공짜 처리 / **0d-2** v16 가족 처리 / **0d-3** feasibility 오라클 정의 / **0d-4** admissibility 수치·표본 / **0d-5** 스테이지 σ 정책.

## 1. bank v1 생성식 폐형식 (결정의 물리 배경 — `shepherd/scripts/a3d_sbe_bank.py`)

리미터별 도착 프로파일: witness 슬롯 L*에 t=0, 속도≈0으로 도착. Δt=0.05, 적분기 v′=clip(v+aΔt), p′=p+v′Δt.
v0 ~ U[0.3,0.8]·(30·kΔt), 선형 감속 |a| = v0/(kΔt) ∈ [9,24](데모 상한 24 = 0.8·30), 도착 방향 = anchor(명목 링 자리)→L*, 콘 지터 ±15°.
스폰 오프셋(슬롯까지 거리) **R = v0Δt(k−1)/2**, zero-action(등속 coast) 시 t=0 오버슛 **O = v0Δt(k+1)/2** — 코드 명세로부터의 폐형식 유도(실측 아님):

| k (스테이지) | v0 범위 [m/s] | R 스폰 거리 [m] | O zero 오버슛 [m] |
|---|---|---|---|
| 1 (d1) | 0.45–1.2 | **0 (슬롯 위 스폰)** | 0.045–0.12 |
| 2 (d2) | 0.9–2.4 | 0.023–0.06 | 0.068–0.18 |
| 4 (d3) | 1.8–4.8 | 0.135–0.36 | 0.225–0.60 |
| 8 (d4) | 3.6–9.6 | 0.63–1.68 | 0.81–2.16 |

구조적 함의 2가지: ① **k=1은 항상 슬롯 위 스폰**(R≡0) — 창이 넓은 witness(v24)에선 스폰이 이미 clean = 선점이며, v0·방향 재추첨으로 구제 불능 ② 오버슛 O ∝ v0 — **"운동량 예산 축소"는 저k에서 오버슛을 줄여 공짜를 늘리는 방향**일 수 있음(0d-1 옵션 A의 방향성 주의; 축소가 아니라 셀별 재보정으로 읽어야 함).

## 3. 0d-1 — v24 계열 관성 공짜 처리

**문제**: v24(가장 넓은 창 가족)에서 무행동이 d2 .70·d4 .30 포획 — "행동 없이 성공하는 시험"은 action-necessity(⑥) 위반. d1/v24는 선점으로 arrival 시험 자체가 성립 안 함.

**기전(라벨 구분)**: d1 = R≡0 구조 선점(**폐형식 확정**, §1) / d2 = 오버슛 7–18cm가 v24의 넓은 공간·시간 창 안(**유도**) / d4 = 장기 coast 중 en-route 창 교차(**가설** — coast가 슬롯을 (k+1)/2 스텝 조기 통과, 근접 구간에서 teacher 발사 추정). **검증 로그 제안**: bank 검증기에 zero-arm 발사 시점 히스토그램 추가(공짜 기전 판별; 어느 옵션 채택이든 무비용 동승).

| 옵션 | 내용 | 기대 | 리스크·비용 | 사전등록 영향 |
|---|---|---|---|---|
| **A 생성식 draw-필터 + 운동량 재보정** | 6조건을 **draw-level rejection**으로 생성기에 내장: 각 draw에 ⓐ 스폰 비-clean ⓑ zero-fail(CRN n_z seeds, 0d-4) 통과분만 수록 + v0 범위는 셀별 재보정(§1 방향성 주의). 셀 최소 수록 draw 수(제안 8/12) 미달 = 셀 탈락 | d4/v24 구제 유력(draw의 ~70%가 이미 zero-fail → 필터로 수록분 정화). d2/v24는 부분 구제 불확실(O 상한 18cm vs 창 폭) | 필터 후 잔존 draw 부족 → 셀 자연 탈락(=C로 수렴). 과도 필터 = 스폰 다양성 축소(D5 전이 재료 감소). 구현 반나절 + 재생성 수 분 | V-1에 필터 조항 추가. 6조건의 적용 수준을 draw로 내림 = **엄격화**(문턱 이완 아님) — "synthesis" 재정의 취지 정합 |

## 4. 0d-2 — v16 가족 처리 (재리파인 vs 폐기)

## 5. 0d-3 — feasibility 오라클: 개방루프 demo 유지 vs 폐루프 추적기 승격

**문제**: v20 demo 감쇠(.83→.53→.47→.33)에서 "k가 길수록 셀이 어렵다"와 "개방루프 재생이 σ·fresh CRN 지터를 못 버틴다"가 교락. admissibility ⑤(demo 성공)의 측정기가 개방루프면 **회복 가능한 셀을 잘못된 이유로 버림**(커버리지 손실 + '불능' 오기록).

| 옵션 | 내용 | 기대 | 리스크·비용 |
|---|---|---|---|
| **A 개방루프 유지** | 정의 불변, 구현 0 | 문구 최소 | 교락 방치 — v20 d2+ 3셀·v16 전부가 "불능"으로 기록될 수 있음. demo=구성 상한 리그 해석도 과소 |
| **B 폐루프 추적기 승격** | **demo_cl = clip(a_demo + K_p(p_demo−p) + K_d(v_demo−v), \|a\|≤30)** — 정책과 동일 행동공간 제약. admissibility ⑤⑥의 "demo" = demo_cl로 재정의, 개방루프 demo는 진단 열로 병기(리그 연속성). 게인 = 전역 1쌍, dev에서 coarse 선택 후 고정(셀별 튜닝 금지). 추적기는 특권 참조(데모 궤적)를 쓰는 **시험 도구** — 정책 스캐폴드 아님, 학습 경로 미접속 | 교락 해소 + 학습 정책(폐루프)과 시험 선별 오라클의 클래스 정합. 회생 후보: v20 d2/d3/d4·v16 일부(측정으로 판가름) | "성공 기준 이완" 외관. 완화: ① 문턱 .8 불변 ② 양 열 병기 ③ **V-5′ 판정은 zero 대비 paired — 오라클과 무관**(admissibility = 시험 선별이지 성공 판정 아님) ④ 지금(학습 전·결과 미견) 고정 = 골대이동 아님. 구현 반나절 |
| **C 병기만** | 둘 다 측정, 선별은 개방루프 유지 | 교락 데이터 확보 | 선별에 미반영 — 회복 가능 셀은 여전히 사망. 반쪽 |

**권고: B.** 근거 보강: 외부 리뷰 문면 자체가 "demo/**oracle** 행동열로는 성공하고"(수록 조건)·"가능하면 oracle"(calibration arm 권고)·"Feasibility: demo/oracle은 성공하는가"(체크리스트)로 **oracle-급 feasibility arm을 이미 상정** — 개방루프 한정은 우리 구현 선택이었다. 단 ⑤ 측정기 정의 변경이므로 0-e 사전등록에 명시(demo≥.8 예시가 개방루프 전제로 읽혔음을 함께 기록).

## 6. 0d-4 — admissibility 최종 수치 + zero-마진 CRN 표본
