# 외부 리뷰 요청 3 — 성형 채널이 무력하다. 어디를 고쳐야 하는가

> 그대로 붙여 넣어 쓴다. 리뷰어는 리포·이전 대화 접근이 없으므로 자기완결적으로 썼다.

---

당신은 다중 에이전트 강화학습 논문의 **비판적 외부 리뷰어**다. 연구의 중심
질문이 **측정 불가능한 상태**임을 오늘 발견했고, 무엇을 고쳐야 하는지에 대해
두 입장이 대립한다. 어느 쪽인지 판단해 달라.

동의만 하는 답은 쓸모가 없다. §6 의 두 입장 **각각을 실제로 공격**해 봐라.

## 1. 시스템과 **동결된 계약**

last-mile 대드론 협력 방어. 회랑을 침투하는 반응형 스크립트 공격자 1 기를
상대로:

- **limiter 4 기** — 셰이핑 기동으로 공격자의 **도달가능집합을 압축**. 학습 대상
- **finisher 1 기** — 그물 발사(탄 K=1, 비가역). **위치 고정**. 현재는 규칙 기반
  발사(하이브리드 확정)

성공 = **비손실 포획**(파괴 아님). 이게 논문의 스파인이다.

**계약은 동결돼 있다** (학습 편의로 변경 금지가 비준 사항):

```
관측    63-dim 공유 full-state (CTDE), limiter 공유 정책 + one-hot ID
행동    limiter = 가속(3) + 압력비트(1)   /   finisher = 조준축(3) + 발사(1)
보상    공유 J = 연속 셰이핑 headline(Δv_shot)
               + λ1·clean-crossing(1.0) − λ2·낭비발사(1.0) − λ3·limiter 손실(0.5)
게이트  v_soft >= 0.9 ∧ non-boxed
기하    limiter 링 x=8 (반경 5), finisher x=2 고정, 공격자 스폰 x≈24.6
        공격자 속도 ≈ 26 m/s, limiter a_max 15.4, kill_radius 0.75, dt 0.05
```

**보상에 이미 조밀 항이 있다** (Δv_shot headline). 희소 보상 문제가 아니다.

## 2. 확립된 것

25 런(500k) 규모 사전등록 실험에서:

1. **학습이 손튜닝 기준선을 못 넘는다.** 무개입 편대+규칙발사 = 0.182 /
   학습편대+규칙발사 = 0.187 / 학습발사 = 0.137 / 둘 다 학습 = 0.072.
2. **finisher 결손은 조준축**이다. 발사 게이트 개방률 해석적 0.043 대 학습 0.026.
   행동복제로 97 % 회복되지만 RL 이 지운다. 상시 BC 항으로 격차의 24.5 % 유지.
3. **탐색 신호가 없다.** 무작위 탐색 수익 std = 종말항의 **0.32 %** (실측).

## 3. ★ 오늘의 발견 — 성형 채널이 **구조적으로 무력**하다

`ring`(손설계 성형 컨트롤러)과 `hold`(아무것도 안 함)를 60 판 돌렸더니
**라벨 카운트가 비트 단위로 동일**했다. 파보니:

```
교전 길이        중앙 24 스텝 = 1.23 s   [16 / p90 41 / 62]   (에피소드 상한 160)
공격자 통과      거리 22.6 ÷ 26 m/s = 17 스텝
limiter 실제이동 중앙 6.83 (p90 9.80)     이론 최대변위 11.55
종료 시 최근접   7.02                     ← kill_radius 0.75
```

limiter 는 **움직인다**. 그런데 공격자에 근처도 못 간다 — 반경 5 링에서 출발해
1.2 초 안에 축까지 닫고 그 순간에 맞춰 있어야 하는데 물리적으로 안 된다.
(감속형 단순 컨트롤러 brake·lam20 도 `hold` 와 동일했다. limiter 가 v=0 으로
스폰하므로 감속기는 아무 일도 안 한다.)

**이 하나가 전부를 설명한다:**

```
학습편대 ≈ 무개입          학습이 못 한 게 아니라 어떤 편대도 못 한다
손설계 성형 ≡ 무개입       위와 같은 사실
"성형 필요" 구간 = 전 팔 0  손튜닝 천장 포함. 정의상 limiter 가 일해야 하는
                            판인데 일할 수가 없다 -> 구조적으로 못 이기는 칸
"RL 불필요" 실측           단순 컨트롤러가 학습을 이긴 것도 같은 사실
```

## 4. 비준 기록이 이미 말하고 있던 것

이 프로젝트는 작년 7월에 이미 다음을 문서로 정해 놨다.

- *"nominal→shell **접근 회랑**의 물리적 실존 = **미검**"* — 한 번도 검사된 적
  없는 열린 질문.
- *"23 스텝 창 내 fire-eligible 기하 생성은 오라클도 미검사 (witness
  p_feas ~2.4e-3 → **부재 가능성 상당**; **부재 시 '미션 설계 과잉 난도' 자체가
  발견**)"*
- 회랑 프로브의 분기: *"존재 → corridor-aware 개발 / **협소 → geometry·reward·
  obs·planning 개선** / 부재 → mission design 재설계 — engineering feedback이지
  MARL 실패 아님"*
- 우선순위 ① = *"A2 하 접근 회랑 존재·구조"*

즉 오늘의 측정은 **비준된 최우선 질문에 대한 직접 증거**다. 다만 오라클 탐색이
아니라 손설계 컨트롤러 두 개(ring·intercept)로 잰 것이라 상한이 아니다.

## 5. 두 입장

### 입장 (가) — 도달성이 먼저다. 시나리오를 고쳐야 한다

1.2 초에 유계 가속 물체가 갈 수 있는 곳은 정해져 있다. limiter 의 도달가능집합이
공격자의 영향권과 **교차하지 않으면** 어떤 정책류·어떤 보상·어떤 행동
파라미터화도 0 을 0 으로 만든다. 학습 질문은 채널 용량이 0 이 아님을 먼저
보인 뒤에야 의미가 있다.

손잡이: 링 반경 축소 / 공격자 감속 / 스폰 거리 확대 / limiter a_max 상향.

### 입장 (나) — 시나리오 조정은 겉치레다. **행동 구조와 보상 구조**가 진짜다

**연구자 본인의 의견이며, 이 요청의 핵심이다.**

- **`ring` 이라는 구조를 우리가 정해 둔 것 자체가 문제일 수 있다.** "협력 성형"
  이 어떻게 생겼는지에 대한 인간의 추측일 뿐이고, 그 추측이 임의적이면
  *"학습 ≈ 스크립트"* 는 협력의 학습가능성에 대해 아무 말도 안 한다.
  둘 다 못 찾았다는 뜻일 뿐이다.
- **행동 파라미터화가 틀렸을 수 있다.** 지금은 스텝별 3 차원 가속이다.
  협력 성형은 시간적으로 확장된(temporally extended)·관계적(relational) 행동
  — 역할 배정, 진형 목표, 차단 지점 — 이라야 표현되는 것 아닌가.
- **보상 구조가 틀렸을 수 있다.** 조밀 항 Δv_shot 이 이미 있는데 작동하지 않는다.
  단일 대리량이 협력에 대한 크레딧을 못 나른다는 신호일 수 있다.
- 링 반경을 줄이는 것은 **문제를 쉽게 만드는 것**이지 방법을 개선하는 것이 아니다.
  그렇게 얻은 양성은 무엇을 주장하는가?

## 6. 답해 달라

1. **(가)와 (나) 중 무엇인가.** 조건부라면 조건을 명시해라. 특히: 도달성 결손이
   **운동학적 사실**이라면 행동·보상 구조 변경이 그것을 뒤집을 수 있는 경로가
   존재하는가? 있다면 구체적으로 어떤 기전인가?
2. **(나)의 첫 항목을 판정해 달라** — 손설계 `ring` 을 성형 기준선으로 쓰는 것이
   비교로서 유효한가? *"학습 ≈ 손설계 성형"* 에서 무엇을 결론낼 수 있고 무엇을
   결론낼 수 없는가? 대안 기준선(오라클 궤적 최적화·MPC·역방향 도달가능집합)이
   필수인가?
3. **행동 파라미터화.** 스텝별 3D 가속이 4 기 협력 성형에 부적합하다는 주장은
   얼마나 강한가? 이 문제에서 옵션/스킬/진형 목표/관계적 행동이 실제로 필요한
   근거가 있는가, 아니면 low-level 로도 충분하고 문제는 다른 데 있는가?
4. **보상 구조.** 조밀 셰이핑 항(Δv_shot)이 있는데 무작위 탐색 수익 std 가
   종말항의 0.32 % 다. 이건 (ⓐ) 대리량이 잘못 골라졌다 (ⓑ) 크레딧 배분이
   문제다(4 기 공유 보상) (ⓒ) 조밀 항의 스케일이 잘못됐다 (ⓓ) 애초에 신호가
   존재하지 않는 기하다 — 중 무엇을 시사하는가? 가르는 측정은?
5. **시나리오를 바꾸면 무엇을 잃는가.** 운용점을 바꾸면 기존 25 런과의 비교가
   끊기고, "쉽게 만들어서 얻은 양성" 이라는 공격면이 생긴다. 그럼에도 바꿔야
   한다면, **바꾼 것이 정당하다는 것을 무엇으로 보이는가?**
6. **최소 실험 하나.** (가)든 (나)든, 지금 상태에서 **가장 값싸게 두 입장을
   가르는 단일 실험**은 무엇인가? 런 수와 판정 지표까지 구체적으로.
   (참고: 새 RL 학습 없이 도는 오라클·해석적 실험이 훨씬 싸다.)

## 7. 형식

- 결론 먼저, 그다음 근거.
- 확실한 것과 추측을 구분해 표시해라.
- 제시된 수치 중 **결론을 지탱하기에 부족한 것**을 지적해라.
- (가)와 (나) 각각에 대해 당신이 시도한 **가장 강한 공격**을 함께 적어라.
  둘 다 부분적으로만 맞다면 그 경계가 어디인지 말해라.
