# 거시 상황 — 무엇이 확립됐고 무엇이 비어 있나

**2026-08-05 · docs/49 본런(10 런)이 도는 중에 쓴다. 결과를 보기 전이다.**

결과를 본 뒤에 쓰면 무엇을 알고 있었는지와 무엇을 알게 됐는지가 섞인다.
그래서 진행 중에 끊어 적는다. §5 의 판단도 지금 시점의 판단이고, 본런이
뒤집으면 뒤집힌 대로 남긴다.

## 1. 확립된 것 — 인과 사슬이 닫혔다

### 1.1 사슬

```
파일럿:  학습이 hold 보다 나쁘다               <- 해석 불가였다
   |
   +-- 어느 역할인가?        LS ≈ SS,  SL −0.045            -> 발사
   |
   +-- 발사의 무엇인가?      [A] 관측은 충분하다  (AUC 1.000)
   |                         [B] 발사 비트는 무죄  (게이트를 본다)
   |                         [C] 조준이 결손      (개방률 0.61x)
   |
   +-- 왜 못 배우나?         보상 기울기 부재
   |                         (무작위 탐색 수익 std = 종말항의 0.32 %)
   |
   +-- 정말 그런가?          BC 한 방에 스크립트의 97 % 회복
```

### 1.2 각 링크의 근거

| 링크 | 무엇을 쟀나 | 수치 | 출처 |
|---|---|---|---|
| 1차 판정 | SHAPING 무력화율 | 세 팔 전부 **0/861**. 풀링 0/2583 → 상한 **0.15 %** | docs/48 §7 |
| 역할 귀속 | 전체 무력화율 | SS 0.182 / LS 0.187 / SL 0.137 / LL 0.072 | docs/48 §8 |
| 상호작용 | 가법 예측 대비 | 예측 0.141 vs 실제 0.072 → **−0.069** | docs/48 §8 |
| [A] 관측 | `clean_crossed` 예측 | 단일 차원 `obs[60]` 로 AUC **1.000** (홀드아웃 정확도 1.000) | docs/48 §10 |
| [B] 발사 | 게이트 인지 | AUC 0.57~0.995, 세 런은 `E[p\|교차] ≈ 1.0` | docs/48 §11 |
| [C] 조준 | 게이트 개방률 | 스크립트 0.0430 → SL 0.0262 / LL 0.0061~0.0176 | docs/48 §12 |
| 기울기 | 탐색 수익 분산 | 무작위 탐색 std = 종말항의 **0.32 %** | `signal_audit` |
| 회복 가능성 | 교사 축 ← 관측 | **선형** 회귀 코사인 0.9984, 각오차 중앙 **1.65°** | docs/49 §1.1 |
| 회복 실측 | BC 직후 개방률 | 0.0441 (스크립트 0.0455 의 **97 %**) | docs/49 §7 |

**순서가 일치한다** — 개방률 1.00x / 0.61x / 0.23x 에 성적 1.00x / 0.75x / 0.40x.
세 점뿐이지만 방향과 크기가 같다.

### 1.3 ~~부수 결과 — LL 의 하드킬~~ ★ 철회 (2026-08-05)

여기 *"LL 만 비손실 0.80 ... 4 판이 하드킬 ... 정책이 스파인을 깬다"* 라고 썼고,
이 문서에서 **가장 논문다운 문장**이라고까지 적었다. **틀렸다.**

`nondestructive_frac = k/max(k+HK, 1)` 이고 LL 시드 3 은 무력화가 **0/300** 이다.
`0/1 = 0` 인 퇴화값이 평균에 섞여 0.80 이 됐을 뿐, **하드킬은 한 건도 없다**
(무력화가 0 이면 하드킬도 0 이다). docs/48 정정 9 참조.

남는 사실은 두 개뿐이다: `LL` 이 압도적으로 나쁘고(0.072), 시드 하나가 완전히
붕괴한다(0/300). 후자는 하드킬 도피가 아니라 **학습 실패**다.

### 1.4 무엇이 용의선상에서 빠졌나

BC 가 한 방에 붙었다는 사실이 여러 가설을 한꺼번에 죽인다.

```
표현 부족        아니다 -- 같은 네트로 코사인 0.9985 (각오차 3.13°) 에 도달
관측 부족        아니다 -- 교사 축 입력이 전부 관측에 있다 (특권 정보 아님)
탐색 노이즈      아니다 -- aim_audit 은 결정론 평균을 썼다. 평균 자체가 나쁘다
발사 타이밍      아니다 -- [B] 가 게이트 인지를 확인했다
```

남은 것은 **최적화**뿐이다. 이 소거가 사슬의 실질적 결론이다.

## 2. ★ 비어 있는 것 — 논문의 중심

**주제는 협력 성형(편대)인데, 정밀 진단은 전부 finisher 에 들어갔다.
finisher 는 조연이다.**

편대에 대해 가진 근거는 사실상 하나다.

| | 전체 무력화 | FREE | BAND_AIM |
|---|---|---|---|
| SS (hold) | 0.182 | 0.448 | 0.010 |
| LS (학습 편대) | 0.187 | 0.441 | 0.003 |

`LS ≈ SS` -- "편대 학습의 순이득이 측정되지 않는다". 그런데 이건

- **한** 운용점 (w_kill 0.5, A2, LAM_REF)
- **한** 알고리즘 (PBRS 없는 MAPPO)
- 발사 채널이 **정상인** 조건
- 1차 지표로는 0/861 (즉 상한만 걸린 음성)

에서의 한 줄이다. **"협력 성형은 학습되지 않는다"를 논문 주장으로 쓰기엔
얇다.** 그리고 docs/48 §8.3 에서 PBRS 를 미룬 판단은 그때는 옳았지만
(발사가 망가진 채로 편대를 손대면 또 해석 불능) 그 결과 편대 축은 **아직
한 번도 제대로 물어진 적이 없다**.

지금 도는 10 런이 성공해도 이 공백은 안 메워진다. 조준을 고쳐야 비로소
편대 질문을 **처음으로** 물을 수 있는 상태가 된다.

## 3. 반복되는 병목 — 알고리즘이 아니라 측정 설계

세 번 같은 모양으로 걸렸다.

| # | 무슨 일 | 대가 |
|---|---|---|
| 1 | `hold` 가 무개입이 아니라 **해석적 발사 규칙이 붙은** 기준선이었다 | docs/48 이 통째로 필요해졌다 (15 런) |
| 2 | `H_fin` 이 **검정 불가능한** 가설이었다 (SL 은 커밋 비트가 구조적 0) | 1차 판정의 1/3 이 날아갔다 |
| 3 | "개방률 → 성적" 이 **가정**이었다 (관측 3 점의 순서 일치) | ★ 2026-08-05 해소 — docs/49 §8.3 |

1·2 는 이미 났고 기록했다. **3 은 해소됐다** -- docs/49 본런에서 개입 두 방향이
게이트와 성적을 **같은 방향·같은 크기**로 움직였다 (BCa 게이트 +24.5 % / 성적
+20.6 %, BCw −8.6 % / −10.3 %, 시드 부호일치 4/5). 5 시드라 유의성은 주장하지
않지만 매개는 붙는 쪽이다 (docs/49 §8.3).

**다섯 번째 (2026-08-06).** 두 손설계 컨트롤러가 `hold` 와 같은 결과를 냈다는
사실에서 *"성형 채널이 구조적으로 무력하다"* 를 유도했다. 도달가능집합 인증을
돌려 보니 `SHAPING` 판의 **111/122** 에서 접촉이 가능했다 -- **반증**. docs/52
에서 공식 철회했다. 앞의 넷이 *무엇을 재는지* 와 *잰 값을 어떻게 읽는지* 의
문제였다면, 이번은 **증거의 강도를 주장의 강도에 맞추지 못한** 문제다.
"구조적으로 / 물리적으로 불가능" 은 인증을 만든 뒤에만 쓴다.

**네 번째 (2026-08-05).** `nondestructive_frac` 의 0/0 퇴화값(§1.3)을 하드킬
비율로 읽었다. 앞의 셋은 *무엇을 재는지* 를 잘못 정한 것이고, 이건 *잰 값을
어떻게 읽는지* 를 틀린 것이다. 집계 평균에서 원인을 역산할 때는 분모가 0 이
될 수 있는지부터 본다.

기록해 둘 것: 이 프로젝트의 실패는 매번 **무엇을 재는지 잘못 정한 데서**
났지 학습이 안 돌아가서 난 게 아니다. 다음 설계도 같은 자리를 먼저 봐야 한다.

## 4. 구조적 한계 (지금 설계로는 못 넘는 것)

- **교사가 천장이다.** BC 는 스크립트 조준을 못 넘는다. 최선이 "해석적
  규칙만큼" 이라 *"학습이 손설계를 넘었다"* 는 주장은 이 경로로 안 나온다.
  넘으려면 `SL-BCa` 의 RL 항이 해야 하는데 λ 고정이라 분리 측정이 안 된다.
- **단일 운용점.** 전부 w_kill 0.5 · A2 · 위협 랜덤화 ON. 강건성 스윕이 없다.
- **기준선 n 불일치.** SS 는 n=500, 학습 팔은 n=861. 같은 표에 올리되 같은
  실험은 아니다.
- **off-policy 진단.** `--aim` 은 hold 편대 · 발사 off 에서 잰다. SL 계열은
  분포가 맞지만 실제 성적은 발사가 켜진 궤적에서 난다.

## 5. 갈림길 (★ 판단 — 측정이 아니다)

10 런이 끝나면 **남은 시간을 어디 쓸지**가 실제 결정이다.

| 분기 | 조건 | 다음 | 비용 |
|---|---|---|---|
| (A) 편대 재개 | 조준 회복 | PBRS 등으로 협력 질문을 **처음** 제대로 묻는다 | 새 설계 + 15 런 이상 |
| (B) 여기서 쓴다 | 조준 회복 | "역할 분리 진단 프로토콜 + 기전 있는 null" 로 낸다 | 강건성 보강만 |
| (C) 자동 수렴 | 둘 다 미달 | (B) 로 간다. 단 §3.4 대로 관측 정규화·용량·스케일로 내려감 | — |

**지금 데이터에 가장 정직한 형태는 (B) 다.** 기여가 둘 있다:

1. **방법론** -- 역할을 하나씩 스크립트로 고정해 학습 열세를 귀속하는 프로토콜.
   `hold` 가 무개입이 아니라는 것을 발견한 과정까지 포함해서.
2. **기전 있는 음성 결과** -- "종말 유도가 해석적으로 완벽하고 보상 기울기가
   없으면 end-to-end RL 은 조준을 못 배우고, 못 배운 조준이 발사 기회를 없애고,
   기회가 없으면 정책은 스파인을 깨는 하드킬로 도망간다."

(B) 에서 협력 주장은 **한계 절로 내린다** -- 주장하지 않고, 왜 아직 못 묻는지를
적는다. §2 를 숨기지 않는 것이 (B) 의 조건이다.

(A) 는 논문 중심을 채우지만 새 실험 설계 + 배치가 필요하다. **마감이 이
결정을 지배한다.**
