## 0. 결론 세 줄

```
1. tau_deploy 는 앵커링 가능하다 — 항력 포함 시뮬의 **병진** 시간(붕괴 시간 아님)
2. 현행 tau = 0.4 는 임의값이 아니었다 — 논문 baseline 의 실측치 0.398 과 일치
3. tau 와 r_net 은 독립 축이 아니다 — 같은 발사 설계 (theta, v, m) 의 두 출력이다
```

3번이 방법론적으로 가장 중요하다. **둘을 독립 sweep 하던 계획은 틀렸다.**

---

## 1. 왜 앵커링이 가능한가 — 병진 vs 붕괴

`docs/n1_net_grounding.md` 의 honest closure 는 *"temporal is not achievable with this model"* 이었다. 그런데 그 판정의 근거는 **hang time**(네트가 5% 면적으로 붕괴하기까지)이고, 실패 원인은 *"flat-init (no folded→opening transient) + no wrapping/entanglement → 네트가 숨쉰다(0.66 s 붕괴 후 재개방)"* 였다.

**`tau_deploy` 는 다른 물리량이다.** 발사부터 유효 면적 도달까지의 **중심 병진** 시간이고, 이는 항력 하 탄도 문제이지 얽힘 동역학이 아니다. 붕괴 모델의 한계가 병진 추정을 무효화하지 않는다.

그리고 코드에 이미 그 계측기가 있다 — `net_forward.travel_to_time` / `simulate()` 의 `cum_travel` 시계열.

## 4. ★ 방법론 정정 — τ 와 r_net 은 독립 축이 아니다

둘 다 **같은 발사 설계 (θ, v, m) 의 출력**이다. 빠르게 쏘면 τ 가 줄고(포획 기하 유리) 동시에 전개 면적도 커진다. 독립 격자로 sweep 하면 **물리적으로 존재하지 않는 조합**을 훑게 된다.

```
잘못된 축   tau in [0.15, 0.40]  x  r_net in [1.5, 2.5]     <- 독립 격자 (물리적으로 불가능한 조합 포함)
올바른 축   발사 설계점 in {Baseline, A, B, C, D*, E*, F}   <- 7점 이산, 각각 (tau, r_net) 쌍을 산출
```

**논문이 이미 평가한 7개 설계점을 sweep 축으로 쓴다.** 임의 격자보다 훨씬 방어 가능하고, "이 설계면 이 위협까지 막힌다"는 결과가 곧바로 나온다.

이건 `docs/30 §5` 의 `(λ × Pk)` 평면 계획과 `docs/32` sweep 표에 반영해야 한다.

## 6. 남은 불확실성과 캐비앗 (정직하게)

1. **`engage_dist = 20 m` 은 논문 값이 아니다.** `net_forward.py` 주석: *"pre-fixed engagement travel distance... NOT tuned per-config"*. 게다가 `rho_air` 가 **이 거리에서** baseline 면적이 맞도록 보정됐다. ⇒ τ 는 `engage_dist` 에 비례하므로 이것이 **최대 잔여 불확실성**이다. 논문이 S_NP 측정 거리를 명시하는지 PDF 확인이 필요(Human-lane).
2. **비-baseline 설계의 `r_net` 은 보수적**(문서화된 한계 2: config spread ~23% 과소예측). 실제 A 는 back-solve 로 2.64 m 이나 시뮬은 2.42 m. **보수적 방향이라 안전하다.**
3. **hang time 은 논문 값만 쓸 수 있다.** 빠른 발사가 포획 기하는 유리하게 하지만 유지 시간을 줄인다(A: 1.30 s vs F: 2.76 s). **"잡았는데 빠져나간다"** 는 현재 모델에 없는 결과이며, T 를 쓰려면 새 종료 조건이 필요하다 — future work.
4. **`S_UAV = 2 m²` 는 우리 위협보다 훨씬 크다** (7" FPV 는 ~0.1–0.3 m²). 논문의 coverage `C` 는 큰 표적 기준이므로 우리 쪽에 **유리한 방향**의 보수성이다. 기하(`r_net`)에는 영향 없고 확률 해석에만 영향.
5. **`kill_radius` 는 여전히 근거 없음** — 3제곱 지렛대인데 이 논문으로는 앵커링 불가(네트 논문이지 탄두 논문이 아님).
