# 외부 리뷰 요청 7 — P95 RED: TRAIN 반응성 taxonomy 재사전등록 (3안 비교)

> 그대로 붙여 넣어 쓴다. 리뷰어는 리포·이전 대화 접근이 없으므로 자기완결적으로 썼다.

---

당신은 다중 에이전트 강화학습 논문의 **비판적 외부 리뷰어**다. 우리는 학습용
위협 분포를 사전등록·동결했고 (9셀 = 반응성 3층 × 속도 3층), 학습 전 마지막
분포 검증 게이트(P95)가 **사전등록된 판정식 그대로 RED** 가 났다. 규율에 따라
성능 지표는 열람하지 않았고, 기준 완화·파라미터 상향 없이 멈췄다. 이제 셀
taxonomy 를 재사전등록해야 하는데, **어느 안을 골라도 "결과를 본 뒤의
재설계"라는 오염을 안고 간다.** 이번 요청의 핵심:

> **세 재설계안 중 어느 것이 사전등록 규율의 훼손을 최소화하면서
> taxonomy 의 semantic validity 를 복원하는가 — 그리고 우리가 그 선택을
> 정당화하려고 쓰는 논리 중 어디가 사후 합리화인가?**

동의해 주는 답은 쓸모가 없다. §5 의 주장 다섯을 각각 무너뜨려 봐라.

## 1. 시스템 (요약)

무인기 last-mile 방어 시뮬레이션 (3D 질점, dt 0.05 s, 300 m 스케일):

- **공격자 1기** (scripted): 표적 정조준 전진 + 횡 jink + **반응 채널** —
  감지 반경(sense_range) 안 limiter 들이 가리는 각도 합집합에서 가장 넓은
  빈 호로 route_gain×a_lat 횡가속 (angular-gap 회피). 종축 속도 프로파일
  (cruise / sprint / sprint+slowdown). 전 항이 단일 |a| ≤ a_max budget 을
  경쟁 (클리핑 = 계약의 일부로 명문화됨, 스프린트 구간 클립 36–76% 실측).
- **limiter 4기** standby (자산 주위 8–16 m), 현 측정은 전부 부동(hold).
- 능력 축 (속도 8–30, 가속 11–78)은 별도 브래킷으로 draw — taxonomy 와 곱.

## 2. 동결된 taxonomy 와 P95 계약 (결과 전 사전등록, 비준·동결됨)

**반응성 3층** (에피소드마다 셀 draw 후 셀 내 uniform jitter):

| 층 | route_gain | sense_range [m] |
|---|---|---|
| weak | U[0.2, 0.4] | U[15, 25] |
| medium | U[0.4, 0.6] | U[25, 35] |
| strong | U[0.6, 0.8] | U[35, 45] |

**P95 (realized-reactivity audit)**: base 30판 각각에서 능력·속도 프로파일·
스폰·standby·jink 위상 전부 고정, 반응 축(route_gain·sense_range)만 세 층
범위로 재사상한 paired 3중 비교 (같은 uniform u — 축 내 상대 위치까지 동일).

- **primary (하나로 고정)**: R_route = (1/T_active) Σ_{t∈active}
  |a_route,realized(t)| — realized = 클립 후 총가속의 route 방향 사영,
  active = route 요청 > 0 인 스텝.
- **판정 (결과 전 고정)**: 30판 R_route 의 **평균과 중앙값 둘 다**
  weak < medium < strong. 인접 층 차이 ≤ 0 → 해당 층 경계 미확정 →
  **셀 경계 재사전등록** (성능 안 본 상태에서).
- 등재된 보조 진단: realized/requested 비 — "strong 에서 역전될 수 있어
  primary 로 쓰지 않는다" (saturation 예고).

## 3. P95 결과 (RED) + 진단 — 전부 기하 관측, 성능 지표 미열람

```
R_route   평균:  weak 18.08 < medium 19.77 > strong 18.97   ✗
          중앙값: weak 18.67 < medium 21.51 > strong 20.37   ✗
per-episode medium > strong 역전: 14/30
```

진단 수치 (같은 P95 기록에서):

```
T_active (반응 활성 스텝 수):   weak 27.1 → medium 39.5 → strong 65.0   (단조 증가)
Σ|realized| (총 반응량):        weak 508  → medium 771  → strong 1250   (단조 증가)
speed regime 별 평균 R_route:
  cruise           15.8 < 17.3 < 18.3     (단조 — 유일하게 성립)
  sprint           20.1 < 21.6 > 20.6     (역전)
  sprint_slowdown  18.2 < 20.1 > 18.0     (역전)
```

**해석 (우리 서사 — 공격 대상)**: strong 은 sense_range 가 커서 더 일찍·더
멀리서 반응을 시작한다 (T_active 2.4배). 총 반응량은 층 순서와 일치하지만,
primary 가 **활성 스텝 평균**이라 원거리 저강도 활성 구간이 분모를 희석한다.
역전은 cruise 에선 없고 종축 가속 수요가 겹치는 sprint 계열에서만 발생 —
budget 경쟁(포화)이 교락. 즉 "반응 기전은 층 순서대로 강해지는데, 라벨을
검증하려고 고정한 지표가 그 순서를 복원하지 못한다."

## 4. 재사전등록 3안 (비교 — 우리는 아직 고르지 않았다)

### (a) 셀 경계 재조정 — 사전등록이 명시한 구제책

medium/strong 경계를 옮기거나 (예: strong 의 sense 범위를 낮춰 T_active
희석 완화), route_gain 과 sense 의 결합을 재배치한다.

- 지지: 사전등록 문서가 지정한 구제 경로 그대로 — 규율상 가장 방어 가능.
- 반대: 역전 driver 가 sense→T_active 희석이라면 경계 이동은 대증요법이다.
  strong 의 sense 를 낮추면 "strong = 조기 감지" 의미가 죽고, 순서가 나올
  때까지 경계를 반복 이동하면 **판정 통과를 위한 탐색 = 사후 튜닝**과
  구분이 어려워진다 (몇 번까지 허용되는가?).

### (b) 층 축 재구성 — 반응 층을 route_gain 단독으로, sense 는 공통축으로

층 정의에서 sense_range 를 빼서 공통 nuisance 축 (예: 전 층 U[15, 45])으로
내리고, 층은 route_gain 만으로 가른다.

- 지지: 희석을 만드는 축을 층 정의에서 구조적으로 분리 — 대증이 아니라
  기전 대응. "반응 강도" 라벨의 의미가 route authority 하나로 깨끗해진다.
- 반대: taxonomy 의 의미 자체가 바뀐다 ("반응성 = 감지+회피 결합" →
  "회피 gain 단독"). 조기 감지 축의 체계적 변주가 층에서 사라져 학습이
  경험하는 분포의 구조가 달라진다 (sense 는 여전히 랜덤이지만 층 균형
  보장이 없어짐). 분포 hash·P92/P93 재실행 필요.

### (c) primary 재정의 — 지표를 데이터 기전에 맞춘다

R_route 를 총량 Σ|realized| 또는 공통 근접창(예: d_asset ≤ 15 m = 전 층
sense 하한 공통 구간) 평균으로 재정의한다. 현 데이터에서 총량은 이미 단조.

- 지지: §3 진단과 가장 정합적 — 층의 실제 기전(총 반응량 증가)을 재는
  지표로 교체하는 것이므로 taxonomy·분포·게이트 재실행이 불필요.
- 반대: **결과를 본 뒤 판정 지표를 바꿔 PASS 를 만드는 것**과 관측상
  구분 불가 — 사전등록 규율의 정면 훼손 후보. 우리 리포의 기존 교정 허용
  5조건 (리뷰 5: gate 가 downstream 결과 전 실패 ✓ / 원인이 **구현 오류**
  ✗ — 이것은 지표 설계 결함이지 버그가 아니다 / …) 을 충족하지 못한다.
  "이미 단조인 지표를 고르는 것" 자체가 선택 편향이다.

## 5. 무너뜨려 볼 주장들

1. **"역전은 taxonomy/지표 결함이지 기전 결함이 아니다"** — 총량 단조가
   그 증거라는 우리 해석은 사후 합리화인가? "strong 이 정말 더 반응적"
   이라는 주장을 총량 말고 무엇으로 반증/지지할 수 있는가?
2. **"cruise 단조 + sprint 역전 = budget 경쟁 교락"** — 그렇다면 "같은
   speed regime 안에서 순서 성립" 으로 판정을 **조건화**하는 변형은 (a~c
   어디에 속하며) 기준 완화인가 아닌가?
3. **소급성 오염** — 진단에 쓴 수치(T_active, Σ|realized|, regime 분해)는
   성능이 아니라 기하 관측이지만, 어쨌든 우리는 결과를 봤다. 세 안 모두
   "결과 informed 재설계"인데, 오염을 최소화하는 실행 프로토콜은 무엇인가
   (예: 재설계 후 P95' 를 **새 base episode 대역**에서 1회만 실행, 재실패
   시 재탐색 금지 등 — 이 규율 초안 자체를 판정해 달라)?
4. **3안 각각의 실패 모드** — (a) 경계 탐색의 정지 규칙 부재, (b) 층 의미
   변경이 하류(9셀 균등 학습·셀별 공개·OOD-CORNER 정의)에 미치는 파장,
   (c) 지표-선택 편향. 각각 우리가 못 본 추가 실패 모드를 지적하라.
5. **재실행 범위** — 어느 안이든 P92(분포 배선)·P93(침투 보존)은 재실행
   대상이다. P94(자연 상태 route ablation, NOMINAL 에서 GREEN)는 taxonomy
   와 독립이라 **유효 유지**라고 주장한다 — 맞는가? scripted baseline
   설계 동결(별도 문서)과의 선후는 어때야 하는가?

## 6. 제약 (이미 잠긴 규율 — 재론 대상 아님)

- P95 실패 = TRAIN taxonomy 실패 (MARL 실패 아님). 성능 지표 미열람 유지.
- route_gain 값 상향 금지 (semantic validity 검증이지 difficulty tuning 아님).
- 판정 기준 완화로 PASS 만들기 금지.
- NOMINAL 로 학습 금지 · 능력 브래킷/스폰/지평선(1100)은 불변.

## 7. 요청 형식

- §5 주장 1~5 각각: **유지 / 조건부 유지 / 기각** + 핵심 이유 (2–3문장).
- **3안 판정: 택1 또는 수정안** (혼합 허용 — 단 "전면 재설계" 는 받지
  않는다. 우리가 스스로 결정할 몫이다). 선택안의 **재사전등록 문구 초안**
  (판정식 1줄 포함)을 제시하라.
- 재검정 프로토콜 판정: P95' 실행 규율 (episode 대역·실행 횟수 상한·재실패
  시 처리) 을 결과 전에 어떻게 고정해야 하는가.
- **이 재설계가 논문에서 공격받을 한 문장**을 미리 써 달라 (우리가 한계
  절에 스스로 적을 수 있도록).
- 동의는 필요 없다. 우리가 놓친 반례·교락·게이밍 경로가 필요하다.
