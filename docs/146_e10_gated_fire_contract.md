## 0. 질문 하나와 결정 규칙 (결과 전 고정)

**질문**: 발사를 보장 판정으로 막은 학습 방어의 확보 포획률은, 그 방어 전용으로 적응한 레드팀 상대로, χ 가 낮아질수록 오르는가?

| 결과 | 그러면 |
|---|---|
| 낮은 χ 에서 열림 + 순서 지지 | 양측 검증 그림 (URP 얼굴): 해석이 안 된다는 곳은 안 열리고, 된다는 곳은 해석 게이트로 열린다. 승률 표 = χ × 방어 종류 (예산 조건 병기) |
| 전 χ 에서 닫힘 | 적응 공격자가 보장 집합을 통째로 우회 — 병목은 창의 존재가 아니라 **창으로 몰아넣기**. 다음 질문 = 경로 제한기 (원래 가설 2) 를 "몰아넣을 창이 있는 영역" 에서 |
| 예산 미수렴 | 숫자는 전부 "≤" (상한 추정) 로만 쓰고, 열림 주장은 예산 조건부로 한정 |

## 1. 근거 (탐색, 원고 근거 아님)

기존 학습 방어 (게이트 없음, 정합 레드팀 1e7, 변형당 720 판): 보장 tick 이 있던 판 28–56% · 그물 포획 5–11%. 실패 = 기회가 있는데 미발사 /
창이 지난 뒤 늦은 발사 (발사 거리 6–8 m) / 기회 없는 판에서 이른 발사 (13–15 m, 전체 판의 40–55%). 포획한 발사는 9–10 m.
→ 병목은 발사 결정. 단, 이 레드팀은 창 진입에 벌을 주지 않는 방어에 적응한 개체라 **창을 피하도록 재적응하면 기회 비율은 내려간다**
(기준 그물의 판정 증류 방어에서는 발사 기회가 판의 1–7%).

## 2. 세계 변경 (새 계보)

- `FS1Spec.fire_gate: str = "off"` (기본 = 현행과 비트 동일) / `"robust"`.
- `"robust"`: LOADED 에서 발사 요청이 와도 **포획 판정 자체** (최악 회피 포함 보장 ∧ limiter 가둠 아님 — `env.py` 의 발사 순간 포획 술어와
  동일) 가 참일 때만 발사. 막힌 요청은 탄·발사 비용을 소모하지 않는다 (내부 FSM 의 기존 gate 경로 재사용; 기존 문턱 soft ≥ 0.9 는 쓰지 않음).
- 게이트 아래 FCS 는 **발사 거리 행동을 무시**하고 arm ∧ LOADED ∧ d ≤ 16 m (계측 창과 같은 범위) 이면 항상 요청한다. 막힌 요청이 무비용이라
  발사 거리 선택에 득실이 없기 때문 (게이트 없는 세계의 의미론은 불변).
- 귀결: 발사 = 포획 (정의상 1:1). 학습이 정하는 것은 **위치·가속·arm** — 즉 창을 만드는 일. 발사 시점은 해석이 정한다.
- JAX 포트 + parity (기존 McNemar 절차) 선행. JAX worktree 는 정본보다 한 달 이상 뒤 → merge 먼저.

## 4. 사전 예측 (부속 판정 3 개)

해석 근거: 정면 기하의 창 길이 (R/V)(1 − χ/χ\*) → 예측 창 2.5 / 5.1 / 6.0 tick (χ 0.52 / 0.231 / 0.13). 게이트는 창이 1 tick 만 열려도 쏜다.

- **P-E10a 열림**: χ 0.130 에서 seed 5 중 3 이상이 포획 ≥ **29/240** (기존 등록 문턱 승계) → `GATE_OPENS`, 아니면 `GATE_NULL`.
- **P-E10b 순서**: seed 중앙값이 χ 가 낮을수록 비감소 (0.13 ≥ 0.231 ≥ 0.52) 이고 양 끝 차 ≥ **13/240** → `ORDER_SUPPORTED`, 아니면 `ORDER_NOT_SUPPORTED`.
  (13 = 2·√2·4.56: 평가 반복성 계약에서 잰 정합 평가 1 회의 이항 SD 4.56/240 의 짝 차이 2 SD. 초안의 12 를 대체.)
- **P-E10c 예산** (레드팀 예산 계약 규칙 승계): slot 별 d = 포획(1e7 스냅샷) − 포획(3e7). 중앙값 ≥ 4 ∧ 15 중 ≥ 10 양수 → `BUDGET_UNDERTRAINED` /
  |중앙값| < 4 → `BUDGET_CONVERGED` (뜻: 예산 효과 < 4/240, 수렴 증명 아님) / 그 밖 `BUDGET_MIXED`.
- 기준 그물 (χ 0.52) 은 0 이 아니라 **가장 낮다**고 예측한다 (창 2 tick 은 존재).
- **두 판정은 독립**: 기준 그물까지 높게 열리면 `GATE_OPENS` 이면서 `ORDER_NOT_SUPPORTED` 일 수 있다 (그 경우 = 10월의 닫힘이 창 길이가 아니라
  발사 결정 문제였다는 뜻 — 보고).
- **보고 전용**: 보장 tick 이 있던 판 비율 · 전체 방어 성공 · 관통률 · 예산 곡선 1e7/2e7/3e7 · 확률적 방어 · 학습된 arm·위치 통계.
