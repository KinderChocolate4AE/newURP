## 4. A (공격자 기전 개입) — v0 이전 실행 가능성

- 설계 (main): 학습된 착취자의 행동 성분을 개입으로 고정·제거 — 후보: (i) 교전 거리 밖에서 학습
  residual 을 0 으로 (순수 homing) (ii) 교전 거리 안에서만 residual 제거 (iii) 기동 스킬 z 고정
  (iv) 횡방향 residual 클램프. 측정 = 정합 방어 상대 robust 창 점유·천장 변화. 체크포인트 재사용,
  새 학습 없음.
- 비용: 구현 (eval 의 공격자 행동 래퍼 + CLI) ~반나절 + 봉인. CPU 평가: 개입 4 × 15 slot (E7-b) × 1
  조합 ≈ 60 평가 — 최근 평가 속도 (slot·조합당 수 분) 로 **1~2시간**.
- **판단: v0 전에 가능** — 단 조건: 사용자 결재 10/13 까지 → 10/13 계약 봉인·구현 → 10/14 실행 →
  10/15 판독 → 10/20 v0 통합. 결재가 늦거나 개입 정의에 합의가 안 되면 v0 이후로 넘기고 gap list 에
  "진행 중" 으로 둔다.
- F (T0 anchor) 는 계산 자원 불필요 — 문헌 조사라 v0 와 병행 가능 (사용자 지시 시 main 착수).
