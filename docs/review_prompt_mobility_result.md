# 외부 리뷰 요청 2 — 이동성 요인 실험 결과

> 그대로 붙여 넣어 쓴다. 리뷰어는 리포·이전 대화 접근이 없으므로 자기완결적으로 썼다.

---

당신은 다중 에이전트 강화학습 논문의 **비판적 외부 리뷰어**다. 앞선 리뷰에서
제기된 위험을 검증하는 실험을 돌렸고, 결과가 우리 설계에 **유리하게** 나왔다.
그래서 이번 요청의 핵심은 이것이다.

> **우리가 유리한 결과를 과대해석하고 있는가?**

동의해 주는 답은 쓸모가 없다. §5 의 주장 셋을 각각 무너뜨려 봐라.

## 1. 시스템 (요약)

무인기 방어. 공격자 1기, 방어측 두 역할.

- **limiter 4기** — 자유 이동. 공격자를 파괴하지 않고 기동을 제약해 포획 가능한
  기하로 몬다.
- **finisher 1기** — **위치 고정**. 조준축(3) + 발사(1)만 낸다. 그물이 맞으면
  **비손실 포획**. 논문의 스파인이 비손실이다.

기하 (실측): finisher 는 x=2 고정, limiter 링은 x=8. 포획 판정은 finisher 를
꼭짓점으로 하는 원뿔(반각 **12.15°**, 최대 사거리 **8.22**, 최소 사거리 **0**)
이고, 공격자의 실현 가능한 모든 회피 궤적이 그물 구(반경 1.77)에 걸릴 때만
성공으로 친다. 조준축은 **슬루 속도 제한**이 있다: `omega_max = 2.0 rad/s`,
`dt = 0.05` → **5.73°/스텝**.

## 2. 확립돼 있던 것 (25 런, 500k 스텝)

역할별로 학습을 켜고 끈 실험에서 인과 사슬이 나왔다.

```
학습이 무개입보다 나쁘다
  → 편대 학습의 단독 기여 ≈ 0 (0.187 vs 0.182)
  → 발사 역할이 결손 (0.137)
  → 3단 진단: 관측 충분(AUC 1.000) / 발사 비트는 게이트 인지 / ★조준축이 결손
      발사 게이트 개방률: 해석적 0.0430 vs 학습 0.0262 (0.61x)
  → 행동 복제(BC)로 조준이 해석적 규칙의 97 % 회복
```

## 3. 앞선 리뷰가 제기한 위험

> 현재 데이터는 *"고정 포획기 조건에서 조준이 병목"* 을 지지하지만
> *"포획기가 움직여도 조준이 병목"* 은 전혀 검증하지 않았다.
>
> 고정 포획기는 조준 오차를 흡수할 자유도를 없앤다. 따라서 다음 둘이 모두
> 자료와 양립한다. (1) RL 이 조준을 학습 못 했다 (2) **고정 설계가** 부분 결손을
> 임무 실패로 증폭했다. 즉 인과 사슬이 **설계 산물**일 수 있다.

판정은 (C) 였다 — 전면 재설계 전에, **학습 없는 요인 실험**으로 고정 가정의
민감도를 먼저 재라.

## 4. 실행한 것과 결과

포획기에 병진을 주고 **해석적 조준**으로 2 칸을 paired CRN 으로 돌렸다. 새 RL
런은 0 개, 두 칸은 같은 초기조건·같은 공격자 난수를 본다.

병진 제어기(선언, 결과 보기 전 고정): 예측 그물 중심 `nc = p_att + v_att·τ` 로의
임계감쇠 추종, `a_max` 는 **limiter 와 같은 값**(15.41, 새 숫자를 만들지 않고
이동에 가장 관대한 능력). 목줄 없음. 이득은 `τ` 하나에서 유도 — 스윕 안 했다.

### 4.1 결과 (n=500 paired, SHAPING 구간 n=297)

| | 전체 무력화 | 비손실 | 성형필요 구간 |
|---|---:|---:|---:|
| 고정 | 0.182 | 1.000 | **0/297** |
| 이동 | 0.142 | 1.000 | **0/297** |

```
성형필요   0.0000 -> 0.0000    구제 0 / 망침 0
전체       0.1820 -> 0.1420    차이 -0.0400, 부트스트랩 CI95 [-0.058, -0.024]
                               구제 0 / 망침 20
이동거리   경로 6.03 (p90 11.13), 순변위 평균 3.94 최대 6.52
```

- 회귀 검사: 고정 칸이 기존 기저선과 **정확히 일치**(0.182, 0/297). 배선이
  이동 off 에서 아무것도 안 바꿨다.
- 포획기는 **실제로 움직였다** (순변위 3.94, 회랑 규모 대비 작지 않다).
- 그런데 297 판에서 **한 판도 구제되지 않았고**, 전체로는 유의하게 나빠졌다.

### 4.2 왜 나빠졌나 (40 판 진단)

| | 요구 회전 중앙 | 슬루 한도 초과율 | 사거리 중앙 | 게이트 개방률 |
|---|---:|---:|---:|---:|
| 고정 | 5.80° | 0.504 | 6.37 | 0.0397 |
| 이동 | **23.23°** | **0.640** | 7.59 | **0.0280** |

사거리는 오히려 **이동 쪽이 더 멀다**. 즉 "가까워져서 각속도가 커졌다" 가
아니다. **포탑이 움직이면 자기 운동이 시선각속도에 더해진다** -- 정지 포탑은
표적의 횡방향 운동만 쫓으면 되지만 움직이면 자기 운동분이 얹힌다. 그리고 이
포탑은 정지 상태에서 이미 스텝의 **50 %** 를 슬루 한도에 걸려 있다.

## 5. 우리가 내린 해석 (★ 이 셋을 공격해 달라)

**주장 1.** 고정 포획기 가정이 §2 의 음성 결과를 만들어낸 것이 아니다. 성형필요
구간에서 구제가 **정확히 0** 이므로 "조금 도왔는데 유의하지 않다" 가 아니라
아무 일도 일어나지 않았다.

**주장 2.** 이동이 해가 되는 **기전이 특정됐다**(§4.2). 따라서 이 음성은 "우리
제어기가 약해서" 가 아니라 접근하는 **어떤** 제어기에도 걸리는 기하다 — 해악이
포획기 속도에 비례한다.

**주장 3.** 그러므로 고정 설계는 이제 *"안 해봤다"* 가 아니라 **측정에 근거한
정당화**로 쓸 수 있다. 심사에서 "왜 고정인가" 에 한 문단 변명이 아니라 실험으로
답한다.

### 5.1 우리가 이미 아는 약점

- **느린 제어기는 이 함정을 피할 수 있다.** 해악이 속도에 비례하므로, 표적이
  각속도로 조용할 때만 조금씩 움직이는 제어기는 다를 수 있다. 부담이 옮겨갔을
  뿐 배제되지는 않았다.
- **학습 조준 칸(이동×학습)은 아직 안 돌렸다.** 그 칸은 정책이 `p_fin` 상수인
  관측에서 학습했으므로 포획기가 움직이면 분포 밖이다. 그래서 1차에서 뺐다.
- **`omega_max = 2.0` 이 선언값이다.** ★ §4.2 의 기전 전체가 포탑이 슬루
  제한을 받는다는 데 의존한다. 이 값이 더 컸다면 자기 운동분이 흡수됐을 수 있다.

## 6. 답해 달라

1. **주장 1~3 각각에 대한 가장 강한 반론.** 특히 주장 2 — "기전이 특정됐으니
   제어기 품질 문제가 아니다" 가 실제로 성립하는가, 아니면 여전히 하나의
   제어기에서 나온 하나의 관측인가?
2. **§5.1 의 세 번째 항목(`omega_max` 의존)이 결론을 얼마나 무르게 하는가.**
   이 결론을 지키려면 `omega_max` 감도 실험이 필요한가? 필요하다면 최소 몇 점을
   어떻게 잡아야 하는가? 아니면 "슬루 제한이 있는 포탑" 자체를 문제 정의에
   못 박는 것으로 충분한가?
3. **사전등록 변경의 정당성.** 당신(앞선 리뷰)이 제안한 2x2 에서 결정 규칙 셋 중
   둘이 `이동×학습조준` 칸에 얹혀 있었는데, 우리는 그 칸이 분포 이동에 오염돼
   있다고 보고 **1차를 해석적 조준 칸으로 옮겼다.** 결과를 보기 전에 바꿨지만
   변경은 변경이다. 이 변경이 정당한가, 아니면 우리가 유리한 칸을 고른 것인가?
4. **통계.** 부트스트랩은 에피소드 쌍을 통째로 20000 회 재표집했다(paired).
   성형필요 구간이 0 대 0 이라 차이의 CI 가 [0, 0] 으로 퇴화하는데, 이 경우
   "차이 없음" 을 주장하는 올바른 형태는 무엇인가? 등가성 검정을 붙여야 하는가,
   붙인다면 등가 범위를 무엇으로 잡아야 하는가?
5. **★ 새 단서.** 정지 상태에서 이미 슬루 한도 초과율이 0.504 다. 지금까지의
   진단은 조준 *방향*만 봤고 *속도*는 안 봤다. 이게 진짜 병목 후보인가, 아니면
   측정 정의의 산물인가? (주의: 이 각도는 `현재 자세 → nc 방향` 이고 p90 이
   142° 인 양봉 분포다. 공격자가 뒤/멀리 있을 때 큰 값이 섞인다. 우리는 고정·이동
   **상대 비교**만 근거로 쓰고 절대 수준은 별도 진단이 필요하다고 보고 있다.)
   진짜라면 어떤 측정으로 확인해야 하는가?

## 7. 형식

- 결론 먼저, 그다음 근거.
- 확실한 것과 추측을 구분해 표시해라.
- 우리가 제시한 수치 중 **결론을 지탱하기에 부족한 것**을 지적해라.
- 최소한 §5 의 한 주장은 실제로 무너뜨려 봐라. 셋 다 살아남는다고 판단하면
  그렇게 말하되, 각각에 대해 당신이 시도한 가장 강한 공격을 함께 적어라.
