## 1. 왜 이 실험인가

docs/48 의 세 진단이 한 점을 가리킨다.

| | 무엇을 봤나 | 결과 |
|---|---|---|
| §10 [A] | 관측에 발사 판단 근거가 있는가 | **있다.** 단일 차원 · 단일 임계로 라벨 재현 (AUC 1.000) |
| §11 [B] | 발사 비트가 게이트를 보는가 | **본다.** AUC 0.57~0.995, 세 런은 `E[p\|교차] ≈ 1.0` |
| §12 [C] | 조준축이 게이트를 여는가 | **못 연다.** 개방률 0.61x(SL) / 0.23x(LL) |

즉 결손은 finisher 의 **연속 3차원(조준)** 이고 이산 1차원(발사)이 아니다.
그리고 `aim_audit` 은 결정론 평균(`fin_actor.mean`)을 썼으므로 탐색 노이즈가
아니라 **평균 자체가 나쁘다** -- log_std 를 줄여도 안 낫는다.

왜 못 배웠는지도 이미 적혀 있다: 교사 축은 `unit(p_att + v_att·tau − p_fin)` 로
해석적으로 완벽한데, 그 함수를 보상만으로 되찾으려면 기울기가 있어야 하고
`signal_audit` 은 무작위 탐색 수익 std 가 종말항의 **0.32 %** 라고 실측했다.

### 1.1 사전 게이트 — 교사 축은 관측의 함수인가 (2026-08-05, 통과)

BC 가 성립하려면 교사 축이 관측으로부터 계산 가능해야 한다. §10 과 같은 방법으로
먼저 쟀다 (90 에피소드 · 2498 스텝 · 에피소드 단위 분할):

| 회귀기 | 코사인 평균 | 코사인 중앙 | 각오차 평균 | 중앙 | p90 |
|---|---:|---:|---:|---:|---:|
| **선형** | **0.9984** | 0.9996 | **2.24°** | 1.65° | 4.60° |
| MLP 128x2 | 0.9930 | 0.9996 | 3.41° | 1.64° | 7.37° |

교사 축의 입력(`p_att`, `v_att`, `p_fin`)이 전부 관측에 실려 있으므로 당연한
결과이고, **특권 정보가 아니다.** §10 과 같은 부수 관찰도 반복된다 -- 용량이 큰
MLP 가 선형보다 약간 나쁘다.

**이 게이트를 통과했으므로 BC 는 원리적으로 가능하다.** 실패하면 그건 표현이
아니라 배선·최적화 문제다.

## 2. 팔 (선언)

| 팔 | 조준 헤드 | 설명 |
|---|---|---|
| **SL** (대조군) | RL 만 | **다시 안 돌린다** — `results/m4_roles/SL_s*` 재사용 |
| **SL-BCw** | BC 워밍업 → RL | 스크립트 궤적에서 조준 헤드만 지도학습한 뒤 RL 시작 |
| **SL-BCa** | RL + BC 보조손실 | 매 업데이트에서 `L = L_PPO + λ·L_BC`, 정책 자신의 상태 분포 |

편대는 세 팔 모두 `hold` 로 고정한다. 조준 하나만 바꾸는 실험이므로 편대를 같이
움직이면 귀속이 다시 깨진다 (docs/48 §8.2 에서 배운 것).

시드 {0,1,2,3,4}. `w_kill = 0.5` 고정.

### 2.1 왜 두 팔인가

`SL-BCw` 는 표준적이지만 **분포 이동**에 취약하다 -- 교사 궤적에서 배운 조준이
정책 자신의 궤적에서는 누적 오차로 무너질 수 있다. `SL-BCa` 는 라벨을 정책의
상태에서 받으므로 그 문제가 없는 대신, BC 가 계속 당겨서 *"RL 이 조준을
개선하는가"* 를 못 보게 만든다.

둘은 서로의 약점을 덮는다. 어느 쪽이 나은지는 **모르므로** 둘 다 선언하고 둘 다
보고한다 (하나만 돌리고 나중에 다른 걸 추가하면 그게 사후 선택이 된다).

### 2.2 고정할 값 (선언, 튜닝 아님)

```
BC 손실      cosine:  L_BC = 1 − cos(â, a*)      (축은 방향만 의미가 있다)
교사         shepherd.agents.baselines.scripted_finisher 의 축 성분 -- 기준선과 같은 함수
BCw 워밍업   20k 스텝 상당의 교사 궤적, 조준 헤드만 갱신 (발사 헤드·크리틱 동결)
BCa 계수     λ = 0.1 고정, 감쇠 없음
```

`λ` 와 워밍업 길이는 **스윕하지 않는다.** 여기서 묻는 것은 "BC 가 조준을
회복시키는가" 이지 "최적의 λ 는 무엇인가" 가 아니다. 값을 찾기 시작하면 선언
규율이 깨지고, 그건 docs/47 §4 에서 이미 정한 원칙이다.

## 3. 판정식 (선언 · 결과 보기 전)

### 3.1 ★ 1차 지표를 바꾼다 — 그리고 그것이 사후 변경이 아닌 이유

docs/48 의 1차 지표는 `SHAPING_NEEDED` 무력화율이었다. **이 실험에는 쓸 수
없다**: 세 팔 모두 편대가 `hold` 이므로 커밋이 구조적으로 0 이고 SHAPING 네트
포획도 배치 없이는 불가능하다 -- 즉 0 말고 나올 값이 없다 (docs/48 §8.2 가
기록한 설계 결함).

그래서 **게이트 개방률**을 1차로 선언한다. 이건 docs/48 의 판정식을 바꾸는 것이
아니다. 다른 질문(*"조준이 쏠 기회를 만드는가"*)에 대한 **새 실험의 새 사전등록**
이고, docs/48 의 결론은 그대로 남는다. 규율상 중요한 구분이라 여기 적어 둔다.

### 3.2 판정

`fire_audit --aim` 의 `learned_aim.gate_open_rate` 를 5시드 풀링해서 본다.

```
기준(하한)   기존 SL 조준        0.0262   Wilson [0.0230, 0.0298]   (n≈8450)
천장         스크립트 조준       0.0430   Wilson [0.0345, 0.0540]   (n≈1690)

H_bc    BC 팔의 Wilson 하한 > 0.0298          -> 조준이 개선됐다
H_rec   BC 팔의 Wilson 구간이 스크립트 구간과 겹친다 -> 조준을 회복했다
```

n≈8450 에서 통과에 필요한 개방률은 **0.035** 다 (하한 0.0313 > 0.0298).
0.033 은 미달(하한 0.0294)이다.

풀링 규율은 docs/48 §4 와 같다 -- **시드 과반**(5시드 → 3)이 개별로도 기준을
넘을 때만 '강함', 아니면 '풀링 의존' 으로 적는다.

### 3.3 2차 (보고 전용, 판정 아님)

전체 무력화율 · `SHAPING` · `BAND_AIM` · 비손실 비율. 특히 **전체 무력화율이
SS(0.182)를 되찾는가** 가 이 실험의 실질적 관심사지만 1차로 걸지 않는다 --
게이트 개방률과 성적 사이에는 매개 가정이 하나 더 있고(§4), 그 가정까지 1차에
싣는 것은 무리다.

### 3.4 null case

두 BC 팔 모두 `H_bc` 미통과면 그것이 결과다: **조준은 지도학습으로도 회복되지
않는다.** 그러면 문제는 조준 함수가 아니라 그 아래(관측 정규화 · 액터 용량 ·
행동 스케일)에 있고, §1.1 의 게이트를 통과했으므로 표현은 용의선상에서 빠진다.

## 4. 무엇을 답하지 못하는가

- **매개 가정.** "게이트 개방률이 오르면 성적이 오른다" 는 docs/48 §12.1 의
  관측(순서 일치)에 기반한 가정이지 증명이 아니다. 개방률만 오르고 성적이
  안 오를 수 있다. 그래서 2차를 반드시 같이 보고한다.
- **교사가 상한이다.** BC 는 스크립트 조준을 넘을 수 없다. 이 실험은 *"교사만큼
  하는가"* 를 묻고 *"교사를 넘는가"* 는 못 묻는다. 후자는 `SL-BCa` 의 RL 항이
  하는 일이지만, λ 고정이라 여기서 분리해 측정되지 않는다.
- **off-policy 측정.** `--aim` 은 `hold` 편대 · 발사 off 로 잰다. `SL` 계열은
  그 분포에서 학습했으므로 맞지만, 실제 성적은 발사가 켜진 궤적에서 난다.
- **편대는 여전히 `hold` 다.** 협력의 순이득 질문(docs/48 §4)은 여기서 답하지
  않는다. 조준을 회복한 뒤에 다시 물어야 한다.

## 7. 배선 스모크 (2026-08-05, 학습 결과 전 — **인용 금지**)

배선이 끝까지 도는지만 본 것이다. 500k 선언값의 0.4 % 인 2048 스텝이고 평가도
n=25 다. 그런데 **하나는 스모크가 아니다**: "RL 0 스텝" 줄은 워밍업 직후를 잰
것이라 학습 확률성이 안 섞인다.

| 조건 | 게이트 개방률 | 판당 최대 v_shot | 열린 판 |
|---|---:|---:|---:|
| 스크립트 조준 (기준) | 0.0455 | 0.583 | 0.28 |
| **BC 워밍업 직후 · RL 0 스텝** | **0.0441** | **0.577** | **0.28** |
| BCw · RL 2048 스텝 뒤 | 0.0043 | 0.126 | 0.04 |
| BCa · RL 2048 스텝 뒤 | 0.0156 | 0.514 | 0.16 |

워밍업 자체는 교사에 붙는다 -- 코사인 0.9985 (각오차 3.13°, n=3394), 그리고
게이트 개방률이 스크립트의 **97 %** 다. 즉 **BC 는 조준을 회복시킨다.**
docs/48 §12 의 결손(0.61x)이 이 경로로 메워진다는 것을 배선 수준에서 확인했다.

**문제는 그 다음이다.** 2 업데이트(2048 스텝)만에 BCw 가 0.0441 → 0.0043 으로
무너진다. `bc_lambda = 0` 인 팔이므로 조준을 붙잡는 항이 없고, PPO 의 조준
기울기는 §1 이 인용한 대로 잡음이 지배한다. `BCa`(λ=0.1 상시)는 0.0156 으로
덜 무너진다. **§2.1 이 BCw 의 위험으로 적어 둔 분포 이동·망각이 실측으로
보이는 것**이고, 두 팔을 다 선언해 둔 이유가 이것이다.

두 번째 후보 기전도 적어 둔다: 워밍업이 `obs_norm` 을 교사 데이터로 갱신한 뒤
RL 이 계속 갱신하므로, BC 로 맞춘 함수가 **밀린 입력**에서 평가된다. 어느 쪽이
지배적인지는 본런의 `finisher/bc_cosine_loss` 곡선(BCa)과 BCw 의 조준 감사로
가른다.

**λ 나 유지 항을 지금 바꾸지 않는다.** 결과를 보기 전에 손대면 그건 튜닝이고
§2.2 의 선언을 깨는 것이다. 이 관찰은 예측으로 남긴다 -- 본런에서 BCw 가
무너지고 BCa 가 버티면 §2.1 의 판단이 맞은 것이고, 그때 '유지 항' 이 다음
설계 축이 된다.

## 8. 결과 (2026-08-05, 10 런 x 500k 완주)

### 8.1 ★ 1차 판정 — 세 팔 모두 미달

게이트 개방률, 5 시드 풀링 n=8450. 통과선 0.035 (하한 > SL 상한 0.0298).

| 팔 | 평균 | 풀링 Wilson | 판정 |
|---|---:|---|---|
| SL (대조) | 0.0262 | [0.0230, 0.0298] | 기준 |
| **SL-BCw** | **0.0247** | [0.0216, 0.0283] | 미달 (SL 보다 **낮다**) |
| **SL-BCa** | **0.0303** | [0.0268, 0.0342] | 미달 (하한 0.0268) |
| 스크립트 | 0.0430 | — | 천장 |

`H_bc` 미통과, `H_rec` 미통과.

### 8.2 두 팔의 의미가 다르다

**`SL-BCw` 는 완전 실패다.**

```
시드별 차이  [0, +0.0025, -0.0043, +0.0031, -0.0085]   평균 -0.0014
SL 상한 초과 시드 0/5
```

워밍업 직후 게이트가 0.0441 (스크립트의 97 %) 이었는데 500k 뒤 0.0247 이다.
**사전등록 §2.1 이 적어 둔 위험 그대로**고 배선 스모크(§7)가 2048 스텝에서
이미 예고했다. 유지 항 없는 워밍업은 살아남지 못한다.

**`SL-BCa` 는 방향이 맞지만 부족하다.**

```
시드별 차이  [+0.0067, +0.0025, -0.0019, +0.0097, +0.0036]   평균 +0.0041
양의 시드 4/5   t(4)=+2.10 (p≈0.10)   부호검정 p=0.375
SL 상한 초과 시드 3/5   <- 풀링 규율의 '시드 과반' 은 만족
★ 격차의 24.5 % 회복 (0.0262 -> 0.0303, 천장 0.0430). 통과선까지 0.0047 부족
```

BC 보조손실은 조준을 **실제로 끌어올린다**. λ=0.1 고정으로는 격차의 1/4 이다.

### 8.3 ★ 매개가 붙었다 — docs/50 §3 위험 3 해소

docs/50 은 *"개방률 -> 성적"* 이 관측 3 점의 순서 일치일 뿐인 **가정**이라고
적었다. 이번 런이 그 가정을 직접 친다 -- 두 팔이 SL 과 **조준만** 다르고
편대·보상·시드가 전부 같기 때문이다.

| 팔 | 게이트 회수율 | 전체 무력화 회수율 | 시드 부호일치 | r |
|---|---:|---:|---:|---:|
| SL-BCa | **+24.5 %** | **+20.6 %** | 4/5 | +0.66 |
| SL-BCw | **−8.6 %** | **−10.3 %** | 4/5 | +0.91 |

(회수율 = SL -> SS 격차 중 메운 비율. 전체 무력화 SS 0.182 / SL 0.137.)

**두 방향 모두 게이트와 성적이 같은 부호·비슷한 크기로 움직인다.** 특히
`BCw` 가 강하다 -- 게이트가 **내려간** 개입에서 성적도 내려갔고 시드 상관이
+0.91 이다. 한 방향만 봤으면 우연일 수 있는데 반대 방향도 같이 움직였다.

**한계**: 시드 5 개라 유의성은 주장하지 않는다. 회수율 일치(24.5 vs 20.6)도
점추정 비교다. 그러나 *"조준이 성적을 만든다"* 는 문장을 이제 **가정이 아니라
관측**으로 적을 수 있다.

### 8.4 SHAPING 은 왜 전 팔 0 인가 — 1차 지표의 판별력 문제

`docs/48` 의 1차 지표(SHAPING 무력화율)는 다섯 팔 전부 0/861 이다. 그런데
**기저선 SS 자신도 0/297** 이다 (2026-08-05 이동성 실험 셀 1 에서 재확인).

```
SS(해석적)  0/297      <- 손튜닝 천장
LL/LS/SL/BCw/BCa  0/861 씩
```

즉 **이 운용점의 SHAPING 구간은 천장을 포함해 아무도 못 잡는다.** docs/48
§8.2 가 기록한 "H_fin 검정 불가" 결함의 더 넓은 버전이다 -- 그때는 SL 만
구조적 0 이라고 봤는데 실제로는 그 칸 전체가 0 이다.

따라서 집계의 *"어느 역할을 학습시켜도 SS 를 못 넘었다"* 는 정보가 없다.
넘을 대상이 0 이다. **다음 실험은 1차 지표를 판별력 있는 칸으로 옮겨야 한다**
(전체 무력화율 또는 BAND_AIM -- SS 0.010 대 SL 0.020 으로 분산이 있다).
