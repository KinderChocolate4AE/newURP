# 외부 리뷰 요청 3 — 계약 개정 (접촉 resolver · net-miss handoff) 검증 결과

> 그대로 붙여 넣어 쓴다. 리뷰어는 리포·이전 대화 접근이 없으므로 자기완결적으로 썼다.

---

당신은 다중 에이전트 강화학습 논문의 **비판적 외부 리뷰어**다. 우리는 동결돼
있던 환경 계약을 개정했다 — 근거는 성능이 아니라 "구현이 비준된 설계를 따르지
않는다"는 코드 감사였다. 개정을 배선하고 사전등록한 검증을 돌렸는데, 하나는
**수락대역을 벗어났고**, 하나는 **판정 기준 하나가 실패했다.** 우리는 둘 다
"문제 없음"으로 해석했다. 이번 요청의 핵심은 이것이다.

> **우리가 사전등록을 지켰다고 주장하면서 실제로는 사후 합리화를 하고 있는가?**

동의해 주는 답은 쓸모가 없다. §6 의 주장 넷을 각각 무너뜨려 봐라.

## 1. 시스템 (요약)

무인기 방어. 반응형 스크립트 공격자 1기, 방어측 두 역할.

- **limiter 4기** — 자유 이동. 공격자를 파괴하지 않고 도달가능집합을 압축.
  `kill_radius = 0.75 m`. 하드킬 경로가 하나 있었다: 정책이 **커밋 비트**를
  올리면 env 가드(기하 검사 → no-kinetic zone 거부권 → Bernoulli Pk)가 해소.
- **finisher 1기** — 위치 고정, 그물 1발. 맞으면 비손실 포획 (논문 스파인).
- `dt = 0.05 s`, 에피소드 80스텝, 공격자 최대가속 ~77 m/s², limiter ~27 m/s².

비준된 설계는 "2모드 + 1핸드오프" (net 실패 → 하드킬 폴백)였다. 그런데 코드
감사에서 두 비정합이 나왔다:

1. **접촉 event resolver 부재** — 공격자가 limiter 의 kill_radius 를 **관통해도
   아무 일도 없다.** 하드킬은 커밋 비트로만 발동.
2. **net miss 즉시 종료** — 그물이 빗나가면 그 스텝에 에피소드가 끝난다.
   핸드오프가 구조적으로 한 번도 발동할 수 없다.

## 2. 개정 전 감사 (프로토타입, boxed 17판)

limiter 가 공격자의 모든 대리 탈출로를 막은 상태(`boxed_in`)를 저장해 4 arm:

```
A  현행·무발사       접촉 0.765  침투 1.000   <- 접촉해도 아무 일 없음
B  현행·즉시발사     침투 0.000 (조기종료 산물, 성공 아님)
C1 종료만 억제       침투 0.941   <- 즉시 종료는 주 비정합이 아니다
C2 + 접촉 resolver   침투 0.235  무력화 0.706  <- 여기서 회복
```

C2 는 스크립트 인라인 프로토타입이다: **스텝 끝 시점(endpoint) 거리 ≤ 0.75 검사
+ 즉시 무력화 (Pk·거부권 미적용).**

## 3. 사전등록한 것 (결과 보기 전 고정)

**R1 접촉 resolver** (기본 off, off 면 기존과 비트 동일):

- 검출 = **swept**: 상대 선분 `r0=p_att(t)−p_lim(t)`, `r1=p_att(t+1)−p_lim(t+1)`
  의 원점 최소거리 ≤ 0.75. (적분은 등가속 곡선이므로 선분은 근사라고 명시.)
- 해소 = 기존 커밋 경로와 같은 사슬 (no-kinetic 거부권 → 소모 → Bernoulli Pk),
  단 **즉시 해소** (커밋 경로의 tau_kill 지연 없음).
- **V2 수락대역**: 같은 boxed 17판에서 `|무력화−0.706| ≤ 0.15 ∧ |침투−0.235| ≤
  0.15`. **이탈 시 (거부권 수 · swept 추가검출 수 · Pk) 로 분해해 원인 귀속 전
  진행 금지. 차이가 이 축들로 설명되면 방향 재현으로 인정한다** ← 이 조항도
  결과 전에 적었다.

**R2 net-miss handoff** (기본 off): miss 종료를 억제하고 에피소드 계속.
V3 판정 = (a) miss 후 즉시 종료 0건 (b) **폴백 무력화 발생** (c) SPENT_FAIL
종료 0건.

## 4. 결과

**V2 (boxed 17판)**: 실 resolver = **침투 0.000 · 무력화 1.000** — 대역 밖
(0.294 / 0.235 초과). 분해: 거부권 0건, Pk 실패 0건, **12판은 프로토타입과 같은
event 같은 스텝(±1), 5판은 swept 단독 검출** — 그 5판이 프로토타입 침투 0.235
의 전부였다. kill 의 선분 최소거리 분포 0.056~0.748; 선분 근사 오차 상한
`a_rel·dt²/8 ≈ 0.033 m` 기준 경계 여유가 그 안인 kill 은 **2/17** (0.019,
0.013). → **"swept 축 전량 귀속, 방향 재현 인정"** 으로 판정했다.

**V3 (boxed 17판, 실 계약 arm)**: 침투 0.000·무력화 1.000 (V2 와 ±0.15 내).
그러나 **net_spent 0/17 — miss 가 한 판도 없었다.** 접촉 kill 이 net 해소(수
스텝)보다 항상 빨랐다. (b)는 이 표본에서 **처치 비활성 = 검정 불가**로 기록.

**V3b (재사전등록 후 실행, miss 가 실재하는 표본 n=100×2)**:

```
hold       SPENT_FAIL종료 0 · net_spent 7 · miss후 무력화 0/7 (전부 침투)
intercept  SPENT_FAIL종료 0 · net_spent 7 · miss후 무력화 0/7 (전부 침투)
```

miss 7판에서 공격자 궤적이 두 팔에서 **동일**했다 (limiter 가 반발 반경 1 m
밖 — 영향 0). miss 시점 간격 8–11 m, intercept 폴백은 침투까지 10.9→6.8 m 이
최선. "꼬리 추격 기하"로 기록하고, 폴백 국면의 요격 가능 **상한**은 oracle
비교 전 미판정으로 남겼다.

회귀: 기본값(두 플래그 off)에서 hold 기준선 n=500 이 변경 전/후 JSON **비트
동일**, 전체 테스트 474/474.

## 5. 우리의 해석 (공격 대상)

1. V2 대역 이탈은 실패가 아니라 **측정기 교정**이다 — 프로토타입의 0.706/0.235
   는 endpoint 검출의 산물이었고, 실 계약(swept)이 참에 더 가깝다.
2. R1 은 학습 편의 조정이 아니라 **누락된 event semantics 복구**다.
3. R2 국면 전환은 검증됐고, 폴백 무력화 0/7 은 구현 결함이 아니라 **폴백
   국면의 전술 난이도** 신호다.
4. boxed 상태의 무력화 1.000 (Pk=1) 은 17판·단일 공격자·intercept arm 한정
   측정이지 포획확률 일반화가 아니다 — 라고 스스로 제한했다.

## 6. 무너뜨려 볼 주장

**주장 1 — "대역 밖이지만 사전등록 위반이 아니다."** 수락대역과 "축으로
설명되면 인정" 조항이 같은 문서에 공존한다. 이 조항이 있으면 대역은 사실상
무의미한 장식 아닌가? 어떤 결과가 나왔어야 "방향 재현 실패"로 판정됐겠는가 —
반증 가능성이 남아 있었는지 답하라.

**주장 2 — "swept 가 endpoint 보다 참에 가깝다."** 선분 근사는 곡선 경로의
안쪽/바깥쪽 어느 쪽으로도 틀릴 수 있다. 우리는 오차 상한 0.033 m 로 15/17 이
강건하다고 했다. 이 상한 유도(등가속 상대운동의 chord 편차 `a·dt²/8`)가 이
백엔드에 실제로 적용되는지, 그리고 "경계 여유 > 상한 ⇒ 강건" 논법에 구멍이
있는지 검사하라. 특히 **접촉 즉시 해소 vs 커밋 경로의 tau_kill 지연** 비대칭이
"같은 확률 모형 재사용" 주장과 충돌하는지.

**주장 3 — "접촉 Pk = 커밋 Pk 재사용은 보수적 선택이다."** 관통 접촉과 예측
요격의 무력화 확률이 같다는 물리 근거는 없다고 우리도 명시했다. 그런데 V2/V3
는 전부 Pk=1 에서 돌았다 — 이 한계 명시가 실제 결론(무력화 1.000)의 신뢰도를
얼마나 깎아야 하는가? Pk sweep 없이 이 수치를 문서에 남겨도 되는가?

**주장 4 — "폴백 무력화 0/7 은 전술 난이도 신호다."** 대안 설명을 나열하라:
(i) miss 판의 selection (miss 가 나는 판 = 이미 지나친 기하), (ii) scripted
폴백이 약한 straw man, (iii) miss 시점이 너무 늦도록 fire gate 가 설계됨,
(iv) n=7 이 아무 결론도 지지하지 못함. 우리가 "oracle 3-way 로 이관"이라고
쓴 것이 이 대안들을 덮는 데 충분한가, 아니면 지금 당장 더 싼 반증 실험이
있는가?

## 7. 답변 형식

각 주장에 대해: **[유지 / 조건부 유지 / 기각]** + 근거 2~3문장 + (있다면)
우리가 다음에 돌려야 할 가장 싼 반증 실험 1개. 마지막에 "이 세션에서 가장
위험한 미검증 가정 1개"를 골라라.
