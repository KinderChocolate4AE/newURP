# 외부 리뷰 요청 5 — 위협 계약 v3 (반응형 공격자·게이트·분포 설계)

> 그대로 붙여 넣어 쓴다. 리뷰어는 리포·이전 대화 접근이 없으므로 자기완결적으로 썼다.

---

당신은 다중 에이전트 강화학습 논문의 **비판적 외부 리뷰어**다. 우리는 하루
만에 위협 계약 v3 를 설계→4차 비준→배선→게이트 5종 전판 통과→행동 sanity
(V6/V7)까지 완주했고, 이제 학습용 위협 분포(docs/61)를 동결하려 한다.
**전부 green 인 하루는 그 자체로 의심스럽다.** 이번 요청의 핵심:

> **게이트들이 쉬워서 통과한 것인가, 주장이 약해서 통과한 것인가,
> 아니면 정말 검증된 것인가?**

동의해 주는 답은 쓸모가 없다. §5 의 주장 일곱을 각각 무너뜨려 봐라.

## 1. 시스템 (요약)

무인기 last-mile 방어 시뮬레이션 (3D 질점 동역학, dt 0.05 s):

- **공격자 1기** (scripted): 표적(원점) 정조준 전진 P-drive + 횡 jink 진동
  (0.6×a_lat, 1.5 Hz) + 횡속도 감쇠(homing 4.0 /s) + 접촉 반발(1.125 m).
  능력: 속도 8–30 m/s 브래킷, 가속 11–78 m/s², v_max = 1.5×순항속도 (선언됨,
  종전엔 행동이 안 씀). 스폰 250–350 m, 방위 ±45°.
- **limiter 4기**: 자산 주위 12 m 4방위 대칭 standby (φ₀~U[0,π/2) 랜덤),
  **현재 전 실험에서 부동(hold)**. kill_radius 0.75 m — 반경 진입 시
  Bernoulli(Pk=1) 요격, 단 자산 6 m 안(no-kinetic zone)에서는 금지.
- **finisher 1기**: 위치 고정 (2,0,0), 그물 1발, 발사 gate 는 도달가능집합
  포함률 v_shot ≥ 0.9.
- 좌표: 표적 z=0 수평면에 standby·finisher 전부, 공격자만 스폰 ±5 m z 지터.

**배경**: 종전 공격자(A2)는 limiter 를 0.75 m 접촉 전까지 완전히 무시했다
— 조작 실험(P84)으로 "0.75 m 밖 limiter 배치는 공격자 궤적에 인과효과 0"
이 42/42 bit-동일로 확정됐고, 따라서 원 연구 질문(limiter 협력 기동으로
공격자를 포획 가능 상태로 유도 = shepherding)이 **검정 불가능**했다. v3 의
목적 = 공격자를 어렵게 만드는 것이 아니라 **causal channel 을 추가해 그
질문을 검정 가능하게 만드는 것.**

## 2. v3 에서 추가한 것 (전부 기본 off = 기존과 bit-동일, NESTING)

1. **횡 반응성 (angular-gap)**: 감지 반경 30 m 안 전방 limiter 들을 진행축
   수직 평면에 사영, 각 limiter 가 가리는 각도 구간(반각 asin(r_block/횡거리),
   r_block = 기존 반발 반경 1.125 m 재사용 — "물리 동일성 주장이 아니라 신규
   자유도를 안 만들기 위한 nominal 선택"으로 명시)을 합집합하고 **가장 넓은
   빈 호의 중앙으로 route_gain 0.5×a_lat 횡가속.** 명칭을 "instantaneous
   transverse angular-gap heuristic" 으로 제한 (종축 거리는 반각에 안 들어감
   — physical widest escape gap 이 아니라고 명시). 동률 tie-break = 횡속도
   bearing 근접 → 세계 +z 선호 → 각도 (1e-9 양자화).
2. **종축 속도 프로파일**: 60–90 m 에서 v_ref = 0.5×순항 (slowdown),
   ≤60 m 에서 v_ref = v_max (sprint). "발사 gate 를 기만한다"는 서사는
   금지해 뒀다 (gate 의 도달가능집합은 가속 유계라 스프린트 가능성이 이미
   샘플 안에 있음).
3. **스폰 방위 ±45° + bearing-독립 standby**: "ring 을 스폰 방위에 회전
   정렬"안은 기각 (문제를 환경이 대신 풀어줌) — 대신 위처럼 대칭 standby,
   위협 방위 대응 재배치는 정책의 몫. 탐지 가정 명시: "bearing 은 에피소드
   시작 시 알려져 있다."
4. **가속도 budget 계약**: 종축·jink·route 가 단일 |a|≤a_max 를 경쟁 —
   클리핑 상호작용은 결함이 아니라 위협 계약의 일부로 명문화.

## 3. 게이트 결과 (판정식은 결과 전 커밋 — git 이력 있음)

```
P87  NESTING bit-동일 (배선 전 커밋 golden 대조): PASS
P88  방향성 조작 게이트, 7판 × 5항 전부 PASS:
     a) 좌우 mirror limiter 배치 -> 공격자 횡가속차 부호 반전
     b) 가속차 방향이 angular-gap 예측과 일치 (cos > 0.7)
     c) 감지 안·접촉 밖 배치 변화 -> 궤적 발산 (종전 42/42 불변의 역전)
     d) 감지 밖 배치끼리 bit-동일
     e) 접촉 안 positive control 즉시 발산
     (배치는 checkpoint 시점 공격자 기준 teleport 구성 -- 자연 발생 배치 아님)
P89  능력 준수 PASS (전 스텝 |v|/v_max ≤ 1.0000). saturation 실측:
     sprint 구간 클립 36% 평균(최대 76%), route 실현/요청 = 0.53
     -> "축 독립" 주장 기각, budget 계약으로 명문화, route_gain 0.5 유지
     ("포화를 덜 보이게 값을 내리면 사후 튜닝" 논리)
P90  무방어 침투 보존: 100/100 PENETRATED, 절단 0
P91a 장면 전체 z-회전 공변성 (finisher 포함): dyn ~1e-13, v_shot 0.000, PASS
P91b bearing ±0.5 mirror 대칭: 1차 FAIL (dev 2.42 m) -> 원인 = 공면 퇴화에서
     ±z 동률 빈 호를 리스트 순서로 분기 (tie-break 비공변) -> 거동 정의를
     "세계 +z 선호 + 1e-9 양자화"로 **교정 재선언** 후 재실행 PASS (8.9e-16).
     정당화: route 는 어떤 기존 결과에도 기여한 적 없음 (항상 off 였음)
```

행동 sanity (V6, 3 nested arm × n=100, 수비 부동·수락대역 없음): 침투/포획
= 85/15·87/13·87/13 (v2 무반응 공격자와 근사). route 활성 스텝 11–17%
(100/100 판). 공격자 z 이탈 최대 8–23 m. 뷰어 육안(V7): "위로 뜨는 움직임은
net 회피 후 관성으로 판독 — route 의 z 요청(활성 스텝의 51–81%)이 실현
기전이라는 증거 아님" 으로 해석을 **하향 정정**해 뒀다. route 인과 귀속
paired ablation (동일 seed, route on/off) 은 **미실시.**

## 4. 이제 동결하려는 것 — 학습용 위협 분포 (docs/61 초안)

- 3×3 stratification: 반응성 {weak 0.2–0.4/15–25 · med 0.4–0.6/25–35 ·
  strong 0.6–0.8/35–45 (route_gain/sense m)} × 속도 {cruise · sprint
  40–80 m · sprint+slowdown(near=sprint, far=near+20–40, frac 0.4–0.8)},
  9셀 균등, 셀 내 uniform. 능력 브래킷(8–30/11–78)과 곱.
- IID = 동일 분포·seed namespace 분리. OOD 4종 = −z tie-break / CPA 회피
  교체 / sprint 90–130 (분포 밖 타이밍) / route 1.0·sense 60 (box 밖).
- 평가 = E[J] (포획·무력화·침투율) + 최악 셀 penetration (9셀×regime) +
  CVaR_0.1 limiter 손실, paired CRN, headline = hold vs scripted vs MARL
  **분포 전체 위** 비교. "이겼다" = E[J] 개선 ∧ 최악 셀 비열화 동시.
- 범위 근거: 전부 외부 앵커 없는 선언 (문헌에 FPV 회피 gain 같은 건 없다).
  sanity 결과(V6)로 범위를 조정하지 않았다고 주장한다.

## 5. 무너뜨려 볼 주장들

1. **"P88 통과 = defender geometry → attacker action 의 방향성 causal
   channel 개통"** — teleport 로 구성한 배치 5종에서의 판정이다. 자연 발생
   배치 분포(standby 부동 4기)에서 route 활성이 스텝 11–17%에 불과하고
   봉쇄 반각이 수 도(°) 수준인데, 이 channel 이 학습이 실제로 잡을 수 있는
   크기인가? "channel 존재"와 "channel 이 학습 가능한 신호"의 간극을 지적하라.
2. **"P91b 의 tie-break 교정은 소급 변경이 아니다"** — 게이트 FAIL 을 보고
   거동 정의를 고쳐 재실행해 PASS 를 얻었다. "route 는 결과에 기여한 적
   없음" 정당화가 충분한가? 이런 교정-재선언이 허용되는 경계는 어디인가?
3. **"P89: budget 공유는 결함이 아니라 계약"** — 포화 실측(스프린트 구간
   클립 36–76%) 후에 이를 계약으로 명문화했다. "결함의 계약화" 아닌가?
   특히 스프린트 구간에서 반응성이 절반으로 죽는 공격자를 "반응형" 이라
   부를 수 있는가?
4. **"V6 = sanity 통과"** — 수비가 부동인데 포획이 13–15% 나온다 (그물
   발사만으로). 반응형 공격자가 무반응 공격자와 거의 같은 라벨 분포(85/15
   vs 87/13)를 낸다면, v3 가 실질적으로 바꾼 것이 있는가? "라벨 불변 =
   sanity" 해석과 "라벨 불변 = 신규 축 무의미" 해석을 어떻게 구분하나?
5. **angular-gap 의 종축 소거** — 2 m 앞 limiter 와 25 m 앞 limiter 가
   같은 횡거리면 같은 각을 막는다. 이 heuristic 이 열어주는 channel 이
   "limiter 배치로 공격자를 유도한다"는 원 질문의 검정에 충분한 모형인가,
   아니면 너무 조악해서 학습이 이 규칙의 결함(예: 종축 무시)만 착취하게
   되는가?
6. **분포 설계 (docs/61)** — (i) 9셀 균등이 "최소 가정" 이라는 주장,
   (ii) 셀 경계·범위가 V6 결과와 정말 독립인가 (nominal 0.5/30 이 medium
   중앙에 오도록 잡은 것 자체가 nominal 중심 설계 아닌가), (iii) 평가
   판정식 "E[J] 개선 ∧ 최악 셀 비열화" 가 게이밍 가능한가 (예: 최악 셀만
   방어하는 정책), (iv) OOD 4종이 "scripted 취약점 암기" 반증에 충분한가.
7. **미실시 목록의 위험도 순위를 매겨라** — route 인과 paired ablation ·
   수직 접근 위협 (스폰이 수평 섹터뿐) · detection 불확실성 (bearing 기지
   가정) · A2 상속값(jink 0.6 등) TRAIN 고정 · scripted 재배치 baseline
   미설계 · slowdown 기전 micro-test. 이 중 **학습 결과가 나온 뒤에 발견하면
   가장 뼈아픈 것**이 무엇인가?

## 6. 요청 형식

- 주장 1~7 각각: **유지 / 조건부 유지 / 기각** + 핵심 이유 (2–3문장).
- **최위험 미검증 가정 1개 지정** (우리 서사 전체가 그것에 의존하는 것).
- docs/61 을 이대로 동결하면 안 되는 이유가 있으면 **동결 전 수정 최소
  목록** (3개 이하 — 전면 재설계 제안은 받지 않는다. 그건 우리가 스스로
  결정할 몫이다).
- 동의는 필요 없다. 우리가 놓친 반례·교락·게이밍 경로가 필요하다.
