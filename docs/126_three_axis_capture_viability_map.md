## 1. 상위 목표 (Paper 1 서사)

**worst-case 회피자 상대 net 포획의 가능 영역을 (① net 물리 × ② 협력 × ③ 회피자 기동 충실도)
공간에서 해석적 경계 + 실측 지도로 긋는다.** 보조 주장:
- (귀속) 협력 (limiter-control opportunity) 의 기여는 승률이 아니라 **탈출 집합 축소량** 으로
  귀속한다 (기전 수준).
- (방법론) 모든 방어 주장은 **전용 착취자 감사** (분포-상대 학습 exploiter, 고정 예산) 를 통과한
  수치로만 한다.

정합성: 연구 정체성 판정 (9/7) 의 기여 서열 ①②③ 과 동형. E7 = 원계획 Fig 6 (net spec sweep),
머니피규어 = Fig 5 (speed×maneuver, E3 에서 평평 확인) → **ρ vs ceiling 곡선** 으로 이동.
교수 요구 ("숫자": 요격 확률 vs 사양) 직결. **K1 손증명 (≤10/31) = ③·ρ 의 해석 경계와 같은 수학.**

**ρ 가설 (사전 등록 예측 지위 — 단정 금지)**: 발사 tick no-escape 성립은 1차적으로 무차원비
**ρ = (표류거리 콘 단면 반경) / (회피 종점 구 반경 ½aτ²)** ≈ 1.5/0.92 ≈ **1.6** 이 지배하고,
μ·ν 는 이 비에 등장하지 않는다.
- 유보 (main): E3 평면의 평평함은 고정-scripted 암기 교란과 미분리 — "구조적 이유" 단정은 아직
  불가. **phase 2 정본 판정 (학습 방어) 이 ρ 가설의 첫 비자명 검정**: 학습도 바닥 → 지지,
  열림 → ρ 단독 지배 기각.
- 검정 경로: E6/K1 이 ρ 경계를 **독립 유도** → E7 실측 곡선과 대조 (머니 커브).

## 4. 실험 프로그램 (순서·게이트)

### P0 — 충실도·조건부 프로브 (하룻밤, 학습 없음, phase-2 harvest 후 착수)
- **P0a (③축 1점)**: `attacker_turn_limited` witness (omega_att_max — dead param 소생) 로 창 크기
  재측정. **판정-모델 변형 선언 필수**: 기존 수치와 pooling 금지, 비등방 witness 는 별도 계보.
  사전 선언 기준: **창 중앙값 ≥ 4 step (0.2 s) → ③축 유효** ("net 보강 없이 학습 가능 영역" 후보).
- **P0b (창 감지 가능성)**: 창 열림 tick 의 상태 특징 (거리·접근속도·limiter 기하·p_feasible)
  로지스틱 회귀 — AUC 높음 → arm C-① 충분 / 낮음 → 창 생성 비중↑. 기존 수확 궤적 재사용.

### phase 2.5 — arm C / arm D (phase 2 정본 판정 후, 별도 봉인)
- **arm C-① 판정기-증류 발사 머리**: 전 궤적 매 tick "지금 발사 시 포획?" 라벨 (JAX) → 발사 채널
  지도학습. **oracle-증류 명찰**: 주장은 "증류로 창 감지가 가능하다" (capability) 까지 — 창발 아님.
- **C-② (coma_D / Δv_shot_soft shaping) = 측정 먼저**: C-① run 에 limiter 별 탈출 집합 축소량을
  **로그로 공짜 탑재** (보조 주장 1 의 데이터는 보상 없이 나옴). 보상 승격은 그 로그가 기울기
  부재를 보일 때만 별도 심사 (dense 조형 기각-보류 지위 승계).
- **arm D 이력 조건화** (프레임 스택 우선): 투입 조건 = arm C 후에도 감사 ~97%+ 관통.
  판정 지표 = 착취자 학습 곡선 (0.05→0.99 서명의 완화).

### E7 — ①축 sweep (다음 장, 새 세계 계약)
- 손잡이: τ_deploy·θ_cone·range 2~3점 축소 격자 + 1단 예측 조준 (등속 외삽 → 기동한계-인지).
  FRPN식 캐리어 종말유도는 2단 보류. 판정 보수성 완화는 축 후보로 병기하되 기본 의미론
  (보장-포획 하한) 유지 — 정직성 자산.
- **1차 산출물 = ρ vs ceiling_s 곡선 (전용 착취자 감사 기준) + E6 해석 경계 겹쳐 그리기 = 머니 커브.**
- 각 변형은 학습 전 1.5a 프로브로 창 크기 선측정 (학습 예산 절약 프로토콜).
- P0a 결과에 따라 ③축을 E7 격자에 포함할지 결정.

### 게이트 사슬
P0 → [phase 2 정본 판정] → arm C (P0b 가 ①/② 배분 결정) → 착취자 감사 → (조건부) arm D →
E7 계약 (P0a 반영). 각 단계 봉인·기준 선언 = main, 결과 전 봉인 규율 불변.
