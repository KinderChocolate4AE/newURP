## 1. 프로토콜 (학습 없음, E4 rollout 그대로)

m0.35_n1, 구세계 적응 공격자 4 × 24 ep, SEED0 268000, 발사 금지, 변형별 포탑 slew 시뮬레이션 (cv), 창 = LOADED ∧ d ≤ 16 m.
`scripts/fs1_e7_probe.py --grid e9`. R 은 바꾸지 않으므로 16 m 창 경계는 비구속 (E4 기준점과 동일).

- **L**: 조준점 = t−L 상태의 지연 보상 외삽 nc = p(t−L) + v(t−L)(τ+L). 포탑은 그쪽으로 slew. 판정은 **참 현재 상태**와 참 τ·a·θ.
- **δ**: 판정 콘 축 = slew 축을 δ 만큼 episode 별 무작위 방향 φ ~ U[0, 2π) 로 기울인 축 (RNG [290000, ep], rollout 전역 RNG 와 분리).
  slew 자체는 무편향.
- **참조 셀**: 같은 χ_eff 를 이상 판정 인자로 — a × ((τ+L)/τ)² 및/또는 θ × (θ0−δ)/θ0, 신선한 조준, 오프셋 없음.

## 2. 격자 (44 변형, 값은 manifest)

기준점 4 = E4 τ 계열 (χ 0.520 / 0.340 / 0.255 / 0.130; 이름 동일) × {L 1·2 tick (0.05·0.10 s), δ 0.02·0.05 rad, 결합 L 0.05 s + δ 0.02}
× (비이상 셀 + 참조 셀). χ_eff 범위 0.13–0.92 (χ\*_geom 0.808 을 걸침).

## 3. 사전 예측

- **최악 논거**: 낡은 상태 편차 ≤ aL(τ + L/2) → 필요 반경 ≤ ½a(τ+L)². 반각 θ 콘을 δ 기울이면 동축 θ−δ 콘을 포함. 둘 다 참조 셀이
  하한 → **예측 gap = 창(비이상) − 창(참조) ≥ 0**.
- **P-E9 접힘** (가족 L, d, Ld 각각): 셀 통과 = 창 ≥ 창(참조) − 1.5 tick (E4 허용 승계). 정보 셀 = max(창, 창(참조)) ≥ 1.
  정보 셀 < 셀 수의 절반 → `FOLD_UNDECIDABLE_FLOOR` · 정보 셀 전부 통과 → `FOLD_CONSERVATIVE` · 하나라도 실패 → `FOLD_BREAKS`.
- **라벨 뜻 (§6 규율)**: `FOLD_CONSERVATIVE` = "이 프로브·이 공격자에서 접힘 규칙이 창을 과대 예측하지 않음". 접힘이 **정확**하다는
  뜻이 아니다 (gap 크기는 보고). `FOLD_BREAKS` ≠ χ 이론 반증 — 접힘 규칙의 실패.
- **보고 전용**: gap 분포 (보수성 크기), 기준점별 L·δ 단조성, χ_eff 에서의 E4 공식 N_pred.

## 5. τ_r (회피 반응 지연) — 해석으로 답함, 실행 없음

판정 수준의 τ_r 은 도달 변위 ½a(τ−τ_r)² = a 를 (1−τ_r/τ)² 배 한 것과 같다. E4 a 계열 (0.654 / 0.49 / 0.25 = τ 0.3 에서
τ_r ≈ 0.057 / 0.09 / 0.15 s) 은 같은 ρ 의 τ 계열과 창이 일치했다 (4 = 4, 4 = 4, 4 vs 5). → τ_r 은 χ_eff = a(τ−τ_r)²/(2ρ) 로 접힌다
(프로브 층). 발사를 **관측하고** 반응하는 행동 수준 τ_r 은 학습 층 질문 — 범위 밖.
