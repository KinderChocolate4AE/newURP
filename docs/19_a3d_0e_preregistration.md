## 0. 판단 요청 요약

신규 결정은 **[D-1]~[D-5] 5건**이며 나머지는 전부 기존 비준 사양(docs/18 v0.2 RATIFIED — 귀하의 5/5 수정승인 + Hyunjun 확정, Gate B 지위 = (ii))의 수치 대입이다. 각 D-슬롯에 승인/수정 판정을 부탁한다: **[D-1]** Gate B family 8멤버 확정 / **[D-2]** v0 후보 선택 = first-fit 구속 / **[D-3]** admissibility 독립 validation 설계(n=100·seed·판정식) / **[D-4]** V-5′ δ_min = 0.10 + 스테이지 exit 유도식 / **[D-5]** 번들 v2 계획. 추가로: ⑥ 본 패키지가 기존 비준 사양과 충돌하는 곳 ⑦ 사전등록에서 빠진 자유도.

## 1. 최소 배경 (직전 리뷰와 동일 세팅 — 요약 재수록)

- **게임**: 방어 리미터 N=4(가속 제어, ‖a‖≤30) + 1회 발사 finisher + 스크립트 공격자(정속 직진 추격 + 반응 회피). clean = 발사 판정 게이트 v_soft ≥ θ=0.9 ∧ 실행가능성>0 (2000-표본 MC, CRN seed 의존 — "면도날" 술어). 판정 보상·게이트·평가 경로 = 동결.
- **SBE**: witness(clean 성립 종말 상태)에서 t−k(k∈{1,2,4,8} = 스테이지 d1..d4)로 폐형식 감속-도착 프로파일을 후방 합성해 스폰(속도 주입). Δt=0.05, v0 ~ U[0.3,0.8]·30kΔt, 콘 ±15°, 스폰 오프셋 R = v0Δt(k−1)/2, zero-coast 오버슛 O = v0Δt(k+1)/2 (귀하가 지적한 k=1 2× 표 오류는 정정·테스트 락).
- **witness 3가족**(공격자 속도) = v16 / v20 / v24, 각 1본. **bank v2의 정의(귀하 재정의 채택) = action-necessary, forward-verified, observation-realizable predecessor synthesis.**

## 3. 비준 이후 실행 기록 (전부 커밋·재현 가능; 새 결정 없음 — 비준 사양의 기계적 이행)

### 3.1 측정기 구현 + 귀하의 필수 항목 이행 결과

- **PFC**(구 demo_cl; `shepherd/train/pfc.py`): a = clip(a_demo + K_p(p_ref−p) + K_d(v_ref−v), ‖a‖≤30), **무차원 게인** K_p = c_p/T_k², K_d = c_d/T_k (귀하 채택안). 참조 = bank 엔트리 **명목** 스폰의 데모 적분 — 동역학이 결정론이라 개방루프는 스폰 지터를 그대로 보존하고, PFC의 가치는 명목 참조 추적으로 그 지터를 상쇄하는 것(테스트 락: 무지터 시 PFC ≡ demo 항등 / σ0.02급 지터에서 endpoint 오차 < 0.6·|δ|).
- **귀하의 필수 정정 1 잔여 항목 이행**: ① 폐형식 R·O unit test 추가(k∈{1,2,4,8}×{v0 하한·상한} 적분기 복제와 정확 일치, k=1 정정값 명시 락) ② **zero-coast env rollout trace 대조 PASS** — 실제 env 경로에서 reset 후 k+2 스텝 전 구간 limiter 위치 == p₀+j·v₀·Δt (atol 5e-4) = "스폰→t=0 사이 정확히 k회 이동" 시간 인덱스 계약 실측 확인. **귀하의 "k+1회면 식 재기술" 분기는 불발**(bank 스크립트 k회 이동과 정합).
- Gate B 프로토타입(brake·λ-brake·attpd) = 생성자 시그니처 수준에서 특권 인자 금지(구조 락). 테스트 +17, 인접 회귀 66 green.

## 4. [D-1] Gate B family 확정 (8멤버, 이후 변경 금지)

- ① brake = −30·unit(v_i) (기존 경쟁선 겸용) ② **λ-brake** a = −λv_i, λ ∈ {2, 5, 10, 20} — 시정수 1/λ ∈ {0.5, 0.2, 0.1, 0.05}s가 사다리 호라이즌 T_k ∈ {0.05..0.4}s를 커버 ③ **attpd**(공격자-상대 리드 타깃 PD; obs의 공격자 상태만 사용, witness 좌표·데모·k 라벨 = 구조적 사용 불가) (k_p, k_d, d_lead) ∈ {(2,3,1.0), (4,4,1.0), (8,6,1.0)} — 근사 임계감쇠 계열(ζ≈1), 고유주파수 √k_p ∈ {1.4, 2, 2.8} rad/s.
- 운용: 전 셀 기록 의무(GateB_best + PFC와의 격차), **obs-hard 경고 문턱 = PFC − GateB_best > 0.4**(docs/18 예시값 채택). 지위 = 비준 (ii). 리스크 자기신고: family가 클수록 best-of가 위로 밀려 경고가 줄어드는 방향 — 8멤버는 유한·사전 고정이며 각 멤버가 진짜 obs-전용 컨트롤러이므로 "존재 증명"으로서 정당하나, 멤버 추가는 금지로 못박는다.

## 5. [D-2] v0 후보 선택 규칙 = first-fit 확정

- 후보 grid(셀 공통) = {U[0.3,0.8](= v1 분포), U[0.5,0.8], U[0.15,0.5]}, try-순서 고정. **first-fit**: 최소 수록 8을 달성하는 첫 후보 채택(후보 0 = v1 분포 = 비준의 "v1 최근접 tie-break"를 try-순서로 실현). argmax(전 후보 실행 후 max(p̂_PFC−p̂_zero)) 모드는 코드에 있으나 **구속 규칙에서 폐기**.
- 근거: ① 선택 자유도 최소화(후보 간 목적함수 차이는 screen 잡음 수준일 가능성 — 그걸 고르는 것 자체가 사후 최적화 표면) ② 최종 판정은 §6 독립 validation이 담당하므로 생성 단계 목적함수 최적화가 불필요 ③ 계산 1/3. 대안(argmax)을 선호하시면 그 사유와 함께 수정 판정 바람.

## 6. [D-3] admissibility 독립 validation

- **validation 세트**: 생성·수록된 각 셀에서 **에피소드 100판** — bank v2 draw에서 **스테이지 σ를 물질화**(번들과 동일 기제; 지터 rng base 76,000)한 스폰 + reset seed **600–699**(신규 예약, 전 대역 서로소). σ 물질화이므로 여기서는 PFC ≠ demo(폐루프 가치·σ-강건성이 실측됨).
- arms = zero / random / brake / demo-open / **PFC** / Gate B 8종. **판정 = LCB95(paired Δ = PFC − zero) > ε = 0.4**(동일 seed 짝지음, LCB = 에피소드 부트스트랩 10,000회·rng 777). 미달 셀 = C 제외. **이후 생성식·문턱 재조정 금지.**
- 파워 스케치(n=100): 진짜 (PFC, zero) = (.85, .05) → LCB ≈ .71 / (.80, .15) → ≈ .56 / (.70, .20) → ≈ .40 경계. 즉 ε=.4 통과에는 실질 Δ ≳ .5 필요 — screen(.8/.2) 통과 셀의 기대 Δ ≈ .6+이므로 건강 셀은 여유, 경계 셀은 자연 탈락. point 문턱 .8/.2는 screen 전용 서술(n=20 CP 한계 문서화 완료). 추론 단위: admissibility = episode / 학습 판정 = training seed(혼합 금지).

## 7. [D-4] V-5′ 최종형 + 스테이지 exit 유도식

- **V-5′(학습 성공 판정)**: 동일 게이팅 번들·동일 ep **paired contrast arr(π) − arr(zero)**, 주검정 = exact **McNemar 단측** + Δ CI(부트스트랩 10k·rng 777), **δ_min = 0.10**. 근거: 게이트 eval 80판에서 0.05는 4판 차이 = 이산 카운트 잡음 경계이고, draw-필터가 zero 바닥을 눌러둔 상태라 실질 증분 여유가 있음 — 귀하의 "무의미한 작은 차이의 유의화" 경고에 대한 보수적 응답. (대안 0.05를 선호하시면 수정 판정 바람.) 무행동 컨트롤 = 상설 무결성 게이트, competence 리그(zero/brake/demo/PFC/GateB) 분리 보고, 2-tier 클레임(mechanistic vs method) 유지, 추론 단위 = training seed, 8항 사전 체크리스트 학습 전 필수, 하드 스톱 불변.
- **스테이지 exit 유도식**: exit_d = **UCB95(zero_d; §6 validation) + δ_min**. zero는 정책-무관 상수라 학습 중 재실행 불요. 공식은 지금 동결, 숫자는 validation 직후 **부록 A로 기계 대입 커밋**(결과 보고 조정이 아님 — 대입만).

## 8. [D-5] 번들 계획

- **dev-v1·sealed-v1 = 구조 변경으로 폐기 기록**(bank v1 스폰 물질화본; 파일 보존·삭제 금지, 이후 어떤 판정에도 미사용). tune 번들 = 게인 선정 전용 소임 종료.
- bank v2 동결 후: **dev-v2 = {rng 75,000, seed 12.0M} / sealed-v2 = {rng 95,000, seed 13.0M}**(균형 물질화, 전 대역 서로소). sealed-v2 = 생성 즉시 md5 해시 로그 기록, Phase 2 확증 전 롤 금지(러너 거부 유지).

## 9. σ 평가 grid + seed 대장

- **σ(0d-5 비준 이행)**: 학습 램프 불변(d0 0 / d1 .005 / d2 .01 / d3 .015 / d4 .02). 최종 평가 = 전 스테이지 × **{배정σ, 공통 0.005}** 필수 [+ {0, .02} 여유 시], 전 arm + learned policy. 진단 전용(사후 σ 선택 금지). d4 = robust-마진 계측지.
- **seed 대장(전 가족)**: 0–9 학습 / 7–16 robust 게이트 union / 61–65·71–75 Φ / 100–104·200–209 witness 탐색·검증 union / **300–319 재리파인 screen** / **400–419 생성 screen** / **600–699 validation [신규]** / 500k·1.5M·2.5M eval 가족 / 7.0M dev-v1 · 8.0M tune · 9.0M sealed-v1 / **12.0M dev-v2 · 13.0M sealed-v2 [신규]** / 31M fire-oracle. rng 스트림: 23(probe)·23k+k(재리파인 draw)·**47k대(생성 draw)**·71k/81k/93k(+**75k/95k/76k 신규**: dev-v2/sealed-v2/validation 지터)·90k+7ep(random arm)·**777(부트스트랩)**.

## 10. 자기신고

① 작성자 = 설계·실행 참여자(이해충돌). ② §3의 dev/tune 수치는 30·10판 point(SE .07–.15) — 워크플로 라우팅용이며 구속 판정은 §6 validation. ③ v24 3셀의 PFC .80은 문턱 정확 접촉 — validation에서 흔들릴 수 있고, draw-필터가 모집단을 바꾸므로 그대로 이월되지 않음. ④ screen의 PFC ≡ demo 항등(무지터; §3.6) — screen 명칭에 오해 소지가 있어 명시. ⑤ (bbb) 재리파인의 rng 스트림 차이(§3.4 캐비앗). ⑥ 스모크(v16/d1)는 정보-무해 셀 선택이었으나 400–419 대역 결과를 먼저 본 것은 사실(단일 셀·기지 결과 재현 한정). ⑦ Gate B 멤버 수치(λ·PD 게인)는 제어이론적 스팬 논리로 선정했으나 실측 근거는 없음 — validation에서 처음 측정됨.

## 11. 출력 형식 (부탁)

[D-1]~[D-5] 각각 ① 승인/수정(수정 시 대안+근거) ② 사전등록 문구 리스크 1줄. 이어서 ⑥ 기존 비준 사양과의 충돌 지점 ⑦ 누락된 자유도(우리가 결과를 보고 고를 수 있게 남아 있는 것) ⑧ 총평(이 패키지로 bank v2 1회 생성에 들어가도 되는가). 비준 후 실행 순서: 0-e 동결 커밋 → bank v2 1회 생성(4–7h) → §6 validation → 부록 A(수치 대입) → P1(3-seed, D1→D2 한정).
