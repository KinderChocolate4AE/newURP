## 3. 사전 예측

- **P-E4a collapse**: 변형마다 ν = 창 / N∞(변형), 예측 ν_pred = (1 − ρ₀(θ)/ρ)₊, 잔차 r = ν − ν_pred.
  같은 ρ 묶음 안에서 (max r − min r) × N∞(base) ≤ **1.5 tick** (1 tick + 정수 중앙값 반올림) 이면 묶음 collapse.
  5 묶음 전부 → `COLLAPSE_SUPPORTED`, 3 이상 → `COLLAPSE_PARTIAL`, 그 밖 → `COLLAPSE_NOT_SUPPORTED`.
  공통 편향 (예측이 상한이라 관측이 낮음) 은 허용하고, 계열끼리의 어긋남만 본다.
- **P-E4b 방향**: ρ 2.94 / 3.92 / 7.69 에서 창(a 계열) ≥ 창(τ 계열) 이 3 중 2 이상 → `SUPPORTED`
  (같은 aτ² 에서 slew 부담 aτ ∝ √a, a 계열은 조준 lead vτ 불변).
- **P-E4c 판정 관대함**: ρ < ρ₀ 세 점의 **limiter 없는** robust tick 합 = 0 → `JUDGE_CONSERVATIVE_AT_BOUNDARY`,
  > 0 → `JUDGE_LENIENT` (창 tick 대비 비율 보고). limiter 있는 tick 은 따로 보고 (limiter 의 탈출로 폐쇄는 관대함이 아님).

## 4. 결과의 쓰임 (결과 전 고정)

- COLLAPSE_SUPPORTED → "ρ 는 τ, a, θ, R 방향 모두에서 프로브 창을 1차로 지배한다". 아니면 지배 주장을 collapse 한
  계열로 한정.
- JUDGE_LENIENT → "보장-포획 하한" 서술을 "유한 witness 판정 하의" 로 한정하고 관대함 크기를 보고 (지도교수 10-11).
