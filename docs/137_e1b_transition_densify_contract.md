## 2. 판정 (주 지표 net 하나)
- 끝점 F = d0 seed 중앙값, P = d4 seed 중앙값 (이 계약 안). P − F < 4 → `NO_STEP` (E1 의 오름이 재현 안 됨).
- M = (F + P)/2 를 처음 넘는 (≥) 내부점: d1 → `ONSET_LOW` / d2 → `ONSET_MID` / d3 또는 없음 → `ONSET_HIGH`.
- 층화 bootstrap 2000 (점 안에서 seed 재표집, F·P·M 재계산): 점추정 라벨의 몫 ≥ 0.90 이면 그 라벨, 아니면 `UNRESOLVED`.
- 진단 (판정 아님): 같은 규칙을 rob_fire 에 적용해 라벨이 다르면 `CONVERSION_SENSITIVE` 표시 + 전환율 (net/rob_fire) 표 첨부.
  E1 의 "갈리면 갈래 주장 없음" 규칙은 재사용하지 않는다 (지도교수 10-12: 검정을 다시 무력화).
- 모양은 기술만: (중앙값 − F)/(P − F).
- 예측 (E1 을 본 뒤 세운 가설): 정면 창 3 step (ρ ≈ 2.17) 근처 → `ONSET_MID` 또는 `ONSET_HIGH`.
