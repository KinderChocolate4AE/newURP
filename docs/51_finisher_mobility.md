# 포획기 이동성 요인 실험 — 사전등록

**2026-08-05 · 외부 리뷰(§0) 직후. 결과를 보기 전에 쓴다.**

---

## 0. 왜 이 실험인가

docs/50 §4 를 쓰다가 `finisher` 가 **위치 고정**이라는 것이 한계 절에 빠져
있음을 발견했고, 외부 리뷰에 (A) 이동형 전면 재설계 / (B) 고정 유지 + 한계
서술 / (C) 소규모 요인 실험 중 무엇이냐고 물었다.

리뷰 판정은 **(C)** 였고 핵심 논거는 하나다.

> 현재 데이터는 *"고정 포획기 조건에서 조준이 병목이다"* 를 강하게 지지하지만,
> *"포획기가 움직여도 조준이 병목이다"* 는 **전혀 검증하지 않았다.**

즉 docs/48 §12 의 인과 사슬이 **설계 산물일 위험**이 남아 있다. 포획기가
고정이라 조준 오차를 흡수할 자유도가 없고, 그래서 작은 각오차가 곧바로 원뿔
진입 실패로 증폭된다. 다음 두 설명이 현재 자료와 **모두** 양립한다.

```
(1) 알고리즘 설명   희소한 종말 보상 때문에 RL 이 조준을 학습하지 못했다
(2) 설계 설명       고정 포획기가 조준 오차를 병진으로 보정하지 못하게 만들어,
                    원래는 부분적 결손일 조준 실패를 임무 실패로 증폭했다
```

BC 가 조준을 97 % 회복시킨 것은 (1) 을 강하게 지지하지만 **(2) 를 제거하지
않는다.** 이 실험은 (2) 를 잰다.

### 0.1 비용이 싸다는 것을 먼저 확인했다

백엔드가 **이미 모든 에이전트의 가속을 똑같이 적분한다** (`sim/analytic.py:116`,
`a_cmd = cmd.get("a", zeros(3))`). finisher 가 안 움직이는 이유는 `env.py:332`
가 `np.zeros(3)` 을 넘기는 것 **하나뿐**이다. 재설계가 아니라 배선이다.

**새 RL 런은 0 개다.**

## 1. 요인 (선언)

두 요인 2x2. 기존 정책·체크포인트는 **동결**하고 재학습하지 않는다.

| # | 병진 | 조준·발사 | 무엇을 읽나 |
|---|---|---|---|
| 1 | 고정 | 해석적 | 회귀 기준 — 기존 `hold` 기저선과 **일치해야 한다** |
| 2 | 고정 | 학습 | 기존 조준 결손 재현 |
| 3 | **이동** | **해석적** | ★ **1차** — 이동이 물리적 상한을 올리는가 |
| 4 | 이동 | 학습 | 2차 — 오염됨 (§3.2) |

편대는 네 칸 모두 `hold` 로 고정한다. 이동성 하나만 바꾸는 실험이다.

## 2. 선언값 (결과 보기 전에 고정. 스윕하지 않는다)

### 2.1 `FinisherSpec.a_max`

```
a_max_finisher = a_max_limiter = 15.413...      (기존 선언값 재사용)
```

새 숫자를 만들지 않는다. 그리고 **가장 관대한 값**을 고른 것이 의도적이다 --
§3.3 이 적듯 이 실험의 음성 결과는 하한으로만 읽히므로, 이동에 최대 능력을
줘야 음성이 나왔을 때 그 음성이 강해진다.

목줄(방어 지점 이탈 제한)은 **걸지 않는다.** 같은 이유다. 다만 이동거리를
2차 지표로 반드시 보고한다 -- 포획기가 편대 없이 혼자 요격해 버리면 그건
"이동이 성형 문제를 무의미하게 만든다" 는 별개의 발견이고, 이동거리로만
드러난다.

### 2.2 해석적 병진 제어기

기하가 이걸 결정한다 (실측: `range_min = 0.0`, `range_max = 8.22`,
원뿔 반각 12.15°, `net_radius = 1.77`, 스폰 시 `|p_att − p_fin| = 22.6`).

**최소 사거리가 0 이므로 접근에 하한 제약이 없다.** 그리고 가까울수록 공격자의
실현 가능 회피 집합이 작아져 최악 케이스 포획이 쉬워진다. 따라서 목표점은
예측 그물 중심이다.

```
nc   = p_att + v_att · tau_deploy            (env._net_center 와 같은 함수)
a_f  = clip( k_p (nc − p_f) − k_d v_f ,  |a| <= a_max )
k_p  = 1 / (tau_deploy^2)      k_d = 2 / tau_deploy        (임계감쇠, dt-무관)
```

`k_p`·`k_d` 는 **튜닝 축이 아니다** -- `tau_deploy` 하나로부터 임계감쇠로
유도했다. 값을 찾기 시작하면 §3.3 의 하한 논리가 깨진다.

**이 제어기는 최적이 아니다.** 리뷰어가 제안한 짧은 지평 MPC 가 더 낫겠지만,
여기서 묻는 것은 *"최적 이동이 얼마나 좋은가"* 가 아니라 *"이동이 조금이라도
사슬을 바꾸는가"* 다.

## 3. 판정 (선언)

### 3.1 ★ 1차 지표 — 셀 3 대 셀 1

**해석적 조준에서, 이동이 성형 필요 구간의 비손실 무력화율을 올리는가.**

```
1차   SHAPING_NEEDED 비손실 포획률:  셀3 − 셀1   (paired CRN)
통과  paired 차이의 95 % 하한 > 0
```

리뷰어의 2x2 를 받되 **1차를 해석적 조준 칸으로 옮겼다.** 리뷰어는 결정
규칙 셋 중 둘을 `이동형 + 학습조준`(셀 4)에 얹었는데, 그 칸은 오염돼 있다.

### 3.2 왜 셀 4 를 1차로 못 쓰는가 (리뷰가 놓친 것)

**finisher 의 9차원 상태가 관측에 들어 있다** (교사 축 입력 `p_fin` 이
관측에 있다는 것이 docs/48 §13 의 근거였다). 학습 중 그 블록은
`p = [2,0,0], v = 0` 으로 **상수**였다. 포획기가 움직이면 정책이 **한 번도 본
적 없는 값**을 받는다.

따라서 셀 4 가 나빠도 *"이동이 도움이 안 된다"* 인지 *"정책이 분포 밖에
있다"* 인지 갈리지 않는다. 셀 4 는 **보고만** 하고 판정에 넣지 않는다.

### 3.3 음성 결과는 하한으로만 읽는다 (비대칭)

해석적 병진 제어기의 품질이 자유 파라미터이므로 결론의 강도가 방향에 따라
다르다. **이걸 결과 전에 선언해 둔다.**

```
셀3 > 셀1  (이동이 돕는다)      -> 강하다. 최적도 아닌 제어기로도 나왔다
셀3 ≈ 셀1  (이동이 안 돕는다)   -> 약하다. 더 좋은 제어기면 달랐을 수 있다
                                   "이동 이득의 하한이 0 근처" 로만 적는다
```

### 3.4 분기

| 결과 | 다음 |
|---|---|
| 셀3 > 셀1 **유의** | 고정 가정이 결론을 만들고 있다. **(A) 를 검토**하고 docs/48 사슬의 적용 범위를 좁힌다 |
| 셀3 ≈ 셀1 | (B) 채택. 한계 절에 **이 실험을 근거로** 적는다 — 한 문단 주장이 아니라 측정 |
| 셀3 > 셀1 인데 SHAPING 은 여전히 0 | 이동은 상한을 올리지만 성형 필요 구간은 못 건드린다. 주 결론 유지, 사슬 강도만 약화 |

### 3.5 2차 (보고 전용)

발사 게이트 개방률 · 최소 조준 각오차 · 게이트 체류시간 · 하드킬 비율 ·
**finisher 이동거리** (§2.1) · 전체 무력화율 · FREE/BAND/SHAPING 분해.

`R_move = P(게이트 안 열림 | 고정, 게이트 열림 | 이동)` 도 낸다 -- 단
학습조준 칸에서 계산하면 오염되므로 **해석적 조준에서** 계산한다.

## 6. 무엇을 답하지 못하는가

- **최적 이동이 아니다.** §3.3 의 비대칭 그대로. 음성이면 "이 제어기로는" 이다.
- **셀 4 는 분포 이동에 오염돼 있다** (§3.2). 이동형에서 학습이 어떻게 되는지는
  **재학습해야** 답한다 -- 그게 (A) 이고 이 실험의 범위 밖이다.
- **이동형 교사는 만들지 않는다.** 리뷰어가 정식화가 존재함을 보였지만
  (`r(τ) = (p_a + v_a τ + ½a_a τ²) − (p_f + v_f τ + ½a_f τ²)`), 그건 `a_f` 가
  **알려져 있을 때**다. 정책이 병진까지 고르면 결합 최적화가 되고, docs/49 §1.1
  의 선형 복원(1.65°)이 유지되는지는 미지수다. (A) 로 갈 때 다시 물을 것.
- **목줄 없음** (§2.1). 포획기가 혼자 요격해 버리는 체제도 허용된다. 그건
  이동거리로 드러나며, 드러나면 그 자체가 (A) 에 대한 반대 근거가 된다.

## 8. 결과 (2026-08-05, 해석적 조준 칸 n=500 paired CRN)

### 8.1 회귀 검사 통과

셀 1 이 기존 `hold` 기저선과 **정확히 일치**한다 -- 전체 무력화 0.182,
`SHAPING_NEEDED` 0/297. 배선이 이동 off 에서 아무것도 바꾸지 않았다 (P69·P72).

### 8.2 ★ 1차 판정 — 미달. 이동은 성형 구간을 전혀 못 건드린다

| | 전체 무력화 | 비손실 | SHAPING_NEEDED |
|---|---:|---:|---:|
| 셀 1 고정 | 0.182 | 1.000 | **0/297** |
| 셀 3 이동 | 0.142 | 1.000 | **0/297** |

```
SHAPING_NEEDED   0.0000 -> 0.0000   구제 0 / 망침 0  (n=297 paired)
ALL              0.1820 -> 0.1420   차이 -0.0400  CI95 [-0.0580, -0.0240]
                                    구제 0 / 망침 20 (n=500 paired)
이동거리          경로 6.03 (p90 11.13), 순변위 평균 3.94 최대 6.52
```

포획기는 실제로 움직였다(순변위 평균 3.94, 회랑 규모 대비 작지 않다). 그런데
**297 판 중 단 한 판도 구제되지 않았다.** 그리고 전체로는 **유의하게 나빠졌다**
(20 판을 망쳤고 구제는 0).

### 8.3 왜 나빠졌나 — ★ 기전 **가설**이다 (2026-08-05 리뷰 2 로 하향)

40 판 진단 (슬루 한도 = `omega_max·dt` = 5.73°/스텝):

| | 요구 회전 중앙 | 한도 초과율 | 사거리 중앙 | 게이트 개방률 |
|---|---:|---:|---:|---:|
| 고정 | 5.80° | 0.504 | 6.37 | 0.0397 |
| 이동 | **23.23°** | **0.640** | 7.59 | **0.0280** |

사거리는 오히려 이동 쪽이 **더 멀다**. 그래서 처음엔 *"포탑이 움직이면 자기
운동이 시선각속도에 더해지고, 이건 어떤 접근 제어기에도 걸리는 기하"* 라고
적었다. **그 문장은 틀렸다. 리뷰 2 가 무너뜨렸고 받아들인다.**

**왜 틀렸나.** 시선각속도는

```
    ω_LOS = |r × v_rel| / |r|²        r = p_att − p_fin
    포획기 기여분 = −(r × v_fin) / |r|²
```

이고 이건 **외적**이다. 즉 `v_fin` 의 **시선에 수직인 성분과 그 부호**에만
의존한다. 세 경우가 다 가능하다.

```
공격자 횡방향 운동과 같은 부호   -> 악화   (우리 제어기가 여기 걸렸다)
반대 부호                        -> 상쇄   (LOS-rate nulling. 유도에서 표준이다)
시선 방향으로만 이동             -> 영향 없음
```

따라서 해악은 포획기 **속력**에 비례하지 않는다. `nc` 를 쫓는 우리 제어기가
시선에 수직인 운동을 만들었을 뿐이고, 그건 **이 제어기의 성질**이지 이동성의
성질이 아니다.

**측정도 기전을 직접 재지 않았다.** 표의 "요구 회전" 은
`∠(현재 자세, nc 방향)` = **추종 오차**이지 목표축의 각속도가 아니다. 목표축이
빨리 움직여 뒤처지는 상태와, 목표축은 멈춰 있는데 초기 자세가 반대라 수렴
중인 상태가 같은 23° 를 낸다. p90 이 142° 인 양봉 분포라는 것 자체가 후자(초기
자세·후방 표적·사거리 밖)가 섞였다는 신호다.

기전을 확정하려면 목표축의 **스텝간 변화** `Δθ*ₜ = ∠(u*ₜ₊₁, u*ₜ)` 를 `ω_max·dt`
와 비교해야 하고, 결정적 반사실은 **같은 궤적을 `ω_max = ∞` 로 재생**하는
것이다 (§9).

### 8.4 판정 — (B) 채택. 단 **범위를 좁혀서**

**셀3 ≈ 셀1 → (B).** 주 실험은 고정을 유지한다.

확립된 것과 아닌 것을 갈라 적는다.

```
[확립]  사전 고정한 고권한 이동 제어기는 성형필요 297 판에서 한 건도 구제
        하지 못했고, 전체 500 판에서 20 건을 악화시켰다 (구제 0)
[확립]  현재 ω_max = 2.0 rad/s 조건에서 이동 추종은 게이트 개방률과 전체
        성능을 낮췄다
[가설]  이동이 만든 횡방향 자기 운동이 시선각속도·슬루 부담을 높였다 (§8.3)
[금지]  "이동은 일반적으로 해롭다"
[금지]  "어떤 이동 제어기도 이 기하를 피할 수 없다"
[금지]  "고정 포획기가 이동형보다 구조적으로 우월하다"
```

논문에 쓸 형태:

> 포획기에 limiter 와 같은 최대 가속을 허용하고 예측 포획점 추종 제어기를
> 적용한 감도 실험을 수행했으나, 성형필요 구간에서 구제 사례는 없었고 현재
> 슬루 제한에서는 전체 성능이 저하됐다. 이 결과는 모든 이동 제어기의 무효성을
> 뜻하지 않으며, 시선각속도와 슬루 여유를 직접 최적화하는 이동 정책은 향후
> 과제로 남긴다.

**남은 반증 공간이 좁혀졌다는 점은 적어 둔다.** 리뷰 2 가 든 대안 제어기 중
하나가 *"발사 예상 시점 전에만 위치를 바꾸고 종말 구간에서는 정지"* 인데,
그건 종말 국면에서 고정 포탑으로 돌아가는 것이다. 즉 이동이 도움이 되는
경로가 남아 있다면 그것은 **재배치이지 종말 추종이 아니다.**

### 8.4b ★ 주장 1 도 좁힌다 — 원래 우려를 직접 재지 않았다

원래 우려는 *"이동이 **학습 조준의 오차**를 위치로 흡수했을 수 있다"* 였는데,
이 실험은 양쪽 다 **해석적 조준**이다. 즉 흡수할 오차를 없앤 상태에서 쟀다.

```
이번 실험   완성도 높은 조준 아래 이동이 추가 이득을 만드는가
원래 우려   불완전한 학습 조준 아래 이동이 오차를 보상하는가
```

논리적으로 `이동+해석적 ≈ 고정+해석적` 이면서 `이동+학습 > 고정+학습` 이
가능하다 -- 이동이 **이미 틀린 조준축이 향한 쪽으로** 상대 위치를 옮기는
경우다. 그래서 셀 2·4 는 "보고용" 이 아니라 **원래 질문에 더 가까운 칸**이다
(분포 이동 오염은 그대로 남으므로 판정은 못 하지만).

안전한 문장: *"고정 가정을 제거하는 것만으로 음성 결과가 자동 해소되지는
않았다"* -- *"고정 가정은 원인이 아니다"* 는 과하다.

### 8.4c 통계 — 부트스트랩보다 정확검정이 낫다 (리뷰 2)

**전체 500 쌍.** 불일치 20 건이 **전부 악화 방향**이다. 귀무가설에서 양쪽이
등확률이면 양측 정확확률은 `2·(0.5)²⁰ ≈ 1.9e−6`. 부트스트랩 CI 보다 이 McNemar
정확검정을 싣는다.

**성형필요 0 대 0.** 부트스트랩 CI `[0,0]` 은 신뢰구간이 아니라 **퇴화**다
(불일치가 없어 재표집해도 항상 0). 올바른 형태:

```
297 쌍에서 이동으로 결과가 바뀐 에피소드가 0 건
불일치 확률 q 의 단측 95 % 상한  ≈ 1.00 %   (양측 상한 1.23 %)
|Δ_SHAPING| ≤ q 이므로 차이의 상한도 같다
```

**"등가성" 이라는 단어는 쓰지 않는다** -- 사전에 정한 실질 최소차 δ 가 없기
때문이다. 지금 상한(1.0 %)보다 조금 큰 δ 를 사후에 고르는 것은 규율 위반이다.

주의: 297 판이 소수의 시드 계열에서 나왔다면 iid 상한은 낙관적이다. §8.5 의
후속에서 초기조건 계층 군집 재표집으로 다시 낸다.

### 8.5 ★ 부수 발견 — 조준 **속도**가 병목 후보다

정지 조건에서도 한도 초과율이 0.504 다. docs/48 의 사슬은 조준 *방향*만 봤고
*속도*는 안 봤다. 단 §8.3 이 적었듯 이 수치는 추종 오차이지 요구 각속도가
아니므로 **절대 수준은 아직 근거가 아니다.**

확인 경로가 §9 다. 만약 슬루가 binding 이면 파급이 크다 -- **BC 가 조준
방향을 97 % 회복시켜도 포탑이 시간 내 못 따라가는 구간이 남는다.** docs/49 의
해석("조준 함수는 배울 수 있다")은 유지되지만 그것으로 충분한가가 새 질문이
된다.

## 9. 무한 슬루 반사실 (2026-08-05, 리뷰 2 의 §4 권고)

`{고정, 이동} x {ω_max = 2.0, ∞}` 4 칸, 같은 CRN 500 쌍, 새 RL 0 개.
(`ω∞` = 1e6 rad/s = 스텝당 2.9e6°, 사실상 즉시 정렬.)

| | 전체 무력화 | 비손실 | SHAPING |
|---|---:|---:|---:|
| 고정 · ω2.0 | 0.1820 | 1.000 | 0/297 |
| 고정 · ω∞ | **0.1820** | 1.000 | 0/297 |
| 이동 · ω2.0 | 0.1420 | 1.000 | 0/297 |
| 이동 · ω∞ | **0.1420** | 1.000 | 0/297 |

```
고정 ω2.0 -> 고정 ω∞    구제 0 / 망침 0  (500 쌍 전부 일치)
이동 ω2.0 -> 이동 ω∞    구제 0 / 망침 0  (500 쌍 전부 일치)
고정 ω∞   -> 이동 ω∞    구제 0 / 망침 20, 차이 -0.0400   <- ω2.0 과 완전히 동일
```

### 9.1 배선 검증 먼저 (불일치 0 이 너무 깨끗해서)

override 가 판정까지 도달하는지 12 판 273 스텝을 스텝 단위로 대조했다.

```
조준오차가 달라진 스텝      54.9 %      <- 자세를 실제로 바꾼다
v_shot_soft 가 달라진 스텝  43.6 %      <- 그게 판정 함수까지 간다
판당 최대 v_shot           0.6679 -> 0.6756   (+1.2 %)   ← ★ 여기가 안 움직인다
```

**배선은 정상이다.** 슬루를 풀면 중간 스텝의 조준은 크게 달라지는데,
**발사 게이트를 결정하는 판당 최대 `v_shot` 이 거의 안 변한다.** 정렬이 중요한
순간에는 포탑이 이미 정렬돼 있다.

### 9.2 ★ §8.5 는 죽었다 — 슬루는 병목이 아니다

무한 슬루로 500 판 중 **결과가 바뀐 판이 0 건**이다. §8.5 가 근거로 삼은
"정지 조건 한도 초과율 0.504" 와 "잔여 조준오차 중앙 42.9°" 는 **리뷰 2 가
경고한 그대로** 정렬이 무의미한 스텝(초기 자세·후방 표적·사거리 밖)이 만든
측정 산물이었다. 리뷰 2 §7 이 이 분기를 미리 적어 뒀고, 그대로 나왔다.

`omega_max = 2.0` 이 `ASSUMED` 선언값이라는 점도 이제 문제가 아니다 -- 값이
결과를 안 바꾸므로 감도 실험이 필요 없다.

### 9.3 ★ §8.3 기전도 죽었다

슬루가 매개였다면 무한 슬루에서 이동의 해악이 줄었어야 한다. **정확히 동일하다**
(−0.0400, 망침 20, 구제 0). 즉 *"자기 운동이 시선각속도에 더해져 슬루 부담을
높였다"* 는 서술은 **틀렸다.** 리뷰 2 가 주장 2 를 무너뜨린 데 이어, 그 대안
설명(슬루 매개)까지 내 실험이 스스로 기각했다.

이동이 왜 해로운지는 **지금 모른다.** 남은 후보는 리뷰 2 가 든 것들이다 --
사거리·실현가능 회피집합·게이트 체류시간. 다음에 물을 것이면 그쪽이다.

### 9.4 대신 주 결론은 **강해졌다**

```
[확립]  이동은 성형필요 297 판에서 한 건도 구제하지 못한다.
        ★ 이제 슬루 제한 유무와 무관하게 그렇다 (통제 하나 추가)
[확립]  이동은 전체를 악화시킨다 (-0.0400, 불일치 20 이 전부 한쪽,
        McNemar 정확 양측 p = 2(0.5)^20 ≈ 1.9e-6). 슬루 제한과 무관하다
[확립]  ★ 슬루 속도 상한은 이 시스템에서 binding 이 아니다 (500/500 동일)
[미상]  이동이 해로운 기전. §8.3 의 설명은 기각됐다
```

논문에는 §8.4 의 문장을 쓰되 **"현재 슬루 제한에서는"** 이라는 단서를 뺀다 --
슬루와 무관함을 쟀기 때문이다.
