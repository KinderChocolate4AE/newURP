### 0.2 기호 — KSAS 2026 추계 계승

| 기호 | 뜻 | 기준값 |
|---|---|---|
| ρ | net 유효 반폭 = R_max·tanθ (KSAS 정의, 길이) | 1.77 m |
| w | 전개 지연 τ 동안 표적이 조준점에서 벗어날 수 있는 최대 거리 = ½aτ² | 0.92 m |
| **χ** | **포획 지연 회피수 = w/ρ = aτ² / (2ρ)** (KSAS 명칭) | 0.52 |
| χ*_geom | 창 존재 경계 = cosθ / (1 + sinθ) (KSAS 식 (5) 와 같은 값) | 0.808 |
| χ*_0.2 | 0.2초 실용 창 경계 = χ*_geom · (1 − 0.2·V/R_max) | 0.355 (0.175초 기준 0.412) |
| θ, R_max, τ, a, V | 반각, 사거리, 전개 시간, 위협 가속, 위협 속도 | 12.15°, 8.22 m, 0.30 s, 20.45 m/s², 23.01 m/s |

- 각도는 KSAS 와 같이 12.15°.

### 0.3 세 제언 — 모든 절은 셋 중 하나를 받친다

| | 제언 | 근거 절 |
|---|---|---|
| ① | **요구 성능**: net 요격기의 요구 성능은 사거리·반각만으로 정할 수 없다. 전개 시간·대상 위협의 가속·속도를 함께 명시해야 하며, 그 조합은 χ ≤ χ*_0.2 와 0.2초 × 위협 속도 < 사거리 로 요약된다 | §4 |
| ② | **시험평가**: 학습 (AI) 기반 방어의 성능은 그 체계 (그 행동 모드) 전용으로 적응한 레드팀으로 평가해야 한다. 다른 모드용 회피자로 재면 중앙값 2.6–3.8 배 부풀려졌다 | §5 |
| ③ | **실측**: net 전개 시간과 조준 정확도는 경계를 지배하지만 독립 실측 공개 자료가 없다 → 획득 전 시험평가 항목으로 실측 | §2, §4 |

### 0.4 줄거리

net 요격기는 이미 조달되고 있다 (현황)
→ 그러나 "어떤 사양을 요구하고 어떻게 시험할지" 의 정량 기준이 없다 (문제)
→ 선행 해석 (KSAS) 의 χ 에 위협 속도를 더해 실용 창 조건을 세운다 (분석 1)
→ 같은 net 이 위협 등급에 따라 넉넉하기도, 창이 없기도 하다 (모델·이상적 회피자 가정)
→ 조건 미달 사양에서는 학습 방어 다섯 가지가 모두 실패했고, 평가 방법을 잘못 고르면 성능이 3 배 안팎 부풀려진다 (분석 2)
→ 요구 성능 · 시험평가 · 실측 세 제언 (제언).

### 0.5 첫 페이지 테스트

1. "net 요격기의 요구 성능은 전개 시간과 대상 위협을 함께 명시해야 한다. 같은 net 이 일반 촬영용 드론에는 넉넉하지만, 이상적으로 회피하는 레이싱급 기체에는 보장 포획 순간이 없다."
2. "AI 기반 방어는 그 체계 전용으로 적응한 레드팀으로 시험해야 한다."

### §4 분석 1 — 요구 성능 (2.25매) ★ 손으로 다시 유도하면서 쓸 절. 단위는 **초**.

| 단락 | 내용 | 식·숫자 | 주의 |
|---|---|---|---|
| 4-1 창 존재 (선행 결과) | **[KSAS] 인용, 반 단락**: χ ≤ χ*_geom = cosθ/(1+sinθ) 일 때만 보장 포획 순간이 존재. 보장 포획 조준 거리 구간 [w/sinθ, R_max − w] | 0.808 / 4.37–7.30 m / τ 0.30 s 에서 a 31.8 m/s² | 명제 번호 붙이지 않음. "불가능" 은 χ > 경계 에서만, 모델 안에서 |
| 4-2 실용 창 (새 결과) | 정면 직선 접근 시 창 길이 T = (R_max/V)·(1 − χ/χ*_geom) — **χ 에 대한 직선**. 0.2초 이상 필요 → χ ≤ χ*_0.2 = χ*_geom·(1 − 0.2·V/R_max). **두 조건 동시 필요**: 0.2·V < R_max, 그리고 χ ≤ χ*_0.2. KSAS 의 속력 의존 관찰과 같은 방향 (속력이 크면 창이 짧다). 등록 시점·경위 공개 (학습 실험 전, 단 시뮬레이션 지도를 본 뒤) | T 상한 0.36초, χ*_0.2 = 0.355 (0.175초: 0.412). τ 0.30 s·V 23 m/s 에서 0.2초 창은 **a ≤ 14.0 m/s²** 위협에만. 속도 한계 41 m/s | "몰래 맞힌 예측" 금지. KSAS 폐루프와의 정량 대조는 하지 않음 (모델이 다름) |
| 4-3 지연과 오차 (해석만) | ① 회피자 반응 지연 τ_r → χ × [(τ − τ_r)/τ]² (0.15초면 1/4) ② 방어 추적 지연 L → χ × [(τ + L)/τ]² ③ 조준 오차 δ → 창 존재 경계 χ*_geom(δ) = 1 / [tanθ·(1 + 1/sin(θ − δ))]. δ ≥ θ 면 창 없음. **좁은 콘 net 일수록 조준 오차에 민감** | ③ δ 0.05 rad → 0.808 에서 0.645 (정확한 값). ② 는 **새로 세운 식 — 직접 유도해 확인한 뒤에만** | 실측 없음 → 제언 ③ |
| 4-4 위협 등급별 판정 | 같은 net (τ 0.30 s) 에서 χ = a × 0.0254: Mavic급 (a 6.9) 0.175 / Phantom급 (8.8) 0.224 / 표준 쿼드 (17.4) 0.442 / 레이싱 쿼드 (≈ 39) 0.99 → 창 없음 (이상적 회피자 가정). 필요한 전개 시간 ∝ 1/√(위협 가속). **정책 읽기**: 요구 성능은 "대상 위협 등급" 을 명시해야 의미가 있다 | 위협 가속은 사양 틸트각·추력비에서 도출. **전투용 FPV (탄두 탑재) 가속은 공개 자료 없음** | 그림 2 는 반각 12.15°·사거리 8.22 m 전용 — 캡션에. **실물 net 의 χ 는 올리지 않음** |
| 4-5 시뮬레이션 대조 | 쏘지 않는 교전 기록 위에서 net 사양만 바꿔 판정을 다시 계산 (공격자 = 규칙 방어용으로 학습된 비공진화 공격자, 낙관 편향). χ 가 작을수록 창이 커짐, 등록 경계는 등록 전에 본 자료의 열림/닫힘과 12 개 중 11 개 일치, 예측은 관측의 상한. 전개 시간·위협 가속·반각을 바꿔도 같은 χ 면 창이 거의 같음 (한 문장) | 동점 보정 순위상관 0.93 (반복 측정 0.94) / 사양 변형 12개 | 그림 3 = 머니 커브 **(a) 패널만**. collapse 는 한 문장, 그림 없음 (AIAA) |

- **AI 사용 명시**: 4-1·4-2 의 유도는 AI 보조 세션이 먼저 만들었다 → 직접 다시 유도해 확인한 뒤 쓴다.
