## 0. 전체 줄거리 (한 장 요약 — 이 순서가 논문의 논리)

1. **문제**: net 은 발사 후 τ 동안 공격자가 도망칠 수 있다 → "콘 안에 있으면 잡힌다" (기하 envelope) 는 과대평가.
2. **해석**: 보장-포획 판정 → 무차원비 ρ = R_max·tanθ / (½aτ²) 하나로 1차 정리. 창 존재 ρ₀ = secθ+tanθ, 창 폭 N(ρ), 실용 경계 ρ* (사전 등록).
3. **현행 net (ρ 1.92)**: 행동 처방 5종 모두 실패 → 원인 = 창이 안 생김 (감지 ✓, 전환 ✓, 생성 ✗).
4. **net 사양을 바꾸면**: 프로브 창은 해석 곡선을 따라 열림 (11/12 일치) / 정합 감사 천장은 0.4–1.7% → ~9% 로 오르지만 ρ ≈ 4 이상 평탄.
5. **limiter 의 탈출로 제어 기회**: 측정상 0 (이 net 기하·교전 규칙·1e7 조건부).
6. **방법론**: 불일치 감사는 천장을 2.6–3.8 배 부풀린다 → 방어 평가는 정합 감사로.
7. **함의**: "필요조건은 해석이 정하고, 도달 수준은 적응 회피자가 정한다". net 사양 요구조건 + 평가 방법 권고. 한계: 모델 내부·3DOF·τ 실측 부재.

심사진 (공사·방산) 앞에 세울 메시지 두 개 (지도교수 10-11): **① net 사양 요구조건 (ρ)** · **② 정합 감사 없이는 2–4 배 과대평가**.

## 8. 결론 (~0.25매, 3 단위)

1. 절단선 문장의 사용자 버전: 필요조건 (보장-포획 창) 은 ρ 의 닫힌 형식이 정하고, 학습 방어가 도달하는 수준은 적응 회피자가 정한다.
2. 실무 권고 두 개: net 사양은 ρ (τ² 가 지배) 로 / 방어 평가는 정합 감사로.
3. 후속: 전이 구간 사다리 (E1, 사전 등록) · τ 실측 · 3DOF+ · 다중 공격자 · mode 전환 (Paper 2).
