- **일자**: 2026-09-16 · **지위**: **설계 노트 (초안 · 미봉인)** — docs/93 과 같은 급.
  결재 대상은 §8. 봉인 문서(B0 v3 `5e7b5b486b9d8a4a` · docs/102 · docs/89 r4 달력)를
  **하나도 변경하지 않는다.**
- **경위**: 교수 관점의 외부 검토 (2026-09-15, **AI 검토 — 실제 지도교수 검토 아님**) 가

  본 노트는 그 관점을 **현행 봉인 상태와 docs/103 의 범위 경계 안에서 우리 연구에 번역**한

- **어휘 규율 승계**: docs/103 부록 D + R2b closure 어휘 전부 유효. "협력 효과" 금지 —

- **범위 제외 선언**: 본 방향은 **kinetic 경로의 전술 최적화를 포함하지 않는다** —
  KINETIC 은 scripted PN reference fallback · NET_FAIL RL-credit cut · H_illegal

## §1. 검토의 3분(triage) 수용 — 세 질문을 동등 목표로 두지 않는다

| 질문 | 우리 프로젝트에서의 실체 | 배치 |
|---|---|---|
| **세계가 얼마나 타당한가** | `docs/103` (r2 완성) | **주장 범위의 경계 문서.** 재감사 루프로 돌아가지 않는다 — 103 의 미확인 목록을 전부 신규 실험 과제로 바꾸지 않는다는 103 §D 규율 그대로 |
| **일반화** | A-family worst-case (docs/97, W10) · plant swap (docs/93) · PFSP (이연) · 잡음/지연 (층3) | **주 질문 — 단, 한 축만** (§3) |
| **행동은 왜 효과적인가** | mechanism branch (`101-A`, **CLOSED** 2026-09-14b) | **설명 수단.** 논문 본체로 승격하되 **새 mechanism 카드는 열지 않는다** (14b 종료 선언 유지) |

수용 문장: **103 은 기반, mechanism 사슬은 도구, 일반화가 질문이다.**

## §2. 주 질문 (후보 기여 — 미점유가 확인된 자리 아님)

> **공칭(nominal) 성과가 비슷한 학습 정책들 사이에서, 공칭 평가 rollout 에서 사전
> 등록·측정한 행동 특성이, 선언된 A-family Class I behavioral 공간의 worst-found 점
> e\* 에서의 Δχ50 차이를 — 그 결과를 보기 전에 — 예측하는가.**

- **"비슷한"의 정의**: 공칭 Δχ50 차 < δ_χ = 0.03 (docs/92 practical resolution 재사용 —
  새 상수 없음).
- **예측 대상 (1차)**: Δχ50@e\* — docs/97 Part B 프로토콜이 이미 산출하기로 봉인한 양.
  셀별 paired Δp 는 보조.
- **null predictor (비교 기준)**: **공칭 Δχ50 자체.** 공칭만으로 e\* 서열이 설명되면
  행동 특성의 추가 기여는 없다 — 그대로 보고하고 접는다.
- **사전–사후 경계**: 예측은 W10 e\* 평가 **실행 전 서면 등록** (prediction card).
  결과 후 특성 재정의는 금지 — 바꾸려면 새 탐색 카드로만 (검토의 "가설이 맞도록 행동
  분류를 결과 후에 바꾸지 않는다" 조항의 기계화).

**이 질문이 우리에게 자연스러운 이유 세 가지**:

1. `101-A` 가 정확히 이 열린 위험을 남겼다 — 닫힌 메커니즘(near-tie argmax separatrix)은
   **A2 policy-specific 일 수 있다**고 스스로 병기했고, docs/97 §B.8 은 PFSP 를
   "mechanism transportability test" 로 재규정했다. 본 질문은 그 재규정의
   **scripted-공간(Class I) 판본**이며, 이번 학기 달력 안에서 실행 가능하다.
2. 행동 특성 후보가 임의 발명이 아니라 **닫힌 증거 사슬에서 유도**된다 (§4) — 검토가
   경고한 "분석자마다 행동 이름이 달라지는" 문제의 1차 방어.
3. **discovery/evaluation 분리 규율이 이미 봉인돼 있다** (docs/97 §B.3 seed 서로소 ·
   fresh CRN 재평가) — "결과 전 예측" 구조를 새 규율 없이 지탱한다.

**문헌 위치** (2026-09-15 검토가 준 **제한된 확인**의 승계 — 전수 검증 아님):
CORD (arXiv:2501.02221, 역할 다양성 → 새 동료 일반화) · *Coordination Matters*
(arXiv:2605.06557, 총점 너머 행동 분석 자체가 이미 제안된 방향) · MEAL
(arXiv:2506.14990). ⇒ "성공률 외에 행동도 본다"로는 부족하고, 우리의 차별 후보는
**결과 전 예측 + 닫힌 메커니즘 유도 특성**의 결합이다. 이것은 후보 기여이지 확인된
공백이 아니다 — P-7 류 신규 prior 스캔 시 이 세 편 + 인접을 사람 원문 대조 대상에 포함.

## §3. 다섯 고정 (범위 잠금 — 검토 형식 그대로)

| 고정할 것 | 이 연구의 범위 |
|---|---|
| 과제 | **현행 봉인 세계의 clean net capture 그대로.** 새 과제·새 세계·새 계약 없음 |
| 일반화의 의미 | **A-family Class I behavioral 변동 단일 축** (docs/97 §A.3 — 좌표 (χ,η,λ) 보존 변동만). plant swap(93) · PFSP · 잡음/지연 · 자산 위치 랜덤화는 **이 연구의 주장에서 제외** — 각자 별도 카드. "일반화"라는 단어 아래 서로 다른 문제를 묶지 않는다 |
| 주된 결과 | e\* 에서의 Δχ50 (docs/97 §B 산출물) |
| 설명 대상 | **사전 등록 행동 특성 3~5개** (§4). 전부 **NET 단계 한정** — arm/정책 차이는 NET 단계에만 존재한다 (docs/103 §3.3 / U-3) |
| 산출물 | 특성–이식성 관계의 **적중/실패 기록 + 적용 한계**. 정책 수가 ~9 (3 arm × ≥3 seed) 라 회귀·상관 연구가 아니라 **서면 예측 대조(ordinal prediction card)** 형식 — 이것이 이 연구 주장의 상한이다 |

- 자산 위치 랜덤화를 제외하는 근거는 103 §3.1 핵심 2: 임무 기하가 관측에 없어 현 관측
  으로는 그 일반화를 **원리적으로 물을 수 없다** — 관측 확장은 세계 개정(B0 v4) 사안.
- 방법론(새 알고리즘·새 학습 기법)을 선행 목표로 고정하지 않는다 — §5 의 순서에서
  반복 확인된 문제가 있을 때만.

## §4. 행동 특성 후보 (초안 — W10 전 feature-registry 카드로 봉인)

파생 출처는 전부 **닫힌 mechanism 사슬** (2026-09-14b §2 표) 이고, 적용 대상은 **학습
정책의 공칭 평가 rollout** — 유도에 쓰인 R2b 140판(3중 선택, 103 §10.3)과 무관한 새
측정이다. 카드에서 각 특성의 정의식·측정원·예측 방향을 확정한다.

| # | 특성 (가칭) | 유도 출처 | 측정 | 사전 예측 방향 (초안) |
|---|---|---|---|---|
| **F1** | **route-경계 근접 의존도** — 성공 판에서 fire 이전 A2 route argmax margin δ_g 분포의 near-tie 질량 | `101-A` | 공칭 rollout 후처리 (`route_boundary_audit` 계측 재사용) | 높을수록 e\* 이식성 **낮음** (A2-brittleness 대리) — 본 연구의 주 예측 |
| **F2** | **이른-궤적 매개 의존도** — prefix-withdrawal 반사실에서 성공이 깨지는 비율 | `96-BR1` | 평가 sidecar replay (**진단 전용, primary 와 pooling 금지**) | 카드에서 확정 |
| **F3** | 속력/위치 채널 비 (AUTH–LOST 판별의 속력 우세) | `99-P` | 후처리 | 카드에서 확정 |
| **F4** | P(FIRE\|χ) · P(N\|FIRE,χ) 분해 형상 — 게이트-변 vs 조향-변 개선의 비 | docs/89 §4 의무 로그 | **이미 로깅 예정** | 카드에서 확정 |
| **F5** | Φ-hacking 감시 4종 시그니처 | docs/89 §4 | **이미 로깅 예정** | 카드에서 확정 |

**규율 3항**:

1. **read-only**: 특성은 보상·sampler·training contract·CEM 탐색 구간에 절대 되먹이지
   않는다 — docs/97 §A.5.1-(4) ("`101-A` 를 보고 구간을 조정하지 않는다") 의 정신을
   진단 층까지 확장. 되먹이는 순간 §B.8 transportability 시험의 독립성이 깨진다.
2. **F4 caveat 승계**: P(N|FIRE) 는 분모 구성 변화만으로 움직인다 (103 §7.4) —
   기술량으로만 쓰고 인과 서술 금지.
3. **측정 가능성 gate**: 카드 봉인 전에 각 특성을 rule arm (B2 산출물) 위에서 1회
   시험 계산해 "측정자에 따라 흔들리지 않는 정의"인지 확인 — 흔들리면 반려 (검토의
   "행동 개념이 측정 가능한 수준인가" 행).

## §5. 순서 — 재현 → 설명되지 않는 차이 → 예측 검증 (달력 무변경)

기존 봉인 사슬 그대로: **B2 primary → stop rule (W5) → training contract → MARL
(W6~W9) → 층3 (W10~W11)**. 본 방향이 얹는 것은 **관측 로그와 카드 2장**뿐이다.

1. **재현 (W6~W9, 기존)**: 검증된 공개 MAPPO 레퍼런스 + 3 arm × ≥3 seed — 검토가 말한
   "기존 방법의 알려진 성과를 신뢰할 수 있게 확보"가 이것이다. 새 알고리즘 없음.
2. **차이 존재 확인 (W9 말~W10 초, 결과 열람은 공칭까지만)**: (i) 공칭 Δχ50 이 δ_χ
   이내로 비슷한 정책쌍이 존재하는가 (ii) 존재한다면 — 이것이 "설명되지 않는 차이"의
   **후보**다. e\* 결과는 아직 보지 않는다.
3. **예측 등록 (W10, e\* 평가 전)**: feature-registry 카드 + prediction card 봉인 —
   정책쌍별로 "F1 이 큰 쪽이 e\* 에서 Δχ50 열세" 형식의 서면 예측.
4. **검증 (W10~W11, 기존 A-family arm 실행)**: docs/97 §B 프로토콜 그대로 실행 후
   적중/실패 대조. §B.6 판독 3분기와 병렬로 읽는다 — 분기 2 (nominal>0, e\*≈0) 가
   나오면 본 연구는 "**어느 정책이** 그렇게 되는지를 사전에 맞혔는가"를 더한다.
5. **방법론 확장은 반복 확인된 문제가 있을 때만** — 이번 학기 없음 (§9 이연 슬롯 불변).

## §6. 중단/판정 기준 (사전 고정 — 검토 표의 번역)

| 관찰 | 판정 |
|---|---|
| 공칭 Δχ50 만으로 e\* 서열이 설명됨 | 특성의 추가 기여 없음 — **폴드**, 보고서 한 줄 |
| 비슷한-공칭 정책쌍 자체가 없음 (seed 간 공칭 분산 > δ_χ) | 전제 불성립 — **폴드** (그 분산 자체는 별개 finding 으로 기록) |
| 특성 정의가 rule-arm 시험 계산에서 불안정 | 측정 가능 수준 아님 — 카드 반려, 그 특성 제외 |
| 예측이 discovery 쪽에서만 성립, 독립 평가에서 소멸 | 과적합/사후 설명 — **그대로 기록** (음성도 산출물이나, 음성이라는 이유만으로 출판 가치를 주장하지 않는다) |
| 서면 예측이 독립 평가에서 적중 | **후보 기여** — Paper 1 robustness/mechanism 절 + 후속 PFSP(learned attacker)에서의 사전 등록 예측으로 승격 |

**금지**: 결과 후 특성 재정의·재선별·구간 조정. 전부 새 탐색 카드로만.

## §8. 결재 목록 (사용자 트랙)

1. **일반화 단일 축 = A-family Class I 확정** (본 노트 추천). 대안으로 검토가 문자
   그대로 제안한 "**새 동료**" 일반화 — B-5 는 π_L/π_C 분리 구조라 **seed/arm 교차
   페어링(예: seed i 의 π_L + seed j 의 π_C) 평가가 추가 학습 없이 가능**하다 — 는
   저비용이지만, 이 연구의 주장에는 불포함하고 후속 카드로만 등재할지 결정.
2. §4 특성 후보 5종 중 3~5종 선별 + F1 주 예측 방향 추인. 카드 봉인 시점 = **W10,
   e\* 평가 전** (늦어도 층3 실행 개시 전).
3. prediction card 형식 = 서면 예측 대조 (회귀 아님) 추인.
4. docs/89 판올림 불요 판단의 추인 — 본 방향은 달력·게이트·계약을 바꾸지 않고 관측
   로그(이미 §4 에 의무화된 것 포함)와 카드 2장만 더한다.
