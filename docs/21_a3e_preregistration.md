# 21 — A-3e 사전등록 패키지 (v0.2, 2026-07-18 — 자기완결 3자 검토판; 비준 시 A-3e 동결 커밋)

> **성격**: 리포 접근 없이 본 문서만으로 판정 가능하도록 경위·증거 수치·규격을 수록한 사전등록 검토안. 여기 적힌 수치·규칙·seed는 실행 결과를 보고 변경하지 않는다. 작성자 = 설계 참여자(이해충돌; 자기신고 §9) — **§1–2 증거에서 독립적으로 판단해 달라.** 검토 후 Hyunjun 비준으로 A-3e 동결 커밋이 된다.
>
> **불변 규율**: 판정 J·게이트 정의·평가 경로·σ 램프(d0 0/d1 .005/d2 .01/d3 .015/d4 .02) 동결 / bank v2 재생성 금지(1회 원칙 소진) / 문턱 사후 조정 금지 / sealed 불가침 / 학습 금지(동결 전) / 하드 스톱·트립와이어 **2026-08-31**.

## 0. 판단 요청 요약

직전 라운드(0-e, 귀하의 조건부 승인 15항 전부 반영)에서 동결한 4조건 validation이 bank v2를 **FAIL**시켰다(§2). 재설계 노선으로 **A-3e**(d1-only 학습 파일럿 → 성공 궤적 수확 → rewind-v2)가 비준됐고, 신규 결정은 **[E-1]~[E-6] 6건**(그 외 전부 0-e 동결 사양 재사용)이다. 각 E-슬롯에 승인/수정 판정 + ⑥ 기존 동결 사양과의 충돌 + ⑦ 누락 자유도 + ⑧ 총평(P1′ 진입 가부)을 부탁한다.

## 1. 최소 배경 (직전 리뷰와 동일 세팅 — 1문단)

방어 리미터 4기(‖a‖≤30) + 1회 발사 finisher + 스크립트 공격자. clean = v_soft ≥ θ=0.9 ∧ 실행가능성>0(2000-표본 MC, CRN-의존 면도날). SBE: witness(v16/v20/v24 robust 1본씩)에서 t−k(k∈{1,2,4,8}=d1..d4)로 폐형식 감속-도착 전임자를 합성. 측정기(0-e 동결): Gate A **PFC** = 명목-참조 추적 clip(a_demo+K_p(p_ref−p)+K_d(v_ref−v)), 무차원 게인 (c_p,c_d)=(1.0,0.5), T_k=kΔt / Gate B 8멤버(brake·λ{2,5,10,20}·attpd 3조합, obs-전용) / 판정 4조건 = A reset_clean≤.2 ∧ B PFC≥.8 ∧ C zero≤.2 ∧ D paired-Δ LCB95>.4 (n=100, outcome=arrival_capture, σ-물질화, 부트스트랩 777).

A-3e의 가설: **실궤적 유래 전임자(속도·이력 보유 = on-manifold)는 같은 σ에서 더 강건하다** — 미검, 본 패키지가 그 검증 설계다.

## 3. [E-1] 스코프·클레임 경계

- **bank-v2-d1** = 기존 bank v2의 validation-admissible 부분집합 그대로: v16/d1 12 + v20/d1 12 = **24 draws**. 신규 생성 아님(재생성 원칙 무충돌); 원본 파일 불변 보존, admissible 필터만 기록.
- **클레임**: P1′ 성공 = **mechanistic·D1 한정**("동결 판정 J 그대로, action-necessary k=1 전임자에서 재성형-후-발사 학습 가능") — A-3b spawn-luck 천장((kk): 스폰-clean 기준선 수렴, 재성형 미학습)의 직접 후속 질문. 가족 일반화·method-competence 클레임 금지.
- 근거: 선택 자유도 0(admissible 판정의 소비적 사용). 대안(기각): v16/d2 .79 편입 = 문턱 완화 금지 위반. 리스크: 24 draws 협소 — 번들 라운드로빈으로 균등 소진하고 한계를 클레임 경계에 반영.

## 4. [E-2] d1-only 번들

- **dev-v2d1 = {jitter rng 75,000, reset seed 12.0M} / sealed-v2d1 = {95,000, 13.0M}** — 0-e 예약분 승계(취소 번들은 **미생성**이라 seed 오염 없음; 대안인 신규 대역 발급은 원장 증식만). 조성 = 0-e §8 규칙의 d1 사영: 셀 균등(v16:v20 50:50)·draw 라운드로빈(비복원 순환)·SHA-256 manifest(번들·bank·필터 기록·생성기 커밋·config·대장·게인·Gate B 사양)·sealed 불가침 테스트 4종(경로 거부/symlink·복사/--force 부재/metadata 변조 검출) 구현 포함.
- 스테이지 = **{d0(앵커: witness 슬롯 자체, σ=0), d1(bank-v2-d1 물질화, σ=.005)}**. d0 유지 근거 = A-3b R0의 "즉시 발사 습득" 단계 재현(캠페인 최초 학습 포획의 재현 경로).
- **zero-캐시**: dev-v2d1 생성 직후 스테이지별 zero-arm outcome을 episode ID 단위 1회 계산·동봉(exit 기계 입력; 0-e §7).

## 5. [E-3] P1′ — d1 학습 파일럿

- 3-seed scratch(train_seed 0–2), 트레이너 = 기존 sbe 커리큘럼에서 **스테이지 exit를 0-e §7 동결형으로 교체 구현**: 전진 = Δ̂_d(policy−zero, 동일 ep)>0.10 **2-eval 연속** / 후퇴 = UCB95(Δ_d)<0.05 ∧ stall 3(Wilson 게이트 폐지). **teacher-gating 기간은 exit 평가에서 제외**(fire-head 무학습 구간의 Δ는 무의미 — teacher-freeze 해제 후부터 계수). teacher 보조 진단 3종(발사 시 fresh-seed robust-clean·clean persistence·v_soft 마진) 로깅 등재(비구속).
- step 예산: **최소소요×1.2 룰**로 구현 시 산출·명기(2스테이지 × exit 2-eval × 케이던스; A-2 340k/A-3b 300k cap 불능 실수의 재발 방지 항목 — 수치는 구현 커밋에서 고정, 이후 불변).
- **P1′ 판정(0-e §7 P1 규칙 그대로)**: **sealed-v2d1 1회** 롤에서 seed별 paired Δ̂ — PASS = ≥2/3 seed Δ̂>0.10 ∧ 전 seed Δ̂≥0; pooled = 진단; McNemar = seed별 보조; 클레임 = "pilot evidence". dev 반복 평가 = development / sealed = confirmatory 지위 구분 유지. **FAIL → A-3e 종료·B 전환(수확 진입 금지).**

## 6. [E-4] 성공 궤적 수확 → rewind-v2 (신규 기계)

- **수확**(P1′ PASS 시): 각 seed의 best-ckpt(기존 사전등록 스코어 그대로)로 d1 물질화 스폰(수확 전용 지터 rng **78,000+1,000k+v**) × reset seed **700–749** × 셀당 200판. **성공 에피소드**(arrival_capture ∧ clean 발사)에서 발사 스텝 F 기준 **t = F−k (k∈{2,4,8}, 존재하는 k만)**의 전체 상태(리미터 p/v·공격자 p/v) + 이후 실행 액션 시퀀스 기록. 근접 dedup(리미터 위치 L2 < 0.05m 병합 — clean 창 두께 하한에 맞춘 선택, 실측 근거는 없음: 자기신고) 후 **per-k 목표 12·최소 8**(기존 수치 재사용). k별 미달 = 결측 기록(전 k 결측 → §8 중단).
- **RT-PFC**(recorded-trajectory PFC — Gate A 승계, 수식 동결): a = clip(a_rec(t) + K_p(p_rec(t)−p) + K_d(v_rec(t)−v), ‖a‖≤30), 참조 = 수확 에피소드의 **기록 궤적**(명목), 게인 = 동일 무차원 (1.0, 0.5)·T_k=kΔt. 특권 = 기록 궤적·시간 인덱스(obs 밖). PFC와의 차이는 참조의 출처뿐(폐형식 데모 → 실측 궤적). 대안(기각): ① d2 폐형식 재생성 = 금지·소진 ② 학습 정책 자체를 Gate A로 = 검증 대상을 기준선으로 쓰는 순환. **RT-PFC가 유일한 비순환 특권 기준선**이나 실측 이력 0(자기신고) — 기록 궤적의 CRN-특이성(그 seed에서만 성공)은 생성 screen의 fresh-CRN 20판이 걸러내는 구조.
- **rewind-v2 파이프라인(bank v2와 동형)**: 생성 screen = paired(RT-PFC/zero) 20판, seeds **750–769**, PASS = 16/4/4 → 독립 validation = **4조건 n=100, seeds 800–899, σ-물질화(지터 rng 79,000+1,000k+v)** — 판정식·부트스트랩(777)·배정식(⌊100/n⌋+잔여 index순) 전부 0-e §6 그대로, Gate A 좌석만 RT-PFC. 셀 = (원천 witness 가족, k) — 수확이 d1 두 셀에서 나오므로 자연 태깅(사후 셀 선택 자유도 없음). **판정: k=2 admissible ≥1 = on-manifold 가설 채택** → d2 사다리 복원·다음 사이클(시한 내); admissible 0 = 가설 기각 → B(벽 증거 최종 행: "on-manifold 전임자로도 σ-강건 도달성 미회복").

## 7. [E-5] seed·rng 대장 증보 (전 대역 서로소 — 테스트 락 약속)

- episode_reset(신규): **700–749 수확 / 750–769 rewind screen / 800–899 rewind validation**; 승계: 12.0M dev-v2d1 / 13.0M sealed-v2d1. 기존 전 가족(0–9 train, 7–16·100–104·200–209 union, 300–319·400–419(은퇴)·420–439·600–699, 500k/1.5M/2.5M, 7.0M/8.0M/9.0M, 31M)과 서로소.
- jitter_rng(신규): **78k대(수확)·79k대(rewind validation)**; 승계 75k/95k(번들). 불변: 게인 (1.0,0.5)·부트스트랩 777·arm rng 90k+7·reset_seed·teacher θ.

## 8. [E-6] 중단·전환 규칙 (사전 고정; 각 발동 = docs/12 §6 증거 행)

① P1′ FAIL → 즉시 B ② 수확: 전 k 결측(성공 풀 부족) → B ③ rewind validation k=2 admissible 0 → B ④ **하드 스톱 2026-08-31** — 도달 단계 무관 중단·B 확정. 일정 스케치: 구현·동결 ~1–2일 → P1′ 서버 반나절 → 수확 수 시간 → rewind 생성+validation ~1일 → 판독 = **1사이클 ≈ 1주**(시한 내 여유).

## 9. 자기신고

① 작성자 = 설계·실행 참여자. ② **RT-PFC는 실측 이력 0의 신규 측정기** — 게인 승계가 기록-궤적 참조에도 적정하다는 실증 없음(validation에서 처음 측정됨). ③ dedup 0.05m·수확 200판/셀·per-k 12/8은 기존 수치 재사용 또는 유추 선택 — 실측 최적화 아님. ④ v16/d2 near-miss(.79)를 회생 후보로 반복 언급해 왔음 — rewind 셀은 (witness, k) 자연 태깅이라 선택 개입 불가하나, 기대 편향의 존재는 신고. ⑤ E-2 예약 seed 승계는 "미생성 = 무오염" 논리에 의존. ⑥ P1′의 dev 반복 평가는 정책 선택에 사용된 데이터(sealed 1회만 confirmatory). ⑦ 수확 스냅샷의 k=4/8은 d1 에피소드 길이(발사까지 ~3–12스텝 관측)상 결측 가능성 높음 — d2 우선 재구축이 실질 목표.

## 10. 출력 형식 (부탁)

[E-1]~[E-6] 각각 ① 승인/수정(수정 시 대안+근거) ② 사전등록 문구 리스크 1줄. 이어서 ⑥ 0-e 동결 사양과의 충돌 지점 ⑦ 누락 자유도(결과 보고 고를 수 있게 남은 것) ⑧ 총평(이 패키지로 P1′에 들어가도 되는가). 비준 후 실행 순서: A-3e 동결 커밋 → 구현(번들 d1-사영·exit 기계·수확/RT-PFC/rewind + 테스트) → P1′(서버) → [PASS 시] 수확 → rewind-v2 생성·validation → 판독.
